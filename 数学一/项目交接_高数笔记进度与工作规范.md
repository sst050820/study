## 六、LaTeX / Markdown 公式防坑清单（血泪教训，逐条遵守）

> 第9讲曾出现大面积表格串格，第13讲曾出现大面积公式乱码。以下每一条都踩过坑，**写完必须自查**。

### 1. 表格内绝对禁止裸竖线
- Markdown 表格以 `|` 分列，公式里的绝对值/范数竖线会把单元格撕碎（第9讲串格事故根因）。
- **表格单元格内**：绝对值一律写 `\vert x\vert`，范数写 `\Vert v\Vert`；**禁止** `|x|`、`\|v\|`（`\|` 在表格里同样被当分隔符）。
- 表格外的行内/独立公式虽然 `|x|` 多数渲染器能认，但**全文档统一用 `\vert`** 最保险。
- `\vert` 后面若紧跟字母，**补一个空格**，防止被吞成 `\verta`（如写 `\vert J\vert\,du` 而非 `\vert J\vertdu`）。

### 2. 表格内禁止 cases 换行
- `\begin{cases}...\\...\end{cases}` 里的 `\\` 和 `&` 在表格单元格内容易错乱。
- 分段函数放进表格时，**拆成单行文字描述**，或把整个 cases 公式移到表格外独立成行。

### 3. `\left` 与 `\right` 必须成对（第13讲乱码主因，22处）
- 错误：`\left.\frac{\partial f}{\partial x}\vert_{(0,0)}` —— `\left.` 开了分隔符分组，却用 `\vert` 收尾，KaTeX 直接报红、整个公式不渲染。
- 正确写法二选一：
  - 不用左右配对：`\frac{\partial f}{\partial x}\big\vert_{(0,0)}` 或直接 `\frac{\partial f}{\partial x}\vert_{(0,0)}`；
  - 完整配对：`\left.\frac{\partial f}{\partial x}\right\vert_{(0,0)}`。
- **写完跑 left/right 配对自查脚本**（见 SOP 第5步）。

### 4. 不用老式 TeX 原语 `\atop`（第13讲 11 处）
- 错误：`\lim_{x\to0\atop y\to0}`（Typora/飞书/部分 MathJax 不认，显示源码）。
- 正确：`\lim_{\substack{x\to0\\y\to0}}`。

### 5. 不用 `\not\Rightarrow` 这类叠印原语
- 改为专用命令：`\nRightarrow`（推不出）、`\neq`（不等于）、`\nleq`/`\ngeq`。

### 6. 反斜杠命令后紧跟字母要留空格
- 如删除 `\left.` 后曾出现 `\Rightarrowf'_y`，LaTeX 把 `\Rightarrowf` 当成一个未知命令。
- 命令后接字母变量时写 `\Rightarrow f`（空格）或 `\Rightarrow\,f`。

### 7. 比较符号在表格/部分渲染器中的兼容
- 表格内 `<`、`>` 建议写 `\lt`、`\gt`（防止被误判为 HTML 标签）。
- 表格外正常用 `<`、`>` 即可。

### 8. 行内公式中的 cases
- 行内 `$...\begin{cases}...\end{cases}...$` KaTeX/MathJax 支持，可保留；但若该公式在表格内，按第 2 条处理。

### 9. 其他确认兼容、可放心使用的命令
`\dfrac \tfrac \substack \xrightarrow \mathring \varnothing \iff \nRightarrow \vert \Vert \big\vert \text{} \quad \qquad \, \; \! \sqrt[n]{} \begin{vmatrix} \begin{cases} \Gamma \Delta \lambda \mu \varepsilon \rho \varphi \psi \eta \xi`。

## 八、内容融合的尺度把握（经验）

1. **教材是骨架，视频是血肉**：定义、定理、公式、例题习题编号以教材为准；视频补充口诀（如二重积分"后积先定线，线内画条线，先交写下限，后交写上限"）、类比（"小薯条拼大面包""谁动了我的面包"）、命题风格提醒（"命题人故意给错误坐标系/错误积分次序"）、教材没有的函数清单（如无初等原函数清单）、真题年份标注。
2. **例题必须给完整过程**，不能只给答案；视频里教师"讨巧"的解法（如变上限积分不必算完直接求导）要写出并点明技巧。
3. **习题全解**：教材章末习题每一道都要在"基础习题精练"里给答案+关键过程，答案值必须与教材习题解答页核对一致。
4. **数字必须有出处**：例题答案、习题答案以教材页图为准；视频口误（偶有）以教材为准。
5. **前后讲呼应要点明**：如第13讲例13.1 与例13.8 呼应、第14讲高斯积分在第13讲例13.5 已出现——这类"前世今生"张宇课堂会专门提，笔记里要保留。
6. **仅数一/数二/数三的内容明确标注**（如第17、18讲整讲仅数一；差分方程仅数三；伯努利方程、欧拉方程仅数一）。

## 十、环境与工具备忘

- 操作系统：Windows，命令行用 PowerShell（注意：内联 Python 含 `$` 符号会被 PowerShell 解析报错，**复杂 Python 一律写成 .py 文件再执行**，不要用 `python -c` 写含 `$` 的脚本）。
- 视频转写走 `mediakit-cli`（byted-mediakit-video / byted-mediakit-shared skill），异步任务：提交拿 task_id → query-task 轮询 → completed 取字幕；命令语法以 skill 的 SKILL.md 与 `mediakit-cli <domain> <tool> --help` 实时输出为准。
- 教材是扫描 PDF，**没有文本层，不能用关键词检索**，只能导页图后 Read 图片。
- 产物一律 UTF-8 编码的 MD；Python 读写文件显式 `encoding="utf-8"`，并对 stdout 包 `io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8")` 防中文乱码。
- 交付只用 `present_files`；中间脚本、逐字稿、页图不交付。
