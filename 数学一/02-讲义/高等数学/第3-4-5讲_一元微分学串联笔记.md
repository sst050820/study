## 一、一句话总纲：是什么 → 怎么算 → 干什么用

```
第3讲 概念          第4讲 计算           第5讲 几何应用
导数/微分"是什么"  →  各种函数"怎么求导"  →  用 f'、f'' "研究函数长什么样"
（定义、可导可微）    （八大求导题型）       （单调/极值/凹凸/拐点/渐近线/最值/作图/曲率）
   地基                  工具                  用工具干活
```

- **第3讲**回答：导数的定义是什么、可导与连续/可微什么关系、导数几何上是什么（切线斜率）。——没有它，第4讲的公式只是符号，第5讲的 $f'(x_0)=0$ 你不知道为什么。
- **第4讲**回答：面对复合、分段、隐函数、参数方程、幂指、高阶等各种形式，怎么把 $f'$、$f''$、$f^{(n)}$ **算出来**。——它是纯工具，本身几乎不直接命题，却是第5讲每一步的"手"。
- **第5讲**回答：把第4讲算出的 $f'$、$f''$ 用起来——$f'$ 定升降与极值，$f''$ 定凹凸与拐点，配合第1讲极限定渐近线，最终画出函数、求出最值。

> 严格老师先点破：**这三讲不能割裂地背。** 第5讲卡壳，十有八九不是第5讲没懂，而是第4讲求导算错、或第3讲概念没透。哪里漏，回哪讲补，别在第5讲原地打转。

## 二、第3讲精华速览（概念，只留骨架）

| 模块 | 必须带走的结论 |
|---|---|
| 导数定义 | 三种等价形式（增量式/"狗"式/函数式）；本质是增量比的**极限** |
| 单侧导数 | 可导 ⇔ 左导 = 右导（均有限）；分段点必用此判 |
| 可导与连续 | **可导 ⇒ 连续；连续 ⇏ 可导；不连续 ⇒ 不可导** |
| 几何意义 | $f'(x_0)$ = 切线斜率；切线 $y-y_0=f'(x_0)(x-x_0)$；角点/无穷导数处"有切线但不可导" |
| 高阶导 | $f^{(n)}(x_0)$ 存在 ⇒ 低阶导在邻域有定义且连续（"连锁结论"） |
| 微分 | 一元函数**可微 ⇔ 可导**；$dy=f'(x)dx$，$\Delta y=dy+o(\Delta x)$（线性主部） |
| 导数性质 | 偶求导变奇、奇求导变偶；周期函数求导周期不变 |
| 含绝对值可导性 | $f$ 连续时 $F=f\cdot\lvert x-a\rvert$ 在 $a$ 可导 ⇔ $f(a)=0$ |

**第3讲埋下、第5讲引爆的两颗雷**：
1. 例3.9 已经用 $f'(x_0)=0$、$f''(x_0)$ 判过极值——那正是第5讲"第二充分条件"的雏形；
2. "可导 ⇒ 连续、连续不一定可导"直接决定第5讲：**不可导点（甚至间断点）也能是极值点，但拐点必须连续。**

## 三、第4讲精华速览（计算，只留工具清单）

**两大基本要素**：基本求导公式表（地基）＋ 四则运算。

**八大题型（第5讲会反复调用，括号是它在第5讲的用武之地）**：

| 题型 | 核心方法 | 第5讲在哪里被调用 |
|---|---|---|
| 复合函数 | 链式法则、一阶微分形式不变性 | 几乎每个 $f',f''$ |
| 分段函数 | 分段点用定义/左右导，区间内直接求 | 绝对值函数判极值拐点（例5.6） |
| 反函数 | 一阶相倒、二阶背公式 | 隐函数/反函数曲线性态 |
| 隐函数 | 两边求导、$y$ 是 $x$ 的函数 | **隐函数求极值（例5.3、习题5.9）** |
| 参数方程 | $\frac{dy}{dx}=\frac{y'_t}{x'_t}$；二阶导再除 $x'_t$ | **参数曲线曲率（例5.15）、参数作图（例5.14）** |
| 对数求导 | 取 ln 化乘除为加减 | 多因子函数求导后判单调 |
| 幂指函数 | $u^v=e^{v\ln u}$ | **$x^x$、$x^{1/x}$（例5.10、5.12）** |
| 高阶导数 | 归纳/莱布尼茨/泰勒公式 | **对 $f^{(n)}$ 再求极值（例5.4）、第三充分条件逐阶求导** |

> 一句话：**第4讲练的是"手速与准确率"，第5讲要求你一边做性态分析一边零失误地连续求两次导。** 第5讲的计算量，本质全是第4讲的账。

## 四、第5讲精华速览（几何应用，"三两一"框架）

- **三种点**：极值点（局部峰谷，写 $x=x_0$）、拐点（凹凸分界，写 $(x_0,f(x_0))$）、最值点（全局最高最低）。
- **两种形态**：$f'$ 定单调性与极值；$f''$ 定凹凸性与拐点。
- **一种线**：铅直 / 水平 / 斜渐近线（斜的最重，$a=\lim f/x,\ b=\lim(f-ax)$，两关都要过）。
- **一次总装**：作图四步（定义域奇偶周期 → $f'$/$f''$ 定性态 → 渐近线 → 画图），服务于第6讲方程根与不等式。
- **数一专属**：曲率 $K=\dfrac{|y''|}{[1+(y')^2]^{3/2}}$、曲率半径 $R=1/K$。

极值与拐点的判别是**一套错位一阶的对称结构**（第5讲核心，详见精讲 9.1 流程图）：必要条件分别是 $f'=0$、$f''=0$；第三充分条件分别"从 $f'$ 数零、偶阶定罪"和"从 $f''$ 数零、奇阶定罪"。

## 五、★三讲如何一环扣一环（本份笔记的核心）

### 5.1 因果链总图

```
第1讲极限 ──┬─> 第3讲：导数定义本身就是极限；可导⇒连续靠极限证
           └─> 第5讲：渐近线 = 纯极限题；保号性推出三大充分条件
                                          │
第3讲 概念（f'是切线斜率、可导⇒连续、f''判极值雏形）
   │ 定义清楚后，需要"算得出"
   ▼
第4讲 计算（对任意形式函数求 f'、f''、f^(n)）
   │ 工具备好后，需要"用得上"
   ▼
第5讲 应用（f' 定单调极值；f'' 定凹凸拐点；极限定渐近线；作图/最值/曲率）
   │
   ▼
第6讲 中值定理（罗尔/拉格朗日/柯西/泰勒；方程根、不等式、辅助函数——第5讲已处处埋伏笔）
```

### 5.2 "概念 → 计算"：第3讲每个概念，在第4讲变成一条可操作法则

| 第3讲的概念 | 第4讲对应的计算动作 |
|---|---|
| 导数是增量比极限 | 分段点、绝对值点不能套公式，只能用定义（左右导）求 |
| 复合函数微分 $dy=f'(u)du$ | 一阶微分形式不变性 → 链式法则的底层依据 |
| 高阶导定义 | 八大题型之"高阶导数"三种算法 |
| 隐函数/参数方程的导数几何意义 | 隐函数求导、参数方程求导两套固定流程 |
| 可微 ⇔ 可导、$dy=f'dx$ | 幂指/对数求导时用微分形式不变性简化 |

### 5.3 "计算 → 应用"：第5讲每一步都在调用第4讲（对照表）

| 第5讲的任务 | 第一步必做的第4讲动作 | 典型例题 |
|---|---|---|
| 判单调、找极值 | 求 $f'$ 并定号 | 全部例题 |
| 判凹凸、找拐点 | 求 $f''$ 并定号 | 例5.5、5.6 |
| 隐函数求极值 | 隐函数一次、二次求导（令 $y'=0$ 后项消失） | 例5.3、习题5.9 |
| 参数曲线算曲率 | 参数方程一阶、二阶导（二阶要再除 $x'_t$） | 例5.15 |
| 幂指/数列最值 | $u^v=e^{v\ln u}$ 改写再求导 | 例5.10、5.12 |
| 高阶导函数的极值 | 把 $f^{(n)}$ 当新函数，再求两阶导 | 例5.4 |
| 第三充分条件 | 逐阶求导到首个非零导数 | 例5.2、$-x^4$ 类 |

### 5.4 第1讲极限是贯穿三讲的"暗线"

- 第3讲：导数定义 $f'(x_0)=\lim\frac{\Delta f}{\Delta x}$ 本身就是极限；
- 第5讲：
 - **三大充分条件的证明全靠"极限保号性"**（由 $f''>0$ 推 $f'$ 左右符号）；
 - **渐近线表面是几何、里子全是极限**：求 $a$ 是 $\infty/\infty$、求 $b$ 是 $\infty-\infty$、铅直看单侧极限是否为 $\infty$；
 - 开区间求最值、作图定端点趋势，靠的都是 $x\to x_0^\pm$、$x\to\pm\infty$ 的单侧极限。
- 所以"极限算不好 → 导数定义不清 → 渐近线/充分条件全崩"是一条连锁反应，病根往往在第1讲。

### 5.5 一条主线贯穿：用 $f,\ f',\ f''$ 三个层次读一张图（三讲共同的灵魂）

| 层次 | 第3讲给定义 | 第4讲给算法 | 第5讲给用途 |
|---|---|---|---|
| $f$ 本身 | 函数值、连续性 | —— | 最值、渐近线趋势、作图描点 |
| $f'$（一阶） | 切线斜率、瞬时变化率 | 复合/隐函数/参数等求 $f'$ | **定单调区间、定极值（变号/ $f'=0$）** |
| $f''$（二阶） | 高阶导、变化率的变化率 | 连续求两次导、参数二阶导 | **定凹凸、定拐点（变号/ $f''=0$）、曲率分子** |

> 读图顺序永远是：**看 $f'$ 正负 → 知 $f$ 升降；看 $f''$ 正负 → 知 $f$ 碗口朝向；$f'$ 变号处找极值、$f''$ 变号处找拐点。** 第3讲让你懂"为什么这三个层次够用"，第4讲让你"算得出这两层导数"，第5讲让你"读得懂整张图"。

## 六、跨讲高频"组合拳"题型（考研怎么把三讲捏在一起考）

1. **隐函数 + 极值**（第4讲隐函数求导 × 第5讲第二充分）：例5.3、习题5.9，固定三步——一次求导令 $y'=0$ 找驻点、联立原方程、二次求导代值定号。
2. **参数方程 + 曲率/切线**（第4讲参数求导 × 第3讲切线 × 第5讲曲率）：例5.15，数一常以小题出现。
3. **幂指函数 + 最值/作图/渐近线**（第4讲 $e^{v\ln u}$ × 第5讲性态分析 × 第1讲极限）：例5.10、5.12，$x^x$、$x^{1/x}$ 是经典载体。
4. **绝对值/分段 + 极值拐点兼任**（第3讲可导性 × 第4讲分段求导 × 第5讲退回第一充分/定义）：例5.6，考"不可导点能否同时是极值点和拐点"。
5. **高阶导 + 极值**（第4讲高阶导公式 × 第5讲第三充分）：例5.4，把 $f^{(n)}$ 当新函数再走一遍判别。
6. **函数性态 + 方程根个数**（第5讲作图 × 第6讲中值定理的预告）：如 $e^x=ax$ 变形为 $a=e^x/x$，用第5讲画出的曲线与水平线数交点——这是三讲能力通向第6讲的桥。

## 七、跨讲易错串联（同一类错误在三讲的不同面孔）

| 错误本质 | 第3讲的表现 | 第4讲的表现 | 第5讲的表现 |
|---|---|---|---|
| 混淆充分/必要 | 可导⇒连续，反推就错 | 公式成立条件（如参数二阶导）漏前提 | $f'=0$ 就当极值、$f''=0$ 硬套第二充分 |
| 忽视"点是否可导" | 分段点不验证左右导相等 | 分段点直接套求导公式 | 不可导点硬套第二/三充分，忘了退回第一充分/定义 |
| 绝对值/开方 | $\lvert f\rvert$ 可导条件 | 分段求导、$\sqrt{u^2}=\lvert u\rvert$ | 例5.1 平方开根漏绝对值、例5.6 不写分段 |
| 高阶/二阶导算错 | 高阶导连锁存在性 | 参数二阶导漏除 $x'_t$、复合漏链 | 导致凹凸、拐点、曲率全盘错 |
| 极限/保号性不熟 | 导数定义型极限卡住 | —— | 充分条件证明、渐近线 $a,b$ 算不出 |

## 八、严格老师的收束：三讲的复习顺序与自检

**正确的复习动线**（不是线性看一遍，而是带着下游问题回上游）：

1. 先拿第5讲一道完整性态题（如例5.13 $e^x/x$）自测，卡在哪一步，就暴露了哪一讲的洞：
 - $f'$、$f''$ 列不出来/算错 → 回第4讲对应题型专项；
 - 不知道为什么 $f'=0$ 是候选、为什么不可导点也要查 → 回第3讲可导与连续、导数定义；
 - 渐近线 $a,b$ 算不对 → 回第1讲 $\infty/\infty$、$\infty-\infty$。
2. 三讲都过完后，**闭卷默画三张图**：
 - 第5讲"极值 vs 拐点错位一阶"判别流程图；
 - "$f\to f'\to f''$ 三层次读图"表；
 - "概念(3)→计算(4)→应用(5)→中值定理(6)"因果链。
3. 能给别人讲清"为什么不可导点能是极值点、却不能（在不连续时）是拐点""为什么有水平渐近线的方向就没有斜渐近线"，才算真的把三讲打通——这些问题的答案分别来自第3讲的连续、第1讲的极限，而不是死记第5讲结论。

**一句话收尾**：第3讲让你"识得导数"，第4讲让你"算得导数"，第5讲让你"用导数看穿一个函数"。识、算、用三步合一，一元微分学才算真正立住，也才有底气进第6讲中值定理。
