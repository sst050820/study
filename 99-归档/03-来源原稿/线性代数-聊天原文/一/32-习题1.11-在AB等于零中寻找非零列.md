# 一、为什么 \(AB=0\) 能推出 \(A\beta=0\)？

假设 \(B\) 的列向量分别是：

\[
B=[\beta_1,\beta_2,\beta_3].
\]

那么：

\[
AB
=
A[\beta_1,\beta_2,\beta_3].
\]

矩阵左乘 \(A\)，就是对每一列分别作用，所以：

\[
AB=
[A\beta_1,A\beta_2,A\beta_3].
\]

题目告诉：

\[
AB=0.
\]

因此：

\[
A\beta_1=0,\qquad
A\beta_2=0,\qquad
A\beta_3=0.
\]

也就是说：

\[
\boxed{B\text{ 的每一列都是 }Ax=0\text{ 的解}}
\]

---

# 二、为什么一定存在一个“非零解”？

关键条件：

\[
\boxed{B\ne0}
\]

这里一定不能误解成：

\[
\det B\ne0.
\]

\(B\ne0\) 只表示：

\[
\boxed{B\text{ 不是零矩阵}}
\]

所以 \(B\) 至少有一个元素不为0，也就一定至少有一列：

\[
\beta\ne0.
\]

而前面已经知道所有列都满足：

\[
A\beta_i=0.
\]

因此至少存在一个：

\[
\boxed{\beta\ne0}
\]

满足：

\[
A\beta=0.
\]

所以：

\[
Ax=0
\]

存在非零解。

对于方阵齐次方程：

\[
\boxed{
Ax=0\text{ 存在非零解}
\iff
\det A=0
}
\]

因此：

\[
\boxed{\det A=0}.
\]

这就是这题最关键的一步。fileciteturn33file0L777-L783

# 三、计算 \(\det A\)

现在：

\[
\det A=
\begin{vmatrix}
1&2&-2\\
2&-1&\lambda\\
3&1&-1
\end{vmatrix}.
\]

沿第一行展开：

\[
\det A
=
1
\begin{vmatrix}
-1&\lambda\\
1&-1
\end{vmatrix}
-
2
\begin{vmatrix}
2&\lambda\\
3&-1
\end{vmatrix}
+
(-2)
\begin{vmatrix}
2&-1\\
3&1
\end{vmatrix}.
\]

分别算。

第一项：

\[
\begin{vmatrix}
-1&\lambda\\
1&-1
\end{vmatrix}
=
1-\lambda.
\]

第二项：

\[
\begin{vmatrix}
2&\lambda\\
3&-1
\end{vmatrix}
=
-2-3\lambda.
\]

第三项：

\[
\begin{vmatrix}
2&-1\\
3&1
\end{vmatrix}
=
2+3=5.
\]

所以：

\[
\begin{aligned}
\det A
&=
(1-\lambda)
-2(-2-3\lambda)
-2\cdot5\\
&=
1-\lambda+4+6\lambda-10\\
&=
5\lambda-5\\
&=
5(\lambda-1).
\end{aligned}
\]

由：

\[
\det A=0,
\]

得到：

\[
5(\lambda-1)=0.
\]

所以：

\[
\boxed{\lambda=1}.
\]

这与MD结论一致。fileciteturn33file0L777-L783

# 四、这题和例1.13是什么关系？

MD直接指出：

\[
\boxed{\text{这就是例1.13的抽象表达}}
\]

例1.13里题目是用语言说：

> \(B\) 的每一列都是某个齐次方程组的解。

而这道题直接把它压缩成：

\[
\boxed{AB=0}.
\]

所以以后看到：

\[
AB=0,\qquad B\ne0
\]

你就应该立刻想到：

\[
\boxed{
B\text{ 至少有一个非零列 }\beta
\Rightarrow
A\beta=0
\Rightarrow
Ax=0\text{ 有非零解}
\Rightarrow
\det A=0
}
\]

这里最重要的防错点还是：

\[
\boxed{B\ne0\neq \det B\ne0}
\]

前者只说明不是零矩阵，后者说明 \(B\) 可逆，强得多。
