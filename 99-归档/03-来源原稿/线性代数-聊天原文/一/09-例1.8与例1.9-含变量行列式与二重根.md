继续第一章“行列式”。现在进入一个很重要的新视角：

\[
\boxed{\text{含变量的行列式，本质上是一个函数}}
\]

如果各元素都是 \(x\) 的多项式，那么这个行列式本身也是关于 \(x\) 的多项式；但它的实际次数可能因为相消而降低，甚至可能恒等于0。你这份讲义接下来重点就是这一类。fileciteturn32file0L325-L329

# 一、先看例1.8：为什么两个行列式可以“只减一列”

## 题目

设

\[
f(x)=
\begin{vmatrix}
1&0&x\\
1&2&x^2\\
1&3&x^3
\end{vmatrix},
\]

求

\[
\boxed{f(x+1)-f(x)}.
\]

fileciteturn32file0L331-L341

很多人第一反应是：

> 先把 \(f(x+1)\) 算出来，再把 \(f(x)\) 算出来，最后相减。

当然能做，但这会很麻烦。

真正的题眼是：

\[
\boxed{\text{两个行列式只有第三列不同}}
\]

这时就可以利用行列式对“某一列”的线性性。

---

## 先写出 \(f(x+1)\)

\[
f(x+1)=
\begin{vmatrix}
1&0&x+1\\
1&2&(x+1)^2\\
1&3&(x+1)^3
\end{vmatrix}.
\]

而

\[
f(x)=
\begin{vmatrix}
1&0&x\\
1&2&x^2\\
1&3&x^3
\end{vmatrix}.
\]

前两列完全相同。

因此：

\[
f(x+1)-f(x)
\]

可以直接把第三列相减：

\[
=
\begin{vmatrix}
1&0&(x+1)-x\\
1&2&(x+1)^2-x^2\\
1&3&(x+1)^3-x^3
\end{vmatrix}.
\]

得到：

\[
\boxed{
f(x+1)-f(x)=
\begin{vmatrix}
1&0&1\\
1&2&2x+1\\
1&3&3x^2+3x+1
\end{vmatrix}
}
\]

。fileciteturn32file0L333-L341

---

# 二、为什么这里只能“一列作差”？

因为行列式对每一列分别具有线性性。

比如固定其他列：

\[
\det(C_1,C_2,U+V)
=
\det(C_1,C_2,U)
+
\det(C_1,C_2,V).
\]

所以反过来：

\[
\det(C_1,C_2,U)
-
\det(C_1,C_2,V)
=
\det(C_1,C_2,U-V).
\]

关键前提是：

\[
\boxed{\text{其他列完全一样}}
\]

所以这道题合法。

但一般情况下：

\[
\boxed{
\det A-\det B\ne\det(A-B)
}
\]

因为如果多列同时不同，就会出现各种交叉项。

这一点你的讲义也专门标成易错点。fileciteturn32file0L338-L343

# 三、接下来怎么把这个三阶行列式算得最快？

现在：

\[
D=
\begin{vmatrix}
1&0&1\\
1&2&2x+1\\
1&3&3x^2+3x+1
\end{vmatrix}.
\]

讲义采用：

\[
\boxed{
c_3\leftarrow c_3-c_1-xc_2
}
\]

我们逐项看为什么这么做。

第三列原来是：

\[
\begin{pmatrix}
1\\
2x+1\\
3x^2+3x+1
\end{pmatrix}.
\]

减第一列：

\[
\begin{pmatrix}
1\\
2x+1\\
3x^2+3x+1
\end{pmatrix}
-
\begin{pmatrix}
1\\
1\\
1
\end{pmatrix}
=
\begin{pmatrix}
0\\
2x\\
3x^2+3x
\end{pmatrix}.
\]

再减：

\[
x c_2
=
x
\begin{pmatrix}
0\\
2\\
3
\end{pmatrix}
=
\begin{pmatrix}
0\\
2x\\
3x
\end{pmatrix}.
\]

于是第三列变成：

\[
\begin{pmatrix}
0\\
0\\
3x^2
\end{pmatrix}.
\]

所以：

\[
D=
\begin{vmatrix}
1&0&0\\
1&2&0\\
1&3&3x^2
\end{vmatrix}.
\]

现在直接三角形：

\[
D=1\cdot2\cdot3x^2.
\]

因此：

\[
\boxed{
f(x+1)-f(x)=6x^2
}
\]

。fileciteturn32file0L338-L341

# 四、这道题真正要留下什么

不是答案 \(6x^2\)，而是：

\[
\boxed{
\text{两个行列式只有一行或一列不同}
\Rightarrow
\text{可以利用该行/列的线性性合并}
}
\]

比如：

\[
\begin{vmatrix}
C_1&C_2&U
\end{vmatrix}
-
\begin{vmatrix}
C_1&C_2&V
\end{vmatrix}
=
\begin{vmatrix}
C_1&C_2&U-V
\end{vmatrix}.
\]

但如果是：

\[
\det A-\det B
\]

而 \(A,B\) 有很多列都不同，则绝不能直接合并。

# 五、例1.9：二重根为什么要分两种来源？

现在进入含参数行列式里更重要的一类。

## 题目

方程

\[
\begin{vmatrix}
\lambda-1&-2&3\\
1&\lambda-4&3\\
-1&a&\lambda-5
\end{vmatrix}
=0
\]

有二重根，求 \(a\)。fileciteturn32file0L345-L364

这题不是普通的“算行列式”。

真正题眼是：

\[
\boxed{\text{行列式关于 }\lambda\text{ 是一个多项式}}
\]

而题目说：

\[
\boxed{\text{它有二重根}}
\]

所以我们的目标应该是：

\[
\boxed{\text{先把这个行列式因式分解}}
\]

---

## 第一步：先化行列式

讲义做：

\[
r_1\leftarrow r_1-r_2.
\]

第一行变成：

\[
(\lambda-2,\ 2-\lambda,\ 0).
\]

即：

\[
(\lambda-2,\ -(\lambda-2),\ 0).
\]

于是第一行已经出现公共结构。

再做：

\[
c_2\leftarrow c_2+c_1.
\]

经过化简，沿第一行展开后得到：

\[
\boxed{
(\lambda-2)
(\lambda^2-8\lambda+18-3a)
=0
}
\]

。fileciteturn32file0L355-L358

现在真正的问题来了。

---

# 六、“有二重根”为什么有两种可能？

现在多项式是：

\[
p(\lambda)
=
(\lambda-2)
(\lambda^2-8\lambda+18-3a).
\]

要出现二重根，有两种完全不同的来源。

## 情况1：两个因子有公共根

第一个因子的根是：

\[
\lambda=2.
\]

如果二次因子在 \(\lambda=2\) 时也等于0，那么：

\[
\lambda=2
\]

就会同时来自两个因子，于是成为二重根。

代入二次因子：

\[
2^2-8\cdot2+18-3a=0.
\]

即：

\[
4-16+18-3a=0.
\]

所以：

\[
6-3a=0.
\]

得到：

\[
\boxed{a=2}.
\]

这时二次因子另一个根是6，因此 \(\lambda=2\) 确实是二重根。fileciteturn32file0L361-L362

---

## 情况2：二次因子自己产生重根

即：

\[
\lambda^2-8\lambda+18-3a
\]

本身有二重根。

二次方程有重根的条件：

\[
\boxed{\Delta=0}.
\]

所以：

\[
(-8)^2
-
4(18-3a)=0.
\]

即：

\[
64-72+12a=0.
\]

所以：

\[
12a=8.
\]

得到：

\[
\boxed{a=\frac23}.
\]

此时二次因子的重根是：

\[
\lambda=4,
\]

和前面的根2不同，因此确实得到一个二重根。fileciteturn32file0L361-L364

最终：

\[
\boxed{
a=2
\quad\text{或}\quad
a=\frac23
}
\]

---

# 七、为什么这题很容易漏一个答案？

因为很多人一看到“二重根”，就只想到：

\[
\boxed{\Delta=0}
\]

于是只能得到：

\[
a=\frac23.
\]

但如果多项式已经分解成：

\[
p(\lambda)=f(\lambda)g(\lambda),
\]

重根还可能来自：

\[
\boxed{f,g\text{ 有公共根}}
\]

所以以后凡是：

\[
\boxed{\text{乘积形式 + 二重根}}
\]

都要检查两件事：

1. 不同因子是否有公共根；
2. 某个因子内部是否自己出现重根。

你的讲义也明确把这一题概括成“二重根有两种来源”。fileciteturn32file0L345-L364

---

# 八、含变量行列式这一块的核心框架

你现在先建立三个反应。

看到：

\[
D(x)
\]

先想：

\[
\boxed{\text{这是关于 }x\text{ 的函数}}
\]

如果元素都是多项式，则：

\[
\boxed{D(x)\text{也是多项式}}
\]

但不要仅凭“\(n\) 阶”就断言它一定是 \(n\) 次，多项式次数可能因为行列关系相消而降低。fileciteturn32file0L325-L329

看到：

\[
f(x+1)-f(x)
\]

这类两个行列式时，先检查：

\[
\boxed{\text{是不是只有一列/一行不同}}
\]

如果是，可以直接在线性位置上作差。

看到：

\[
\boxed{\text{有二重根}}
\]

且已经因式分解，就检查：

\[
\boxed{
\text{公共根}
\quad+\quad
\text{单个因子内部重根}
}
\]

下一步按照讲义继续，就是一个非常适合考场提速的例子：先判断一个复杂行列式是否恒等于0，再去处理另一个，而不是两个都硬展开；然后正式进入**抽象行列式与列向量线性组合**。
