继续第一章“行列式”。现在进入你讲义里的 **视频例2.1**。这一题是在刚才“余子式反向展开”的基础上，再往前走一步：

\[
\boxed{\text{原行列式与一个“替换行后的行列式”只差一行}}
\]

所以可以直接利用行列式对某一行的线性性，把两个行列式作差。fileciteturn32file0L490-L506

# 一、先看完整题目

已知

\[
A=
\begin{pmatrix}
2&1&0&-1\\
-1&2&-5&3\\
3&0&a&b\\
1&-3&5&0
\end{pmatrix},
\]

并且满足

\[
\boxed{
\det A=A_{41}-A_{42}+A_{43}+10
}
\]

求 \(a\)。fileciteturn32file0L492-L499

这题第一眼不要急着算 \(\det A\)。

真正的题眼是：

\[
A_{41}-A_{42}+A_{43}
\]

这一串全部都是：

\[
\boxed{\text{第4行的代数余子式}}
\]

所以先反向展开。

---

# 二、先把余子式组合变成一个完整行列式

原式：

\[
A_{41}-A_{42}+A_{43}.
\]

可以写成：

\[
1\cdot A_{41}
+(-1)\cdot A_{42}
+1\cdot A_{43}
+0\cdot A_{44}.
\]

所以根据上一部分的结论：

\[
A_{41}-A_{42}+A_{43}
\]

就等于把原矩阵第4行：

\[
(1,-3,5,0)
\]

替换成：

\[
\boxed{(1,-1,1,0)}
\]

之后得到的行列式。

因此：

\[
A_{41}-A_{42}+A_{43}
=
\begin{vmatrix}
2&1&0&-1\\
-1&2&-5&3\\
3&0&a&b\\
1&-1&1&0
\end{vmatrix}.
\]

所以题目条件变成：

\[
\begin{vmatrix}
2&1&0&-1\\
-1&2&-5&3\\
3&0&a&b\\
1&-3&5&0
\end{vmatrix}
=
\begin{vmatrix}
2&1&0&-1\\
-1&2&-5&3\\
3&0&a&b\\
1&-1&1&0
\end{vmatrix}
+10.
\]

这就是这道题最关键的转化。fileciteturn32file0L499-L503

---

# 三、为什么两个行列式可以直接“减第4行”？

把10移到左边：

\[
10=
\det A
-
\det A'.
\]

注意这两个行列式：

- 前3行完全一样；
- 只有第4行不同。

所以可以利用行列式对第4行的线性性：

\[
\det(R_1,R_2,R_3,U)
-
\det(R_1,R_2,R_3,V)
\]

等于：

\[
\boxed{
\det(R_1,R_2,R_3,U-V)
}
\]

因此第4行直接作差：

\[
(1,-3,5,0)-(1,-1,1,0)
\]

得到：

\[
\boxed{(0,-2,4,0)}.
\]

所以：

\[
\boxed{
10=
\begin{vmatrix}
2&1&0&-1\\
-1&2&-5&3\\
3&0&a&b\\
0&-2&4&0
\end{vmatrix}
}
\]

。fileciteturn32file0L499-L506

这一步和前面 \(f(x+1)-f(x)\) 那题其实是同一个原理：

\[
\boxed{\text{只有一行不同，才能直接把这一行作差}}
\]

---

# 四、现在这个新行列式怎么计算？

我们有：

\[
D=
\begin{vmatrix}
2&1&0&-1\\
-1&2&-5&3\\
3&0&a&b\\
0&-2&4&0
\end{vmatrix}.
\]

第四行：

\[
(0,-2,4,0)
\]

只有两个非零元素。

所以沿第4行展开最合适。

得到：

\[
D=(-2)A_{42}+4A_{43}.
\]

注意这里的 \(A_{42},A_{43}\) 是**这个新行列式对应的代数余子式**。

---

## 第一项

位置：

\[
(4,2)
\]

符号：

\[
(-1)^{4+2}=+1.
\]

所以：

\[
A_{42}
=
\begin{vmatrix}
2&0&-1\\
-1&-5&3\\
3&a&b
\end{vmatrix}.
\]

计算：

\[
\begin{aligned}
A_{42}
&=
2
\begin{vmatrix}
-5&3\\
a&b
\end{vmatrix}
+(-1)
\begin{vmatrix}
-1&-5\\
3&a
\end{vmatrix}\\
&=
2(-5b-3a)
-\bigl(-a+15\bigr)\\
&=
-10b-6a+a-15\\
&=
\boxed{-5a-10b-15}.
\end{aligned}
\]

---

## 第二项

位置：

\[
(4,3)
\]

代数余子式符号：

\[
(-1)^{4+3}=-1.
\]

先算余子式：

\[
M_{43}
=
\begin{vmatrix}
2&1&-1\\
-1&2&3\\
3&0&b
\end{vmatrix}.
\]

计算：

\[
M_{43}=5b+15.
\]

所以：

\[
A_{43}
=
-(5b+15).
\]

于是：

\[
\begin{aligned}
D
&=
(-2)(-5a-10b-15)
+
4[-(5b+15)]\\
&=
10a+20b+30-20b-60\\
&=
10a-30.
\end{aligned}
\]

因此：

\[
\boxed{
D=10(a-3)
}
\]

讲义也正是得到这个结果。fileciteturn32file0L502-L506

---

# 五、现在回到原条件

前面已经有：

\[
10=D.
\]

所以：

\[
10=10(a-3).
\]

两边除以10：

\[
1=a-3.
\]

于是：

\[
\boxed{a=4}.
\]

这就是最终答案。fileciteturn32file0L499-L506

---

# 六、为什么最后 \(b\) 自动消掉了？

你在中间可能注意到：

\[
A_{42}
\]

和

\[
A_{43}
\]

里都有 \(b\)。

但是最后：

\[
20b-20b=0.
\]

所以：

\[
\boxed{\text{这个条件并不限制 }b}
\]

讲义也明确指出，这个关系只确定 \(a\)，不限制 \(b\)。fileciteturn32file0L503-L506

这也说明一个很重要的做题习惯：

> 题目问 \(a\)，不代表你必须先把 \(b\) 求出来。

有些参数会在结构运算中自动消掉。

---

# 七、这道题你要留下的完整模板

以后看到：

\[
\det A
=
k_1A_{i1}
+k_2A_{i2}
+\cdots
+k_nA_{in}
+c
\]

先做：

\[
\boxed{
k_1A_{i1}+\cdots+k_nA_{in}
\Rightarrow
\text{替换第 }i\text{ 行}
}
\]

然后原题会变成：

\[
\boxed{
\text{原行列式}
-
\text{替换行后的行列式}
=
c
}
\]

由于这两个行列式只有一行不同：

\[
\boxed{\text{直接把这一行作差}}
\]

最终只需要算一个行列式。

所以整条路线是：

\[
\boxed{
\text{余子式反向展开}
\rightarrow
\text{两个行列式作差}
\rightarrow
\text{只差一行}
\rightarrow
\text{行作差}
\rightarrow
\text{制造零后展开}
}
\]

这就是这一题最值得掌握的结构。

下一步按照你的讲义顺序，就是 **全部代数余子式之和**。这时不再只是一行的 \(A_{ij}\)，而可能是：

\[
\sum_{i,j}A_{ij}.
\]

讲义会把它和伴随矩阵联系起来，写成：

\[
\boxed{
\mathbf1^TA^*\mathbf1
}
\]

然后利用：

\[
A^*=\det A\,A^{-1}
\]

把“逐个算余子式”的大工程，转成“求逆矩阵元素和”。
