# 一、先用一个具体方程组理解克拉默法则

看MD里的例子：

\[
\begin{cases}
x_1+x_2=3,\\
2x_1-x_2=0.
\end{cases}
\]

先写成矩阵形式：

\[
\begin{pmatrix}
1&1\\
2&-1
\end{pmatrix}
\begin{pmatrix}
x_1\\
x_2
\end{pmatrix}
=
\begin{pmatrix}
3\\
0
\end{pmatrix}.
\]

所以系数矩阵：

\[
A=
\begin{pmatrix}
1&1\\
2&-1
\end{pmatrix}.
\]

第一件事不是算 \(x_1,x_2\)，而是先算：

\[
D=\det A
=
\begin{vmatrix}
1&1\\
2&-1
\end{vmatrix}.
\]

得到：

\[
D=-1-2=-3.
\]

所以：

\[
\boxed{D=-3\ne0}
\]

这一步非常关键。

它告诉我们：

\[
\boxed{\text{这个方程组有唯一解，而且可以使用克拉默法则}}
\]

---

# 二、\(D_1,D_2\) 到底是怎么来的？

克拉默法则说：

\[
\boxed{
x_i=\frac{D_i}{D}
}
\]

其中 \(D_i\) 的构造规则非常死：

\[
\boxed{
\text{求哪个未知量，就把系数矩阵的第几列换成常数列}
}
\]

注意是：

\[
\boxed{\text{换列，不是换行}}
\]

---

## 求 \(x_1\)

原系数矩阵：

\[
A=
\begin{pmatrix}
1&1\\
2&-1
\end{pmatrix}.
\]

常数列：

\[
b=
\begin{pmatrix}
3\\
0
\end{pmatrix}.
\]

求 \(x_1\)，把**第一列**换成 \(b\)：

\[
D_1=
\begin{vmatrix}
3&1\\
0&-1
\end{vmatrix}.
\]

所以：

\[
D_1=-3.
\]

于是：

\[
x_1=\frac{D_1}{D}
=
\frac{-3}{-3}
=
\boxed{1}.
\]

---

## 求 \(x_2\)

把第二列换成常数列：

\[
D_2=
\begin{vmatrix}
1&3\\
2&0
\end{vmatrix}.
\]

所以：

\[
D_2=1\cdot0-3\cdot2=-6.
\]

因此：

\[
x_2=\frac{D_2}{D}
=
\frac{-6}{-3}
=
\boxed{2}.
\]

所以最终：

\[
\boxed{x_1=1,\qquad x_2=2}
\]

这就是MD里给出的完整克拉默法则例子。fileciteturn33file0L551-L587

---

# 三、现在抽象成一般公式

假设有 \(n\) 个方程、\(n\) 个未知量：

\[
Ax=b.
\]

令：

\[
D=\det A.
\]

如果：

\[
\boxed{D\ne0}
\]

那么：

\[
\boxed{\text{方程组有唯一解}}
\]

而且：

\[
\boxed{
x_i=\frac{D_i}{D}
}
\]

其中 \(D_i\) 就是：

\[
\boxed{
\text{把 }A\text{ 的第 }i\text{ 列替换成 }b
}
\]

得到的行列式。fileciteturn33file0L536-L550

---

# 四、为什么我说“条件比公式重要”？

因为很多选择题最喜欢问你：

> \(D=0\) 的时候怎么办？

这时候一定不能写：

\[
x_i=\frac{D_i}{D}.
\]

因为分母已经是：

\[
D=0.
\]

克拉默法则的比值公式直接失效。

但：

\[
D=0
\]

到底意味着什么？

对于**非齐次方程组**

\[
Ax=b,
\]

只能说：

\[
\boxed{\text{不再保证唯一解}}
\]

它有两种可能：

\[
\boxed{\text{无解}}
\]

或者：

\[
\boxed{\text{无穷多解}}
\]

不能只靠 \(D=0\) 判断是哪一种。MD明确强调了这一点。fileciteturn33file0L536-L550

---

# 五、一个非常容易掉进去的坑

MD专门给了一个反例。

设：

\[
A=
\begin{pmatrix}
1&0&0\\
0&0&0\\
0&0&0
\end{pmatrix},
\qquad
b=
\begin{pmatrix}
0\\
1\\
0
\end{pmatrix}.
\]

很明显：

\[
D=\det A=0.
\]

再分别把第1、2、3列换成 \(b\)，会发现：

\[
D_1=D_2=D_3=0.
\]

于是有人会错误地说：

> \(D=D_1=D_2=D_3=0\)，所以有无穷多解。

这是错的。

因为这个方程组实际是：

\[
\begin{cases}
x_1=0,\\
0=1,\\
0=0.
\end{cases}
\]

第二个方程：

\[
\boxed{0=1}
\]

根本不可能成立。

所以这个方程组其实：

\[
\boxed{\text{无解}}
\]

。fileciteturn33file0L588-L610

因此一定记住：

\[
\boxed{
D=D_1=\cdots=D_n=0
}
\]

也**不能仅凭这个条件**断言“无穷多解”。

MD把正确结论整理成：

\[
\boxed{
\begin{array}{c|c}
\text{条件}&\text{结论}\\
\hline
D\ne0&\text{唯一解，可用克拉默法则}\\
D=0&\text{可能无解，也可能无穷多解}\\
D=D_1=\cdots=D_n=0&\text{仍不足以判断是否有解}
\end{array}
}
\]

更完整的判断要等后面“线性方程组”章节学：

\[
r(A)\quad\text{与}\quad r(A,b).
\]

这里第一讲只要求先知道这个边界。fileciteturn33file0L588-L610

---

# 六、齐次方程组是另一回事

这个地方特别重要。

如果变成：

\[
Ax=0,
\]

也就是齐次方程组，那么情况就非常干净。

因为齐次方程永远至少有：

\[
\boxed{x=0}
\]

这个零解。

所以我们真正关心的是：

\[
\boxed{\text{有没有非零解}}
\]

对于方阵 \(A\)：

\[
\boxed{
\det A\ne0
\iff
\text{只有零解}
}
\]

以及：

\[
\boxed{
\det A=0
\iff
\text{存在非零解}
}
\]

这是第一讲后面很多题真正要用的结论。fileciteturn33file0L544-L550

---

## 为什么？

先看：

\[
\det A\ne0.
\]

这说明 \(A\) 可逆。

方程：

\[
Ax=0.
\]

两边左乘：

\[
A^{-1}.
\]

得到：

\[
x=0.
\]

所以只有零解。

反过来，如果：

\[
\det A=0,
\]

\(A\) 不可逆。

对于方阵齐次方程组，就会存在非零解。

所以在考研题里，一看到：

> “齐次线性方程组存在非零解”

你的第一反应应该直接翻译成：

\[
\boxed{\det A=0}
\]

这会是下一道 **例1.13** 的核心题眼。

---

# 七、考研拿到题时怎么判断？

以后看到方程组，可以先分成两类。

如果是：

\[
Ax=b,\qquad b\ne0,
\]

属于**非齐次**。

先看：

\[
\det A.
\]

若：

\[
\det A\ne0,
\]

唯一解，可以用克拉默。

若：

\[
\det A=0,
\]

先停止使用克拉默公式，不能直接判断无解还是无穷多解。

而如果是：

\[
Ax=0,
\]

属于**齐次**。

那么直接记：

\[
\boxed{
\begin{aligned}
\det A\ne0&\Longleftrightarrow\text{只有零解},\\
\det A=0&\Longleftrightarrow\text{存在非零解}.
\end{aligned}
}
\]

这两句话是本节真正比

\[
x_i=\frac{D_i}{D}
\]

更重要的东西。

下一步严格按照MD，就是 **例1.13：从“非零矩阵 \(B\)”中找出齐次方程的非零解**。那道题会第一次把

\[
\boxed{B\ne0}
\]

翻译成

\[
\boxed{\text{\(B\) 至少有一列是非零解}}
\]

然后利用

\[
\det A=0
\]

求出参数 \(\lambda\)，最后再证明

\[
\boxed{\det B=0}.
\]
