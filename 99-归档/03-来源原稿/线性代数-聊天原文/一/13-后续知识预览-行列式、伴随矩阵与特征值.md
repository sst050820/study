# 一、例1.7：已知 \(A^*\) 的特征值，怎么反推出 \(A\)？

题目给的是四阶矩阵 \(A\)，已知它的伴随矩阵 \(A^*\) 的特征值为

\[
1,\,-1,\,-2,\,4.
\]

先看第一步：特征值的乘积等于行列式，所以

\[
\det A^*=1\cdot(-1)\cdot(-2)\cdot4=8.
\]

而对四阶矩阵，

\[
\boxed{\det A^*=(\det A)^3}.
\]

因此

\[
(\det A)^3=8,
\]

得到

\[
\boxed{\det A=2}.
\]

于是 \(A\) 可逆，并且：

\[
\boxed{
A^*=\det A\,A^{-1}=2A^{-1}
}
\]

。fileciteturn32file0L445-L453

---

## 怎么从 \(A^*\) 的特征值变成 \(A\) 的特征值？

假设 \(A\) 的一个特征值是 \(\lambda\)。

那么 \(A^{-1}\) 对应的特征值就是：

\[
\frac1\lambda.
\]

而：

\[
A^*=2A^{-1},
\]

所以 \(A^*\) 对应的特征值就是：

\[
\frac2\lambda.
\]

因此：

\[
\boxed{
\mu=\frac2\lambda
}
\]

其中 \(\mu\) 是 \(A^*\) 的特征值。

反过来：

\[
\boxed{
\lambda=\frac2\mu
}
\]

所以分别计算：

\[
\mu=1
\Rightarrow
\lambda=2,
\]

\[
\mu=-1
\Rightarrow
\lambda=-2,
\]

\[
\mu=-2
\Rightarrow
\lambda=-1,
\]

\[
\mu=4
\Rightarrow
\lambda=\frac12.
\]

所以 \(A\) 的特征值为：

\[
\boxed{
2,\,-2,\,-1,\frac12
}
\]

。fileciteturn32file0L445-L453

# 二、为什么 \(\det p(A)\) 可以直接用特征值算？

讲义接着令：

\[
p(t)=t^3+2t^2-t-3.
\]

要求：

\[
\det p(A).
\]

这里先把：

\[
p(A)=A^3+2A^2-A-3I
\]

看成一个新的矩阵。

如果 \(A\) 的特征值是：

\[
\lambda_1,\lambda_2,\lambda_3,\lambda_4,
\]

那么 \(p(A)\) 对应的特征值就是：

\[
p(\lambda_1),p(\lambda_2),p(\lambda_3),p(\lambda_4).
\]

因此：

\[
\boxed{
\det p(A)
=
\prod_{i=1}^4p(\lambda_i)
}
\]

讲义直接代：

\[
p(2)=11,
\]

\[
p(-2)=-1,
\]

\[
p(-1)=-1,
\]

\[
p\left(\frac12\right)=-\frac{23}{8}.
\]

所以：

\[
\begin{aligned}
\det p(A)
&=
11\cdot(-1)\cdot(-1)\cdot
\left(-\frac{23}{8}\right)\\
&=
\boxed{-\frac{253}{8}}.
\end{aligned}
\]

fileciteturn32file0L447-L455

这一题你现在不用深入证明“为什么矩阵多项式会这样改变特征值”，因为这是后面特征值章节的内容。

当前只要建立这个连接：

\[
\boxed{
A\text{ 的特征值 }\lambda
\Longrightarrow
p(A)\text{ 的对应特征值 }p(\lambda)
}
\]

于是行列式就是这些特征值的乘积。

# 三、例1.8：主对角相同、非对角也相同

讲义还有一个预览题。

矩阵主对角线全部是：

\[
k,
\]

其余元素全部是：

\[
ka,
\]

其中：

\[
k>0,\qquad0<a<1.
\]

也就是：

\[
A=
\begin{pmatrix}
k&ka&\cdots&ka\\
ka&k&\cdots&ka\\
\vdots&\vdots&\ddots&\vdots\\
ka&ka&\cdots&k
\end{pmatrix}.
\]

把 \(k\) 提出来：

\[
A=
k
\begin{pmatrix}
1&a&\cdots&a\\
a&1&\cdots&a\\
\vdots&\vdots&\ddots&\vdots\\
a&a&\cdots&1
\end{pmatrix}.
\]

还可以写成：

\[
\boxed{
A=k[(1-a)I+a\mathbf1\mathbf1^T]
}
\]

其中：

\[
\mathbf1=
\begin{pmatrix}
1\\1\\\vdots\\1
\end{pmatrix}.
\]

fileciteturn32file0L456-L458

---

## 先看最特殊的向量 \(\mathbf1\)

因为每一行的元素和都是：

\[
k[1+(n-1)a].
\]

所以：

\[
A\mathbf1
=
k[1+(n-1)a]\mathbf1.
\]

因此：

\[
\boxed{
\lambda_1=k[1+(n-1)a]
}
\]

是一个特征值。

这和你前面学过的“每行和相同”其实已经产生联系了。

---

## 其他方向的特征值

如果一个向量 \(x\) 满足：

\[
\mathbf1^Tx=0,
\]

也就是分量和为0，那么：

\[
\mathbf1\mathbf1^Tx=0.
\]

所以：

\[
Ax
=
k(1-a)x.
\]

于是：

\[
\boxed{
\lambda_2=k(1-a)
}
\]

并且这种方向一共有 \(n-1\) 个独立方向，因此这个特征值重复 \(n-1\) 次。fileciteturn32file0L456-L458

所以这类矩阵的特征值结构是：

\[
\boxed{
\begin{cases}
k[1+(n-1)a],&1\text{ 个}\\
k(1-a),&n-1\text{ 个}
\end{cases}
}
\]

这个结果你现在以“认识结构”为主，后面第五章特征值时我们再系统解释。

---

## 这一小段现在掌握到什么程度就够了？

讲义本身的要求就是：

\[
\boxed{\text{认识矩阵多项式、伴随矩阵与行列式之间的连接}}
\]

而不是现在就把特征值理论全部学完。fileciteturn32file0L445-L458

你现在留下三条连接：

\[
\boxed{
\det A=\lambda_1\lambda_2\cdots\lambda_n
}
\]

\[
\boxed{
A^*=\det A\,A^{-1}\qquad(\det A\ne0)
}
\]

以及：

\[
\boxed{
\lambda\text{ 是 }A\text{ 的特征值}
\Rightarrow
p(\lambda)\text{ 是 }p(A)\text{ 的对应特征值}
}
\]

下一步就回到第一章真正的重点内容：

\[
\boxed{\text{余子式组合与反向展开}}
\]

也就是看到

\[
k_1A_{i1}+k_2A_{i2}+\cdots+k_nA_{in}
\]

时，不要一个个去算余子式，而是直接把它变成：

\[
\boxed{\text{“替换第 }i\text{ 行后的一个完整行列式”}}
\]

这会是第一章非常典型的考研题型。
