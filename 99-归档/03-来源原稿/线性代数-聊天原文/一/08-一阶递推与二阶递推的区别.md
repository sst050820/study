\[
\boxed{\text{两种递推不要混用}}
\]

重点不是多记两个公式，而是学会判断：

\[
\boxed{\text{展开以后，究竟留下几个“同类型的低阶行列式”}}

# 一、第一种：只留下一个同类行列式 → 一阶递推

先看讲义里的第一类：

\[
D_n=
\begin{vmatrix}
b&-1&0&\cdots&0\\
0&b&-1&\cdots&0\\
\vdots&&\ddots&\ddots&\vdots\\
0&\cdots&0&b&-1\\
a_n&a_{n-1}&\cdots&a_2&b+a_1
\end{vmatrix}.
\]

fileciteturn32file0L295-L310

先不要急着套公式。

看第一列：

\[
\begin{pmatrix}
b\\
0\\
\vdots\\
0\\
a_n
\end{pmatrix}
\]

只有两个非零元素。

所以：

\[
\boxed{\text{沿第一列展开}}
\]

是最自然的。

---

## 第一项：为什么是 \(bD_{n-1}\)？

第一列第一行元素是：

\[
b.
\]

删掉第一行、第一列以后，剩下的结构还是同一种：

\[
\begin{vmatrix}
b&-1&\cdots&0\\
0&b&\ddots&\vdots\\
\vdots&\ddots&\ddots&-1\\
a_{n-1}&\cdots&a_2&b+a_1
\end{vmatrix}.
\]

这就是：

\[
D_{n-1}.
\]

所以第一部分是：

\[
\boxed{bD_{n-1}}
\]

---

# 二、第二项：为什么最后直接变成 \(+a_n\)？

第一列最后一个元素是：

\[
a_n.
\]

它的位置是：

\[
(n,1).
\]

代数余子式符号：

\[
(-1)^{n+1}.
\]

删掉第 \(n\) 行、第1列以后，剩下的是：

\[
\begin{vmatrix}
-1&0&\cdots&0\\
b&-1&\cdots&0\\
0&b&\ddots&\vdots\\
\vdots&\ddots&\ddots&-1
\end{vmatrix}.
\]

这是一个下三角行列式。

主对角线全部是：

\[
-1.
\]

一共有：

\[
n-1
\]

个。

所以这个余子式等于：

\[
(-1)^{n-1}.
\]

因此这一项整体是：

\[
a_n
(-1)^{n+1}
(-1)^{n-1}.
\]

指数相加：

\[
(n+1)+(n-1)=2n.
\]

所以：

\[
(-1)^{2n}=1.
\]

于是第二项直接变成：

\[
\boxed{a_n}
\]

所以递推式：

\[
\boxed{
D_n=bD_{n-1}+a_n
}
\]

。fileciteturn32file0L307-L313

---

# 三、为什么它叫“一阶递推”？

因为：

\[
D_n
\]

只和：

\[
D_{n-1}
\]

有关。

也就是：

\[
\boxed{
D_n=bD_{n-1}+a_n
}
\]

这里没有：

\[
D_{n-2}.
\]

所以称为一阶递推。

初值：

\[
D_1=b+a_1.
\]

---

## 顺着递推算几次，你就能看到通式

先算：

\[
D_1=b+a_1.
\]

再：

\[
D_2=bD_1+a_2.
\]

所以：

\[
D_2
=
b(b+a_1)+a_2.
\]

即：

\[
D_2=b^2+a_1b+a_2.
\]

再算：

\[
D_3=bD_2+a_3.
\]

代入：

\[
D_3
=
b(b^2+a_1b+a_2)+a_3.
\]

得到：

\[
D_3
=
b^3+a_1b^2+a_2b+a_3.
\]

规律已经很明显：

\[
\boxed{
D_n
=
b^n
+a_1b^{n-1}
+a_2b^{n-2}
+\cdots
+a_{n-1}b
+a_n
}
\]

这就是讲义给出的结果。fileciteturn32file0L307-L313

---

# 四、第二种：展开后留下两个同类行列式 → 二阶递推

现在看第二个例子。

三对角行列式：

\[
D_n=
\begin{vmatrix}
2a&1&0&\cdots&0\\
a^2&2a&1&\ddots&\vdots\\
0&a^2&2a&\ddots&0\\
\vdots&\ddots&\ddots&\ddots&1\\
0&\cdots&0&a^2&2a
\end{vmatrix}.
\]

讲义给出的递推是：

\[
\boxed{
D_n
=
2aD_{n-1}
-a^2D_{n-2}
}
\]

初值：

\[
D_0=1,\qquad D_1=2a.
\]

fileciteturn32file0L314-L321

这个其实就是我们上一部分讲过的三对角一般公式：

\[
D_n=kD_{n-1}-bcD_{n-2}.
\]

这里：

\[
k=2a,
\]

\[
b=1,
\]

\[
c=a^2.
\]

所以：

\[
D_n
=
2aD_{n-1}
-(1)(a^2)D_{n-2}.
\]

因此：

\[
\boxed{
D_n=2aD_{n-1}-a^2D_{n-2}
}
\]

---

# 五、先算几项，不要急着背通式

先有：

\[
D_0=1,
\]

\[
D_1=2a.
\]

算：

\[
D_2
=
2aD_1-a^2D_0.
\]

代入：

\[
D_2
=
2a(2a)-a^2.
\]

所以：

\[
\boxed{
D_2=3a^2
}
\]

再算：

\[
D_3
=
2aD_2-a^2D_1.
\]

代入：

\[
=
2a(3a^2)-a^2(2a).
\]

所以：

\[
=
6a^3-2a^3.
\]

得到：

\[
\boxed{
D_3=4a^3
}
\]

再看：

\[
D_1=2a,
\]

\[
D_2=3a^2,
\]

\[
D_3=4a^3.
\]

很明显会猜：

\[
\boxed{
D_n=(n+1)a^n
}
\]

这正是讲义结论。fileciteturn32file0L314-L321

---

# 六、这个通式怎么证明？

如果只是“看规律”，还不够严谨。

我们用归纳法。

假设：

\[
D_{n-1}=na^{n-1},
\]

\[
D_{n-2}=(n-1)a^{n-2}.
\]

代入递推：

\[
D_n
=
2aD_{n-1}
-a^2D_{n-2}.
\]

所以：

\[
D_n
=
2a\cdot na^{n-1}
-
a^2\cdot(n-1)a^{n-2}.
\]

第一项：

\[
2na^n.
\]

第二项：

\[
(n-1)a^n.
\]

所以：

\[
D_n
=
[2n-(n-1)]a^n.
\]

括号：

\[
2n-n+1=n+1.
\]

因此：

\[
\boxed{
D_n=(n+1)a^n
}
\]

成立。

讲义也专门给出了这个归纳验证。fileciteturn32file0L317-L323

---

# 七、这两种递推到底怎么区分？

把它们摆在一起看。

第一种：

\[
D_n=bD_{n-1}+a_n.
\]

第二种：

\[
D_n=2aD_{n-1}-a^2D_{n-2}.
\]

本质区别不是“公式长得不一样”，而是：

第一类展开以后：

\[
\boxed{\text{只留下一个同类低阶行列式}}
\]

所以自然得到：

\[
D_n\leftrightarrow D_{n-1}.
\]

第二类展开以后：

\[
\boxed{\text{留下两个不同阶数的同类行列式}}
\]

所以自然出现：

\[
D_{n-1}
\]

和

\[
D_{n-2}.
\]

因此你讲义最后把判断方法总结得非常好：

\[
\boxed{
\text{先看展开后剩几个同类行列式，再决定是一阶还是二阶递推}
}
\]

而且：

\[
\boxed{\text{初值不能漏，末项符号不能错}}
\]

。fileciteturn32file0L321-L323

# 八、考场上的识别流程

以后看到规律型高阶行列式，不要第一反应就是“我有没有背过这个公式”。

应该按：

\[
\boxed{
\text{先找零最多的首行/末行/首列/末列}
}
\]

然后展开一次。

接着问：

\[
\boxed{
\text{余子式是不是和原题同结构？}
}
\]

如果是，再看：

\[
\boxed{
\text{出现一个同结构低阶式，还是两个？}
}
\]

于是：

- 一个 → 一阶递推；
- 两个 → 二阶递推。

这比死背很多“特殊行列式公式”可靠得多。

---

下一步按照你的讲义顺序，就进入 **含变量的行列式**。

重点会从“怎么计算行列式”转向：

\[
\boxed{\text{把行列式看成关于 }x\text{ 的函数或多项式}}
\]

首先讲 **例1.8**：

\[
f(x)=
\begin{vmatrix}
1&0&x\\
1&2&x^2\\
1&3&x^3
\end{vmatrix}
\]

求：

\[
f(x+1)-f(x).
\]

这道题最值得学的是：为什么两个行列式只有**一列不同**时，可以直接把那一列作差；但一般情况下绝不能写

\[
\det A-\det B=\det(A-B).
\]
