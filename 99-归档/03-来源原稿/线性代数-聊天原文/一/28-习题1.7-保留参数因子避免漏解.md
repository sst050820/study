\boxed{\text{习题1.7：先提出参数，不要除掉参数}}

题目是：

\[
\begin{vmatrix}
\lambda&2&2\\
-2&\lambda-2&2\\
2&2&\lambda-2
\end{vmatrix}=0.

MD的核心提醒是：

\[
\boxed{\text{保留所有参数因子，不能为了化简随便约掉}}
\]

因为一旦把可能为0的参数约掉，就可能漏解。fileciteturn33file0L729-L742

D=

这一步的符号还是：

# 二、分别算三个二阶行列式

第一个：

\[
\begin{vmatrix}
\lambda-2&2\\
2&\lambda-2
\end{vmatrix}
=
(\lambda-2)^2-4.
\]

所以第一部分是：

\[
\lambda[(\lambda-2)^2-4].
\]

第二个：

\[
\begin{vmatrix}
-2&2\\
2&\lambda-2
\end{vmatrix}
=
-2(\lambda-2)-4.
\]

所以第二部分：

\[
-2[-2(\lambda-2)-4].
\]

第三个：

\[
\begin{vmatrix}
-2&\lambda-2\\
2&2
\end{vmatrix}
=
-4-2(\lambda-2).
\]

所以第三部分：

\[
2[-4-2(\lambda-2)].
\]

因此：

\[
\boxed{
D=
\lambda[(\lambda-2)^2-4]
-2[-2(\lambda-2)-4]
+2[-4-2(\lambda-2)]
}
\]

这就是MD中的展开式。fileciteturn33file0L735-L741

# 三、化简时注意参数因子

先看第一项：

\[
(\lambda-2)^2-4
\]

这是平方差：

\[
[(\lambda-2)-2][(\lambda-2)+2].
\]

所以：

\[
=(\lambda-4)\lambda.
\]

因此第一项：

\[
\lambda\cdot\lambda(\lambda-4)
=
\lambda^2(\lambda-4).
\]

再看后面两项。

第二项括号：

\[
-2(\lambda-2)-4
=
-2\lambda+4-4
=
-2\lambda.
\]

所以：

\[
-2(-2\lambda)=4\lambda.
\]

第三项括号：

\[
-4-2(\lambda-2)
=
-4-2\lambda+4
=
-2\lambda.
\]

所以：

\[
2(-2\lambda)=-4\lambda.
\]

这两项正好相消：

\[
4\lambda-4\lambda=0.
\]

所以：

\[
\boxed{
D=\lambda^2(\lambda-4)
}
\]

。fileciteturn33file0L735-L741

# 四、令行列式等于0

题目要求：

\[
D=0.
\]

所以：

\[
\lambda^2(\lambda-4)=0.
\]

于是：

\[
\lambda^2=0
\]

或者：

\[
\lambda-4=0.
\]

因此：

\[
\boxed{\lambda=0\text{ 或 }4}.
\]

与MD一致。fileciteturn33file0L742-L742

# 五、这题最重要的防错点

如果你中途看到：

\[
\lambda^2(\lambda-4)=0
\]

然后两边“除以 \(\lambda^2\)”：

\[
\lambda-4=0,
\]

就只会得到：

\[
\lambda=4.
\]

这样会直接漏掉：

\[
\boxed{\lambda=0}.
\]

为什么不能除？

因为你并不知道：

\[
\lambda\ne0.
\]

所以涉及参数方程时，只要某个因子：

\[
\lambda,\quad \lambda-1,\quad a,\quad x
\]

有可能为0，就不能随便除掉。

要写成：

\[
\boxed{
pq=0
\Rightarrow
p=0\text{ 或 }q=0
}
\]

而不是：

\[
pq=0\Rightarrow q=0.
\]

所以这道题的真正考点其实是：

\[
\boxed{\text{参数因子必须保留到最后分类}}
\]
