继续第一章“行列式”。现在进入你讲义里的一个**提高型补充**：

\[
\boxed{\text{奇数阶正交矩阵 + 反对称矩阵}}
\]

这道题表面上出现了矩阵乘法、转置、正交矩阵，看起来已经不像“行列式计算题”了，但真正落脚点仍然只有一个：

\[
\boxed{\det A^T=\det A}
\]

以及

\[
\boxed{\det(-A)=(-1)^n\det A}
\]

。你讲义的视频例1.6就是用这两个行列式性质，把问题转化成“奇数阶反对称矩阵行列式为0”。fileciteturn32file0L429-L443

# 一、先看完整题目

设 \(A,B\) 是**奇数阶实正交矩阵**，求

\[
\boxed{
\det[(A-B)(A+B)]
}
\]

。fileciteturn32file0L429-L441

拿到这道题，第一反应可能是展开：

\[
(A-B)(A+B).
\]

但注意：

\[
(A-B)(A+B)
\]

不能像普通代数那样直接写成：

\[
A^2-B^2.
\]

因为矩阵一般：

\[
AB\ne BA.
\]

实际上：

\[
(A-B)(A+B)
=
A^2+AB-BA-B^2.
\]

这并没有变简单。

所以题眼不是“平方差”，而是：

\[
\boxed{A,B\text{ 是正交矩阵}}
\]

---

# 二、正交矩阵这个条件到底能给我们什么？

正交矩阵满足：

\[
\boxed{
A^TA=I
}
\]

以及：

\[
\boxed{
B^TB=I
}
\]

。

所以只要我们能在式子里制造出：

\[
A^TA
\]

和

\[
B^TB,
\]

就能直接把它们化成单位矩阵 \(I\)。

因此我们希望把原来的：

\[
A-B
\]

变成：

\[
(A-B)^T.
\]

问题是：这样会不会改变行列式？

不会。

因为：

\[
\boxed{\det M^T=\det M}
\]

所以：

\[
\det(A-B)^T=\det(A-B).
\]

于是原式：

\[
\det[(A-B)(A+B)]
\]

利用：

\[
\det(XY)=\det X\det Y
\]

可以写成：

\[
\det(A-B)\det(A+B).
\]

而：

\[
\det(A-B)=\det[(A-B)^T].
\]

所以：

\[
\boxed{
\det[(A-B)(A+B)]
=
\det[(A-B)^T(A+B)]
}
\]

。fileciteturn32file0L433-L438

注意：

> 这里只说明**两个矩阵的行列式相同**，并没有说这两个矩阵本身相等。

这点讲义也专门提醒了。fileciteturn32file0L441-L443

---

# 三、为什么一定要转置？现在展开你就看出来了

计算：

\[
(A-B)^T(A+B).
\]

首先：

\[
(A-B)^T=A^T-B^T.
\]

所以：

\[
\begin{aligned}
(A-B)^T(A+B)
&=(A^T-B^T)(A+B)\\
&=A^TA+A^TB-B^TA-B^TB.
\end{aligned}
\]

利用正交条件：

\[
A^TA=I,
\]

\[
B^TB=I.
\]

所以：

\[
\begin{aligned}
(A-B)^T(A+B)
&=I+A^TB-B^TA-I\\
&=A^TB-B^TA.
\end{aligned}
\]

因此原问题变成：

\[
\boxed{
\det(A^TB-B^TA)
}
\]

。fileciteturn32file0L433-L441

这就是为什么前面要主动制造转置：

\[
\boxed{
\text{转置}
\rightarrow
\text{制造 }A^TA,B^TB
\rightarrow
\text{利用正交条件消掉}
}
\]

---

# 四、关键来了：这个矩阵有什么特殊结构？

令：

\[
\boxed{
S=A^TB-B^TA
}
\]

现在求它的转置：

\[
S^T
=
(A^TB-B^TA)^T.
\]

利用：

\[
(X-Y)^T=X^T-Y^T
\]

以及：

\[
(XY)^T=Y^TX^T,
\]

得到：

\[
(A^TB)^T=B^TA,
\]

\[
(B^TA)^T=A^TB.
\]

因此：

\[
S^T
=
B^TA-A^TB.
\]

提一个负号：

\[
S^T
=
-(A^TB-B^TA).
\]

所以：

\[
\boxed{
S^T=-S
}
\]

这种矩阵叫做：

\[
\boxed{\text{反对称矩阵}}
\]

也常叫“斜对称矩阵”。

讲义正是到这里识别出 \(S\) 是反对称矩阵。fileciteturn32file0L438-L443

---

# 五、为什么“奇数阶”反对称矩阵的行列式一定为0？

这才是整道题最重要的知识点。

已知：

\[
S^T=-S.
\]

先利用转置不改变行列式：

\[
\det S
=
\det S^T.
\]

因为：

\[
S^T=-S,
\]

所以：

\[
\det S
=
\det(-S).
\]

现在假设 \(S\) 是 \(n\) 阶。

因为 \(-S\) 相当于 \(S\) 的**每一行都乘 \(-1\)**。

一共 \(n\) 行，所以：

\[
\boxed{
\det(-S)=(-1)^n\det S
}
\]

。

而题目说：

\[
n\text{ 是奇数}.
\]

所以：

\[
(-1)^n=-1.
\]

于是：

\[
\det S=-\det S.
\]

移项：

\[
2\det S=0.
\]

因此：

\[
\boxed{\det S=0}.
\]

所以原题答案：

\[
\boxed{
\det[(A-B)(A+B)]=0
}
\]

。fileciteturn32file0L436-L443

---

# 六、这一步你要真正理解“奇数阶”为什么不能少

如果 \(n\) 是偶数：

\[
(-1)^n=1.
\]

那么刚才只能得到：

\[
\det S=\det S.
\]

这什么信息都没有。

所以：

\[
\boxed{\text{奇数阶反对称矩阵一定奇异}}
\]

但：

\[
\boxed{\text{偶数阶反对称矩阵行列式不一定为0}}
\]

讲义也特意提醒了这一点。fileciteturn32file0L441-L443

比如二阶反对称矩阵：

\[
S=
\begin{pmatrix}
0&1\\
-1&0
\end{pmatrix}.
\]

确实：

\[
S^T=-S.
\]

但是：

\[
\det S
=
0\cdot0-1(-1)
=
1.
\]

所以偶数阶完全可能：

\[
\det S\ne0.
\]

---

# 七、这道题的考研思路应该怎么形成？

以后看到：

\[
\boxed{\text{正交矩阵}}
\]

先想到：

\[
\boxed{
A^TA=AA^T=I
}
\]

然后观察原式能不能通过转置制造：

\[
A^TA.
\]

像本题：

\[
(A-B)(A+B)
\]

直接展开不好算，于是从**行列式层面**把第一个因子换成转置：

\[
A-B
\quad\rightsquigarrow\quad
(A-B)^T.
\]

得到：

\[
(A^T-B^T)(A+B).
\]

正交条件立即消去两个单位阵，留下：

\[
A^TB-B^TA.
\]

再识别：

\[
\boxed{S^T=-S}.
\]

最后利用：

\[
\boxed{
n\text{ 为奇数}
\Rightarrow
\det S=0
}
\]

完整路线就是：

\[
\boxed{
\begin{aligned}
&\det[(A-B)(A+B)]\\
&\Downarrow\quad \det M=\det M^T\\
&\det[(A-B)^T(A+B)]\\
&\Downarrow\quad A^TA=B^TB=I\\
&\det(A^TB-B^TA)\\
&\Downarrow\\
&S^T=-S\\
&\Downarrow\quad n\text{奇}\\
&\boxed{0}
\end{aligned}}
\]

---

## 这一部分需要记住两个非常有用的小结论

第一：

\[
\boxed{
A^T=-A,\ n\text{为奇数}
\Longrightarrow
\det A=0
}
\]

第二：

遇到正交矩阵：

\[
\boxed{
A^TA=AA^T=I
}
\]

如果原式里没有 \(A^TA\)，可以考虑利用**转置不改变行列式**去主动制造。
