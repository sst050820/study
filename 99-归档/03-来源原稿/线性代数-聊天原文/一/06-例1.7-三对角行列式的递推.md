继续第一章“行列式”。现在进入一个新的计算方法：**三对角行列式的递推**。

这一类题和前面“制造零、化三角形”不太一样。它的核心不是把一个大行列式一次算完，而是：

\[
\boxed{
D_n\longrightarrow D_{n-1},D_{n-2}
}
\]

也就是把高阶问题降成低阶同类问题。你讲义的例1.7正是这一类。fileciteturn32file0L245-L267

# 一、先看例1.7：为什么一展开就会想到递推？

## 完整题型

四阶行列式

\[
D_4=
\begin{vmatrix}
1-a&a&0&0\\
-1&1-a&a&0\\
0&-1&1-a&a\\
0&0&-1&1-a
\end{vmatrix}.
\]

主对角线都是：

\[
1-a,
\]

上相邻对角线都是：

\[
a,
\]

下相邻对角线都是：

\[
-1.
\]

其他位置全是0。fileciteturn32file0L245-L258

这种形状就叫**三对角行列式**。

你先观察第一行：

\[
(1-a,\ a,\ 0,\ 0).
\]

只有两个非零元素。

所以最自然的动作就是：

\[
\boxed{\text{沿第一行展开}}
\]

而关键就在于：展开以后留下来的余子式，居然还是和原来差不多的结构。

这就是“递推”出现的原因。

---

# 二、先不要直接算四阶，定义一般的 \(D_n\)

把同一种结构推广成 \(n\) 阶：

\[
D_n=
\begin{vmatrix}
1-a&a&0&\cdots&0\\
-1&1-a&a&\ddots&\vdots\\
0&-1&1-a&\ddots&0\\
\vdots&\ddots&\ddots&\ddots&a\\
0&\cdots&0&-1&1-a
\end{vmatrix}.
\]

现在沿第一行展开。

第一项是：

\[
(1-a)A_{11}.
\]

删掉第一行第一列以后，剩下的是：

\[
\begin{vmatrix}
1-a&a&\cdots&0\\
-1&1-a&\ddots&\vdots\\
\vdots&\ddots&\ddots&a\\
0&\cdots&-1&1-a
\end{vmatrix}.
\]

这不就是：

\[
\boxed{D_{n-1}}
\]

吗？

所以第一项：

\[
\boxed{(1-a)D_{n-1}}.
\]

---

## 第二项为什么会变成 \(aD_{n-2}\)？

第二个非零元素在：

\[
(1,2)
\]

位置：

\[
a_{12}=a.
\]

所以它的贡献是：

\[
aA_{12}.
\]

而：

\[
A_{12}=(-1)^{1+2}M_{12}=-M_{12}.
\]

现在看 \(M_{12}\)。

删掉第一行、第2列以后，得到：

\[
M_{12}
=
\begin{vmatrix}
-1&a&0&\cdots\\
0&1-a&a&\cdots\\
0&-1&1-a&\cdots\\
\vdots&&\ddots&\ddots
\end{vmatrix}.
\]

这个行列式的第一列只有第一个元素：

\[
-1.
\]

所以再沿第一列展开：

\[
M_{12}
=
(-1)\cdot D_{n-2}.
\]

即：

\[
M_{12}=-D_{n-2}.
\]

因此：

\[
A_{12}
=
-M_{12}
=
D_{n-2}.
\]

于是第二项：

\[
aA_{12}
=
aD_{n-2}.
\]

所以最终：

\[
\boxed{
D_n=(1-a)D_{n-1}+aD_{n-2}
}
\]

这就是讲义里的递推式。fileciteturn32file0L247-L255

你看，这个式子不是凭空记出来的，而是：

\[
\boxed{\text{沿第一行展开两次，自然出现}}
\]

---

# 三、递推一定要有初值

只有：

\[
D_n=(1-a)D_{n-1}+aD_{n-2}
\]

还不能算。

你必须知道最开始的几个值。

定义：

\[
\boxed{D_0=1}
\]

以及：

\[
D_1=1-a.
\]

为什么把 \(D_0\) 定义成1？

因为这样递推式从 \(n=2\) 开始也能统一成立。

例如：

\[
D_2=
\begin{vmatrix}
1-a&a\\
-1&1-a
\end{vmatrix}.
\]

直接算：

\[
D_2=(1-a)^2+a.
\]

展开：

\[
D_2
=
1-2a+a^2+a
=
\boxed{1-a+a^2}.
\]

用递推：

\[
D_2=(1-a)D_1+aD_0.
\]

代入：

\[
=(1-a)(1-a)+a\cdot1
\]

同样得到：

\[
1-a+a^2.
\]

所以：

\[
\boxed{D_0=1}
\]

是为了让整个递推体系保持统一。讲义也明确采用这个初值。fileciteturn32file0L249-L255

---

## 接着算 \(D_3\)

已经有：

\[
D_1=1-a,
\]

\[
D_2=1-a+a^2.
\]

所以：

\[
\begin{aligned}
D_3
&=(1-a)D_2+aD_1\\
&=(1-a)(1-a+a^2)+a(1-a).
\end{aligned}
\]

先展开第一部分：

\[
(1-a)(1-a+a^2)
=
1-2a+2a^2-a^3.
\]

再加：

\[
a-a^2.
\]

于是：

\[
\boxed{
D_3=1-a+a^2-a^3
}.
\]

---

## 再算 \(D_4\)

\[
D_4=(1-a)D_3+aD_2.
\]

代入：

\[
D_4
=
(1-a)(1-a+a^2-a^3)
+a(1-a+a^2).
\]

第一部分：

\[
1-2a+2a^2-2a^3+a^4.
\]

第二部分：

\[
a-a^2+a^3.
\]

相加：

\[
\boxed{
D_4=1-a+a^2-a^3+a^4
}
\]

这就是例1.7的答案。fileciteturn32file0L252-L258

---

# 四、为什么三对角结构一般都会出现 \(D_{n-1},D_{n-2}\)？

现在把具体数字换成一般形式：

\[
D_n=
\begin{vmatrix}
k&b&0&\cdots&0\\
c&k&b&\ddots&\vdots\\
0&c&k&\ddots&0\\
\vdots&\ddots&\ddots&\ddots&b\\
0&\cdots&0&c&k
\end{vmatrix}.
\]

沿第一行展开。

第一项：

\[
kD_{n-1}.
\]

第二项是：

\[
bA_{12}.
\]

因为：

\[
A_{12}=-M_{12},
\]

而 \(M_{12}\) 的第一列只有一个 \(c\)，继续展开得到：

\[
M_{12}=cD_{n-2}.
\]

所以：

\[
A_{12}=-cD_{n-2}.
\]

于是：

\[
bA_{12}
=
-bcD_{n-2}.
\]

最终：

\[
\boxed{
D_n=kD_{n-1}-bcD_{n-2}
}
\]

这才是一般三对角递推公式。fileciteturn32file0L261-L267

现在回头看例1.7：

\[
k=1-a,\qquad b=a,\qquad c=-1.
\]

于是：

\[
-bc=-a(-1)=+a.
\]

所以：

\[
D_n=(1-a)D_{n-1}+aD_{n-2}.
\]

符号完全对应。

---

# 五、考研做这种题应该怎么识别？

以后看到：

\[
\begin{matrix}
*&*&0&0&\cdots\\
*&*&*&0&\cdots\\
0&*&*&*&\cdots\\
\vdots&&\ddots&\ddots
\end{matrix}
\]

也就是只有：

\[
\boxed{\text{主对角线 + 上一条对角线 + 下一条对角线}}
\]

有非零元素，就要马上想到：

\[
\boxed{\text{三对角}\Rightarrow\text{沿首行/末行展开}\Rightarrow\text{递推}}
\]

而不是把一个六阶、七阶行列式一直硬展开。

---

## 为什么一定要写初值？

假设只告诉你：

\[
D_n=2D_{n-1}-D_{n-2}.
\]

满足这个递推的数列有无数个。

例如只要初值不同，整个数列就不同。

所以完整递推必须包含：

\[
\boxed{
\text{递推关系}+\text{初值}
}
\]

比如：

\[
D_0=1,\qquad D_1=k.
\]

讲义也特别提醒：

> 考场优先会列递推，通式只是辅助，不能漏初值。fileciteturn32file0L261-L267

---

# 六、通式先知道它从哪里来，不必现在当重点

一般递推：

\[
D_n=kD_{n-1}-bcD_{n-2}
\]

对应特征方程：

\[
\boxed{
\lambda^2-k\lambda+bc=0
}
\]

如果有两个不同根：

\[
\lambda_1,\lambda_2,
\]

那么讲义给出：

\[
\boxed{
D_n=
\frac{
\lambda_1^{n+1}-\lambda_2^{n+1}
}{
\lambda_1-\lambda_2
}
}
\]

如果是重根：

\[
\lambda_1=\lambda_2=\lambda,
\]

则：

\[
\boxed{
D_n=(n+1)\lambda^n
}
\]

。fileciteturn32file0L261-L267

但你当前阶段不要把重心放在背这个通式。

考研第一反应应该是：

\[
\boxed{
\text{识别三对角}
\rightarrow
\text{建立递推}
\rightarrow
\text{写初值}
}
\]

题目只让算四阶、五阶时，直接递推几次通常比解特征方程快。

---

## 这一节最需要记住的一个模板

三对角：

\[
\boxed{
\begin{vmatrix}
k&b&&\\
c&k&b&\\
&c&k&\ddots\\
&&\ddots&\ddots
\end{vmatrix}
}
\]

对应：

\[
\boxed{
D_n=kD_{n-1}-bcD_{n-2}
}
\]

为什么？

不是因为需要硬背，而是：

\[
\boxed{
\text{首行只有两个非零元素}
}
\]

第一个留下：

\[
D_{n-1},
\]

第二个经过余子式再展开，留下：

\[
cD_{n-2}.
\]

这才是公式来源。

下一步按照讲义顺序，会进入一个和普通“减阶递推”很不一样的方法：**加边法**

\[
\det(I+\alpha\alpha^T).
\]

它表面是一个很满的 \(n\) 阶行列式，直接展开很麻烦，但通过主动增加一行一列，反而能把它化成单位阵结构，最后得到：

\[
\boxed{
\det(I+\alpha\alpha^T)
=
1+\sum_{i=1}^n x_i^2
}
\]

这一部分会重点讲清楚“为什么加边后还能和原行列式建立等式”，而不是把加边当魔法。
