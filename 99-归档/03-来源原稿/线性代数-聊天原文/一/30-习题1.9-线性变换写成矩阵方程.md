继续严格按照《01-行列式.md》的顺序。现在讲：

\[
\boxed{\text{习题1.9：把线性变换写成矩阵方程}}
\]

题目给出

\[
P=[\alpha_1,\alpha_2,\alpha_3]
\]

可逆，并且

\[
A\alpha_1=\alpha_2-2\alpha_3,
\]

\[
A\alpha_2=\alpha_1-\alpha_2+2\alpha_3,
\]

\[
A\alpha_3=2\alpha_1+\alpha_2.
\]

要求实际上是求 \(\det A\)。这道题的核心题眼是：

\[
\boxed{\text{把三个向量等式一次性拼成 }AP=PC}
\]

。fileciteturn33file0L749-L766

# 一、为什么左边可以拼成 \(AP\)？

因为

\[
P=[\alpha_1,\alpha_2,\alpha_3].
\]

所以矩阵乘法

\[
AP
\]

就是：

\[
A[\alpha_1,\alpha_2,\alpha_3].
\]

矩阵左乘 \(A\)，相当于对每一列分别作用 \(A\)，因此：

\[
\boxed{
AP=[A\alpha_1,A\alpha_2,A\alpha_3]
}
\]

再把题目给的三个关系代进去：

\[
AP=
[
\alpha_2-2\alpha_3,\,
\alpha_1-\alpha_2+2\alpha_3,\,
2\alpha_1+\alpha_2
].
\]

所以现在问题变成：

> 能不能把右边这三个新列，都用 \(\alpha_1,\alpha_2,\alpha_3\) 的系数统一写成一个矩阵？

可以。

---

# 二、系数矩阵 \(C\) 是怎么写出来的？

这是这道题最容易写错的地方。

我们一列一列读系数。

第一列：

\[
A\alpha_1=\alpha_2-2\alpha_3.
\]

写成：

\[
0\alpha_1+1\alpha_2-2\alpha_3.
\]

所以第一列系数是：

\[
\begin{pmatrix}
0\\
1\\
-2
\end{pmatrix}.
\]

第二列：

\[
A\alpha_2
=
\alpha_1-\alpha_2+2\alpha_3.
\]

所以第二列系数：

\[
\begin{pmatrix}
1\\
-1\\
2
\end{pmatrix}.
\]

第三列：

\[
A\alpha_3
=
2\alpha_1+\alpha_2.
\]

也就是：

\[
2\alpha_1+1\alpha_2+0\alpha_3.
\]

所以第三列系数：

\[
\begin{pmatrix}
2\\
1\\
0
\end{pmatrix}.
\]

因此：

\[
\boxed{
C=
\begin{pmatrix}
0&1&2\\
1&-1&1\\
-2&2&0
\end{pmatrix}
}
\]

于是：

\[
[\alpha_2-2\alpha_3,\,
\alpha_1-\alpha_2+2\alpha_3,\,
2\alpha_1+\alpha_2]
=
PC.
\]

因此：

\[
\boxed{AP=PC}.
\]

这正是MD给出的矩阵关系。fileciteturn33file0L756-L764

这里再强调一次：

\[
\boxed{\text{一个新列的系数，要竖着放成 }C\text{ 的一列}}
\]

不是横着写。

---

# 三、为什么最后只需要算 \(\det C\)？

现在已经有：

\[
AP=PC.
\]

两边取行列式：

\[
\det(AP)=\det(PC).
\]

利用：

\[
\det(XY)=\det X\det Y,
\]

得到：

\[
\det A\cdot\det P
=
\det P\cdot\det C.
\]

题目特别告诉我们：

\[
\boxed{P\text{ 可逆}}
\]

所以：

\[
\det P\ne0.
\]

因此可以约掉：

\[
\det P.
\]

得到：

\[
\boxed{\det A=\det C}.
\]

这一步为什么一定要强调 \(P\) 可逆？

因为如果：

\[
\det P=0,
\]

那么

\[
\det A\det P=\det P\det C
\]

只会变成：

\[
0=0,
\]

什么也推不出来。

所以这里：

\[
\boxed{P\text{ 可逆}\Rightarrow\det P\ne0}
\]

是能约掉 \(\det P\) 的必要条件。

---

## 最后算 \(\det C\)

\[
\det C=
\begin{vmatrix}
0&1&2\\
1&-1&1\\
-2&2&0
\end{vmatrix}.
\]

沿第一行展开：

\[
\begin{aligned}
\det C
&=
-1
\begin{vmatrix}
1&1\\
-2&0
\end{vmatrix}
+
2
\begin{vmatrix}
1&-1\\
-2&2
\end{vmatrix}.
\end{aligned}
\]

第一个二阶：

\[
\begin{vmatrix}
1&1\\
-2&0
\end{vmatrix}
=
2.
\]

所以第一部分：

\[
-2.
\]

第二个二阶：

\[
\begin{vmatrix}
1&-1\\
-2&2
\end{vmatrix}
=
2-2=0.
\]

所以：

\[
\det C=-2.
\]

于是：

\[
\boxed{\det A=-2}.
\]

与MD结论一致。fileciteturn33file0L760-L766

这道题以后要形成的反应是：

\[
\boxed{
A\alpha_1,\ A\alpha_2,\ A\alpha_3
\text{ 都写成 }\alpha_1,\alpha_2,\alpha_3\text{ 的线性组合}
}
\]

马上考虑：

\[
\boxed{
P=[\alpha_1,\alpha_2,\alpha_3],
\qquad
AP=PC
}
\]

然后利用：

\[
\boxed{
P\text{ 可逆}
\Rightarrow
\det A=\det C
}
\]

下一步严格按照MD，就是 **习题1.10：齐次方程“只有零解”的充要条件**，核心直接使用：

\[
\boxed{
Ax=0\text{ 只有零解}
\iff
\det A\ne0
}
\]

最后会得到：

\[
\boxed{\lambda\ne1}.
\]
