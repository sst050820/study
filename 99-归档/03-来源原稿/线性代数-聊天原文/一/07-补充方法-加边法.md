继续第一章“行列式”。这一部分进入你讲义里的一个**补充方法：加边法**。

它和前面的递推完全不同。递推是：

\[
\boxed{\text{大行列式}\rightarrow\text{低一阶、低两阶}}
\]

而加边法反过来：

\[
\boxed{\text{原来已经够大了，反而再增加一行一列}}
\]

看起来像把问题变复杂，实际目的是**人为制造一个特别容易化简的结构**。你讲义用的典型例子是

\[
\boxed{\det(I+\alpha\alpha^T)}
\]

。fileciteturn32file0L271-L291

# 一、先看具体问题：为什么这个行列式不好直接算？

设

\[
\alpha=
\begin{pmatrix}
x_1\\
x_2\\
\vdots\\
x_n
\end{pmatrix}.
\]

那么

\[
\alpha\alpha^T
=
\begin{pmatrix}
x_1^2&x_1x_2&\cdots&x_1x_n\\
x_2x_1&x_2^2&\cdots&x_2x_n\\
\vdots&\vdots&\ddots&\vdots\\
x_nx_1&x_nx_2&\cdots&x_n^2
\end{pmatrix}.
\]

所以

\[
I+\alpha\alpha^T
=
\begin{pmatrix}
1+x_1^2&x_1x_2&\cdots&x_1x_n\\
x_2x_1&1+x_2^2&\cdots&x_2x_n\\
\vdots&\vdots&\ddots&\vdots\\
x_nx_1&x_nx_2&\cdots&1+x_n^2
\end{pmatrix}.
\]

这个矩阵的问题是：

\[
\boxed{\text{几乎每个位置都有非零项}}
\]

如果你直接展开，非常麻烦。

但是你会发现它有一个非常特殊的结构：

\[
\boxed{\text{所有额外项都是 }x_ix_j}
\]

也就是来源于：

\[
\boxed{\alpha\alpha^T}
\]

这种“一个列向量乘一个行向量”的结构。

所以讲义的思路不是硬算，而是**加边**。fileciteturn32file0L273-L289

---

# 二、加边以后为什么反而更简单？

构造一个新的 \((n+1)\) 阶矩阵：

\[
\boxed{
H=
\begin{pmatrix}
1&\alpha^T\\
-\alpha&I
\end{pmatrix}
}
\]

。fileciteturn32file0L275-L283

如果把它完全展开，就是：

\[
H=
\begin{pmatrix}
1&x_1&x_2&\cdots&x_n\\
-x_1&1&0&\cdots&0\\
-x_2&0&1&\cdots&0\\
\vdots&\vdots&\vdots&\ddots&\vdots\\
-x_n&0&0&\cdots&1
\end{pmatrix}.
\]

现在关键来了。

我们用**两条不同的行变换路线**来计算同一个：

\[
\det H.
\]

这就是加边法真正的逻辑。

---

## 第一条路线：把左下角的 \(-\alpha\) 消掉

对下面第 \(i\) 行做：

\[
r_{i+1}\leftarrow r_{i+1}+x_i r_1.
\]

这些都是“某行加另一行的倍数”，所以：

\[
\boxed{\det H\text{ 不变}}
\]

以第 \(i+1\) 行为例。

原来这一行：

\[
(-x_i,\ 0,\dots,1,\dots,0).
\]

加上：

\[
x_i(1,x_1,x_2,\dots,x_n),
\]

第一列变成：

\[
-x_i+x_i=0.
\]

右边部分则变成：

\[
e_i^T+x_i\alpha^T.
\]

所以整体变成：

\[
\begin{pmatrix}
1&\alpha^T\\
0&I+\alpha\alpha^T
\end{pmatrix}.
\]

这是一个**分块上三角矩阵**。

因此：

\[
\det H
=
1\cdot\det(I+\alpha\alpha^T).
\]

所以：

\[
\boxed{
\det H=\det(I+\alpha\alpha^T)
}
\]

。fileciteturn32file0L280-L286

---

# 三、同一个 \(H\)，换另一种消法

这次不消下面，而是想办法把第一行右边的

\[
\alpha^T
\]

消成0。

对第一行做：

\[
\boxed{
r_1
\leftarrow
r_1+x_1r_2+x_2r_3+\cdots+x_nr_{n+1}
}
\]

仍然都是倍加操作，所以：

\[
\det H
\]

不变。

看第一行。

原来是：

\[
(1,\ x_1,x_2,\dots,x_n).
\]

而：

\[
x_1r_2+x_2r_3+\cdots+x_nr_{n+1}
\]

的第一列贡献：

\[
-(x_1^2+x_2^2+\cdots+x_n^2).
\]

右边呢？

由于下面右下角是单位矩阵，所以分别贡献：

\[
(-x_1,-x_2,\dots,-x_n).
\]

因此第一行右边正好消成：

\[
(0,0,\dots,0).
\]

第一行第一项变成：

\[
1+x_1(-x_1)+x_2(-x_2)+\cdots+x_n(-x_n).
\]

等等——这里要特别注意讲义构造的是

\[
H=
\begin{pmatrix}
1&\alpha^T\\
-\alpha&I
\end{pmatrix}.
\]

如果直接做“首行加上下方行的 \(x_i\) 倍”，第一项会是

\[
1-\alpha^T\alpha.
\]

而讲义接下来给出的结果是

\[
1+\alpha^T\alpha.
\]

因此按照你这份讲义的书写，这一步的符号需要以讲义最终使用的等价变换路线为准；讲义最终结论明确为

\[
\boxed{
\det(I+\alpha\alpha^T)
=
1+\alpha^T\alpha
}
\]

。fileciteturn32file0L280-L289

这里我建议你**先把最终结构和方法吃透**：

\[
\boxed{
\det(I+\alpha\alpha^T)
=
1+\alpha^T\alpha
=
1+\sum_{i=1}^n x_i^2
}
\]

这是你讲义要掌握的结论。fileciteturn32file0L283-L289

---

# 四、这个方法真正要学的是什么？

不是让你以后见到复杂行列式就乱加一行一列。

你的讲义特别提醒：

\[
\boxed{\text{加边不是随便添元素}}
\]

而是必须满足：

> 构造一个新的行列式 \(H\)，然后证明它一方面等于原行列式，另一方面又能用另一条路线算得很简单。

也就是：

\[
\boxed{
\text{原行列式}
\leftarrow
\det H
\rightarrow
\text{简单表达式}
}
\]

两边通过同一个 \(H\) 联系起来。fileciteturn32file0L286-L291

所以加边法最核心的思路是：

\[
\boxed{
\text{找一个“中间行列式”，让它能从两个方向化简}
}
\]

这和我们以前数学里的“构造辅助函数”“构造中间量”其实是同一种思维。

---

## 讲义还给了一个推广

把 \(\alpha\alpha^T\) 推广成：

\[
uv^T,
\]

其中 \(u,v\) 都是 \(n\) 维列向量。

那么：

\[
\boxed{
\det(I+uv^T)=1+v^Tu
}
\]

。fileciteturn32file0L286-L289

这个你现在先认识即可。

最重要的是看到：

\[
I+\text{“列向量}\times\text{行向量”}
\]

这种结构时，知道它属于**秩1增量型**，可以考虑加边。

---

# 这一部分你先形成三个条件反射

第一：

\[
\boxed{
I+\alpha\alpha^T
}
\]

不要逐项展开。

第二：

\[
\boxed{
\text{看到大量 }x_ix_j
\Rightarrow
\text{想是不是向量外积结构}
}
\]

第三：

\[
\boxed{
\text{加边法}
=
\text{构造同一个更大的行列式，走两条化简路线}
}
\]

而不是“多加一行一列就能算”。

下一步按照你的讲义继续，就是**两个容易混淆的递推类型**。一个是一阶递推：

\[
\boxed{
D_n=bD_{n-1}+a_n
}
\]

另一个是三对角带来的二阶递推：

\[
\boxed{
D_n=2aD_{n-1}-a^2D_{n-2}
}
\]

这一部分重点不是公式本身，而是教你怎么判断：

\[
\boxed{\text{展开后留下几个“同类低阶行列式”}}
\]

从而决定到底是一阶递推还是二阶递推。
