继续第一章“行列式”。现在进入你讲义这一部分的下一块：

\[
\boxed{\text{全部代数余子式之和}}
\]

前面我们处理的是“同一行的一串 \(A_{ij}\)”，可以靠反向展开解决；但现在如果题目要求的是

\[
\sum_{i,j}A_{ij},
\]

也就是**所有代数余子式加起来**，逐个算会非常麻烦。这时讲义引入伴随矩阵：

\[
\boxed{A^*=(A_{ji})}
\]

并利用

\[
\boxed{A^*=\det A\,A^{-1}}
\]

来整体处理。fileciteturn32file0L508-L531

# 一、先用例2.2看：为什么“所有余子式之和”要联想到 \(A^*\)

讲义给出

\[
A=
\begin{pmatrix}
0_{2\times3}&B\\
C&0_{3\times2}
\end{pmatrix},
\]

其中

\[
B=
\begin{pmatrix}
5&6\\
7&8
\end{pmatrix},
\qquad
C=
\begin{pmatrix}
1&2&3\\
0&1&4\\
0&0&1
\end{pmatrix}.
\]

要求的核心对象是：**\(A\) 的所有代数余子式之和**。fileciteturn32file0L512-L527

如果你直接去算 \(A_{ij}\)，这是一个 \(5\times5\) 矩阵，一共有25个代数余子式，显然不合适。

所以先想：

\[
A^*=
\begin{pmatrix}
A_{11}&A_{21}&\cdots\\
A_{12}&A_{22}&\cdots\\
\vdots&\vdots&
\end{pmatrix}.
\]

虽然 \(A^*\) 把余子式矩阵转置了，但：

\[
\boxed{\text{所有元素的总和，转置前后不变}}
\]

所以：

\[
\boxed{
\sum_{i,j}A_{ij}
=
\text{\(A^*\) 中所有元素之和}
}
\]

而一个矩阵所有元素之和，可以写成：

\[
\boxed{
\mathbf1^TA^*\mathbf1
}
\]

其中

\[
\mathbf1=
\begin{pmatrix}
1\\1\\\vdots\\1
\end{pmatrix}.
\]

这就是讲义给出的统一表达。fileciteturn32file0L508-L510

---

## 为什么 \(\mathbf1^TA^*\mathbf1\) 是所有元素之和？

先算：

\[
A^*\mathbf1.
\]

右乘全1列向量，相当于把 \(A^*\) **每一行的元素加起来**。

得到：

\[
\begin{pmatrix}
\text{第1行和}\\
\text{第2行和}\\
\vdots
\end{pmatrix}.
\]

再左乘：

\[
\mathbf1^T=(1,1,\dots,1),
\]

就是再把这些行和全部加起来。

因此：

\[
\boxed{
\mathbf1^TA^*\mathbf1
=
A^*\text{全部元素之和}
}
\]

---

# 二、例2.2怎么计算：把问题变成 \(A^{-1}\) 的元素和

只要 \(A\) 可逆：

\[
\boxed{
A^*=\det A\,A^{-1}
}
\]

于是：

\[
\sum_{i,j}A_{ij}
=
\det A\cdot
\bigl(A^{-1}\text{的全部元素之和}\bigr).
\]

所以问题变成两个任务：

\[
\boxed{\det A}
\]

以及：

\[
\boxed{A^{-1}\text{ 的元素和}}
\]

---

## 第一步：算 \(\det A\)

这个矩阵是副对角分块型：

\[
A=
\begin{pmatrix}
0&B\\
C&0
\end{pmatrix}.
\]

讲义前面学过：

\[
\det
\begin{pmatrix}
0&A\\
B&C
\end{pmatrix}
=
(-1)^{mn}\det A\det B.
\]

这里对应符号为：

\[
(-1)^6=1.
\]

所以：

\[
\det A
=
\det B\det C.
\]

先算：

\[
\det B
=
5\cdot8-6\cdot7
=
40-42
=
-2.
\]

而 \(C\) 是上三角矩阵：

\[
\det C=1.
\]

因此：

\[
\boxed{\det A=-2}.
\]

fileciteturn32file0L515-L523

---

## 第二步：算 \(A^{-1}\) 的元素和

讲义给出：

\[
A^{-1}
=
\begin{pmatrix}
0&C^{-1}\\
B^{-1}&0
\end{pmatrix}
\]

这种对应的分块结构。fileciteturn32file0L520-L527

所以 \(A^{-1}\) 的元素和，就是：

\[
\boxed{
C^{-1}\text{元素和}
+
B^{-1}\text{元素和}
}
\]

讲义给出：

\[
B^{-1}
=
\begin{pmatrix}
-4&3\\
\frac72&-\frac52
\end{pmatrix}.
\]

元素和：

\[
-4+3+\frac72-\frac52.
\]

后面：

\[
\frac72-\frac52=1,
\]

前面：

\[
-4+3=-1.
\]

所以：

\[
\boxed{\sum B^{-1}_{ij}=0}.
\]

再看：

\[
C^{-1}
=
\begin{pmatrix}
1&-2&5\\
0&1&-4\\
0&0&1
\end{pmatrix}.
\]

元素和：

\[
1-2+5+0+1-4+0+0+1.
\]

逐步算：

\[
1-2+5=4,
\]

\[
1-4=-3,
\]

最后再加1：

\[
4-3+1=2.
\]

所以：

\[
\boxed{\sum C^{-1}_{ij}=2}.
\]

因此：

\[
A^{-1}\text{全部元素和}=2.
\]

---

## 最后利用 \(A^*=\det A A^{-1}\)

所以全部代数余子式之和：

\[
=(-2)\cdot2.
\]

最终：

\[
\boxed{-4}.
\]

这就是讲义例2.2的答案。fileciteturn32file0L520-L527

这道题真正的思路是：

\[
\boxed{
\text{所有 }A_{ij}\text{ 之和}
\rightarrow
A^*
\rightarrow
\det A\,A^{-1}
\rightarrow
A^{-1}\text{元素和}
}
\]

---

# 三、例2.4：如果只求某一列代数余子式的和，怎么更快？

下面这个例子更值得你形成条件反射。

已知三阶矩阵：

\[
\det A=3,
\]

并且 \(A^{-1}\) **每一行元素和都是2**。

求：

\[
\boxed{
A_{13}+A_{23}+A_{33}
}
\]

。fileciteturn32file0L529-L531

先看目标：

\[
A_{13}+A_{23}+A_{33}.
\]

很多人会认为：

> 这不是第3列的余子式吗？

是的，从代数余子式矩阵来看，它们是第3列。

但注意伴随矩阵：

\[
A^*=(A_{ji}).
\]

所以 \(A^*\) 的第3行是：

\[
\boxed{
(A_{13},A_{23},A_{33})
}
\]

因此题目实际求的是：

\[
\boxed{A^*\text{ 第3行元素和}}
\]

---

## 利用已知 \(A^{-1}\) 每行和为2

“每一行元素和为2”可以写成：

\[
\boxed{
A^{-1}\mathbf1=2\mathbf1
}
\]

因为右乘 \(\mathbf1\)，就是每行求和。

又因为：

\[
A^*=\det A\,A^{-1},
\]

而：

\[
\det A=3,
\]

所以：

\[
A^*=3A^{-1}.
\]

因此：

\[
A^*\mathbf1
=
3A^{-1}\mathbf1.
\]

代入：

\[
A^{-1}\mathbf1=2\mathbf1,
\]

得到：

\[
A^*\mathbf1
=
3\cdot2\mathbf1
=
6\mathbf1.
\]

这句话的意思就是：

\[
\boxed{A^*\text{ 每一行元素和都等于6}}
\]

所以第3行：

\[
A_{13}+A_{23}+A_{33}=6.
\]

最终：

\[
\boxed{6}.
\]

这正是讲义给出的简化方法。fileciteturn32file0L529-L531

---

## 这类题最容易混的地方

你一定要注意：

\[
A^*=(A_{ji}),
\]

所以：

原来代数余子式矩阵的**第3列**

\[
A_{13},A_{23},A_{33}
\]

在 \(A^*\) 里面变成了：

\[
\boxed{\text{第3行}}
\]

因此：

\[
A_{13}+A_{23}+A_{33}
\]

对应的是：

\[
\boxed{A^*\text{第3行和}}
\]

不是第3列和。

---

# 四、这一块的统一框架

以后见到：

\[
\boxed{\text{大量代数余子式求和}}
\]

不要第一反应逐个算。

先问：

### 如果是所有 \(A_{ij}\) 之和

想：

\[
\boxed{
\sum_{i,j}A_{ij}
=
\mathbf1^TA^*\mathbf1
}
\]

若 \(A\) 可逆，再用：

\[
\boxed{
A^*=\det A\,A^{-1}
}
\]

---

### 如果是某一列代数余子式的和

例如：

\[
A_{1j}+A_{2j}+\cdots+A_{nj},
\]

由于转置关系，它对应：

\[
\boxed{A^*\text{ 第 }j\text{ 行和}}
\]

于是可以用：

\[
A^*\mathbf1.
\]

---

### 如果是某一行代数余子式的和

例如：

\[
A_{i1}+A_{i2}+\cdots+A_{in},
\]

它对应：

\[
\boxed{A^*\text{ 第 }i\text{ 列和}}
\]

于是更自然考虑：

\[
\mathbf1^TA^*.
\]

这就是伴随矩阵把“很多余子式”整体处理掉的价值。

讲义接下来还有一个**特征值预览**：若三阶 \(A\) 的特征值为

\[
-1,\ 2,\ 3,
\]

则

\[
A_{11}+A_{22}+A_{33}
\]

等于三个二阶主子式之和：

\[
(-1)\cdot2+(-1)\cdot3+2\cdot3=1,
\]

但这个结论来自特征多项式系数，**绝不能误认为它等于 \(\operatorname{tr}A\)**。这一点讲义只作为后续章节预告。fileciteturn32file0L529-L535

下一步按照讲义顺序，就进入第一章最后一个大的主干：

\[
\boxed{\text{克拉默法则与齐次方程非零解}}
\]

会先从一个具体二元方程组出发，讲清楚为什么：

\[
\det A\ne0
\]

时可以用

\[
x_i=\frac{D_i}{D},
\]

以及为什么：

\[
\boxed{\det A=0}
\]

对于齐次方程组正好对应“存在非零解”。
