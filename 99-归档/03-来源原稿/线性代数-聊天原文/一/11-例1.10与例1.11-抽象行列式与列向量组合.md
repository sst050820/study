继续第一章“行列式”。现在进入一个很重要的板块：

\[
\boxed{\text{抽象行列式：先看列向量之间的关系}}
\]

从这里开始，题目不一定再给具体数字，而会写成

\[
[\alpha_1,\alpha_2,\alpha_3,\beta,\gamma]
\]

这种形式。你讲义把这一类题总结成两条主路：

\[
\boxed{\text{列的线性性拆分}}
\qquad\text{或}\qquad
\boxed{\text{写成矩阵乘积 }B=AC}
\]

。fileciteturn32file0L383-L395

# 一、先看例1.10：抽象行列式其实比数字题更“规整”

## 题目

已知四阶行列式

\[
\det[\alpha_1,\alpha_2,\alpha_3,\beta]=a,
\]

以及

\[
\det[\beta+\gamma,\alpha_2,\alpha_3,\alpha_1]=b.
\]

求：

\[
\boxed{
\det[\alpha_2+\alpha_3,\alpha_1,\alpha_3,\gamma]
}
\]

。fileciteturn32file0L397-L407

刚拿到这题，很多人会觉得：

> 没有具体数，这怎么计算？

实际上恰恰相反。

这种题不要求你“算”，而是要求你利用：

\[
\boxed{\text{行列式对某一列具有线性性}}
\]

以及：

\[
\boxed{\text{两列相同，行列式为0}}
\]

来拆。

---

## 第一步：先处理已知条件 \(b\)

我们有：

\[
b=
\det[\beta+\gamma,\alpha_2,\alpha_3,\alpha_1].
\]

第一列是：

\[
\beta+\gamma.
\]

所以可以按第一列拆开：

\[
\begin{aligned}
b
&=
\det[\beta,\alpha_2,\alpha_3,\alpha_1]\\
&\quad+
\det[\gamma,\alpha_2,\alpha_3,\alpha_1].
\end{aligned}
\]

现在第一个行列式：

\[
\det[\beta,\alpha_2,\alpha_3,\alpha_1].
\]

而已知的是：

\[
\det[\alpha_1,\alpha_2,\alpha_3,\beta]=a.
\]

它们内容一样，只是列顺序不同。

---

# 二、列移动时为什么是 \(-a\)？

原来：

\[
[\alpha_1,\alpha_2,\alpha_3,\beta].
\]

我们想变成：

\[
[\beta,\alpha_2,\alpha_3,\alpha_1].
\]

最直接看排列：

原列序：

\[
(1,2,3,4)
\]

变成：

\[
(4,2,3,1).
\]

也可以一步一步交换。

例如把 \(\beta\) 从第4列移到第1列，需要交换3次：

\[
[\alpha_1,\alpha_2,\alpha_3,\beta]
\]

先：

\[
\beta\leftrightarrow\alpha_3,
\]

一次交换；

再和 \(\alpha_2\) 交换；

再和 \(\alpha_1\) 交换。

总共：

\[
3
\]

次。

所以符号：

\[
(-1)^3=-1.
\]

因此：

\[
\det[\beta,\alpha_2,\alpha_3,\alpha_1]
=
-a.
\]

于是：

\[
b
=
-a
+
\det[\gamma,\alpha_2,\alpha_3,\alpha_1].
\]

所以：

\[
\boxed{
\det[\gamma,\alpha_2,\alpha_3,\alpha_1]
=
a+b
}
\]

这一步是后面求目标式的关键。fileciteturn32file0L399-L407

---

# 三、再处理目标行列式

目标：

\[
D=
\det[\alpha_2+\alpha_3,\alpha_1,\alpha_3,\gamma].
\]

第一列是：

\[
\alpha_2+\alpha_3.
\]

所以拆开：

\[
\begin{aligned}
D
&=
\det[\alpha_2,\alpha_1,\alpha_3,\gamma]\\
&\quad+
\det[\alpha_3,\alpha_1,\alpha_3,\gamma].
\end{aligned}
\]

看第二项：

\[
\det[\alpha_3,\alpha_1,\alpha_3,\gamma].
\]

第一列和第三列都是：

\[
\alpha_3.
\]

所以：

\[
\boxed{
\det[\alpha_3,\alpha_1,\alpha_3,\gamma]=0
}
\]

因此：

\[
D
=
\det[\alpha_2,\alpha_1,\alpha_3,\gamma].
\]

---

## 现在怎么利用刚才得到的 \(a+b\)？

我们刚才知道：

\[
\det[\gamma,\alpha_2,\alpha_3,\alpha_1]
=
a+b.
\]

目标：

\[
\det[\alpha_2,\alpha_1,\alpha_3,\gamma].
\]

两者只是列顺序不同。

从：

\[
[\gamma,\alpha_2,\alpha_3,\alpha_1]
\]

变成：

\[
[\alpha_2,\alpha_1,\alpha_3,\gamma].
\]

这两个排列相差偶数次交换，所以符号不变。

因此：

\[
\boxed{
D=a+b
}
\]

与你的讲义一致。fileciteturn32file0L399-L407

---

## 例1.10真正训练的是什么？

抽象行列式拿到以后，先看：

\[
\boxed{\text{有没有“向量和”}}
\]

例如：

\[
\alpha+\beta.
\]

有的话第一反应：

\[
\boxed{\text{利用该列的线性性拆开}}
\]

拆开以后如果出现：

\[
[\cdots,\alpha,\cdots,\alpha,\cdots],
\]

立刻：

\[
\boxed{=0}.
\]

最后再通过列交换，把剩下的行列式调整到已知形式。

所以这一类题的主流程是：

\[
\boxed{
\text{拆}
\rightarrow
\text{重复列消0}
\rightarrow
\text{调整列序}
\rightarrow
\text{用已知值}
}
\]

---

# 四、例1.11：列向量组合多时，不拆，直接写成 \(B=AC\)

现在看第二种更重要的方法。

已知：

\[
A=[\alpha_1,\alpha_2,\alpha_3],
\]

且：

\[
\det A=2.
\]

定义：

\[
B=
[
\alpha_1-\alpha_2+2\alpha_3,\;
2\alpha_1+3\alpha_2-5\alpha_3,\;
\alpha_1+2\alpha_2-\alpha_3
].
\]

求：

\[
\boxed{\det(B-A)}
\]

。fileciteturn32file0L409-L425

这题如果你把每一列分别拆行列式，当然也能做，但会非常乱。

因为三列都是：

\[
\alpha_1,\alpha_2,\alpha_3
\]

的线性组合。

这种情况更好的思路是：

\[
\boxed{\text{把所有系数集中成一个系数矩阵}}
\]

---

# 五、第一步先算 \(B-A\)

因为：

\[
A=[\alpha_1,\alpha_2,\alpha_3].
\]

所以逐列相减。

第一列：

\[
(\alpha_1-\alpha_2+2\alpha_3)-\alpha_1
\]

得到：

\[
-\alpha_2+2\alpha_3.
\]

第二列：

\[
(2\alpha_1+3\alpha_2-5\alpha_3)-\alpha_2
\]

得到：

\[
2\alpha_1+2\alpha_2-5\alpha_3.
\]

第三列：

\[
(\alpha_1+2\alpha_2-\alpha_3)-\alpha_3
\]

得到：

\[
\alpha_1+2\alpha_2-2\alpha_3.
\]

所以：

\[
B-A
=
[
-\alpha_2+2\alpha_3,\;
2\alpha_1+2\alpha_2-5\alpha_3,\;
\alpha_1+2\alpha_2-2\alpha_3
].
\]

---

# 六、怎么把它写成 \(A\) 乘一个矩阵？

因为：

\[
A=[\alpha_1,\alpha_2,\alpha_3].
\]

先看第一列：

\[
-\alpha_2+2\alpha_3.
\]

它等于：

\[
0\alpha_1
-1\alpha_2
+2\alpha_3.
\]

所以对应系数列：

\[
\begin{pmatrix}
0\\
-1\\
2
\end{pmatrix}.
\]

注意：

\[
\boxed{\text{一列向量组合的系数，要竖着放成系数矩阵的一列}}
\]

不是写成一行。

第二列：

\[
2\alpha_1+2\alpha_2-5\alpha_3
\]

对应：

\[
\begin{pmatrix}
2\\
2\\
-5
\end{pmatrix}.
\]

第三列：

\[
\alpha_1+2\alpha_2-2\alpha_3
\]

对应：

\[
\begin{pmatrix}
1\\
2\\
-2
\end{pmatrix}.
\]

所以：

\[
\boxed{
B-A
=
A
\begin{pmatrix}
0&2&1\\
-1&2&2\\
2&-5&-2
\end{pmatrix}
}
\]

这正是讲义里的关键式。fileciteturn32file0L419-L425

---

# 七、为什么这样一写就结束了？

设：

\[
C=
\begin{pmatrix}
0&2&1\\
-1&2&2\\
2&-5&-2
\end{pmatrix}.
\]

则：

\[
B-A=AC.
\]

所以：

\[
\det(B-A)
=
\det(AC).
\]

同阶方阵满足：

\[
\boxed{
\det(AC)=\det A\det C
}
\]

。fileciteturn32file0L387-L395

已知：

\[
\det A=2.
\]

再算：

\[
\det C.
\]

即：

\[
\begin{vmatrix}
0&2&1\\
-1&2&2\\
2&-5&-2
\end{vmatrix}.
\]

沿第一行展开：

\[
\begin{aligned}
\det C
&=
-2
\begin{vmatrix}
-1&2\\
2&-2
\end{vmatrix}
+
\begin{vmatrix}
-1&2\\
2&-5
\end{vmatrix}\\
&=
-2(2-4)+(5-4)\\
&=4+1\\
&=5.
\end{aligned}
\]

所以：

\[
\det(B-A)
=
2\times5.
\]

最终：

\[
\boxed{
\det(B-A)=10
}
\]

与你的讲义一致。fileciteturn32file0L419-L425

# 八、什么时候用“拆分”，什么时候用 \(B=AC\)？

这一点非常重要。

像例1.10：

\[
\det[\alpha_2+\alpha_3,\alpha_1,\alpha_3,\gamma]
\]

只有少数一两列出现简单的向量和，而且拆开以后马上产生重复列。

这种时候：

\[
\boxed{\text{直接拆列最快}}
\]

而例1.11里，三列全都是：

\[
\alpha_1,\alpha_2,\alpha_3
\]

的复杂线性组合。

如果每列都拆，项数会爆炸。

所以：

\[
\boxed{\text{多列都是同一组基向量的线性组合}\Rightarrow B=AC}
\]

这就是讲义总结的两条主路。fileciteturn32file0L383-L395

这里还有两个必须防的错误：

\[
\boxed{
\det(B-A)\neq\det B-\det A
}
\]

一般不成立。

以及系数矩阵要记：

\[
\boxed{
\text{第 }j\text{ 个新列的系数}
\Rightarrow
\text{放在系数矩阵第 }j\text{ 列}
}
\]

不能横着写。fileciteturn32file0L419-L427

到这里，“抽象行列式”的最核心计算方法已经建立起来：

\[
\boxed{
\text{简单列组合}\rightarrow\text{利用线性性拆分}
}
\]

\[
\boxed{
\text{多列复杂组合}\rightarrow\text{写成 }B=AC\rightarrow\det B=\det A\det C
}
\]

下一步按讲义顺序，会进入一个更抽象但很经典的补充：**奇数阶正交矩阵与反对称矩阵**。核心结论是理解为什么奇数阶反对称矩阵

\[
S^T=-S
\]

一定满足

\[
\boxed{\det S=0},
\]

以及题目怎样从正交条件构造出这个反对称矩阵。
