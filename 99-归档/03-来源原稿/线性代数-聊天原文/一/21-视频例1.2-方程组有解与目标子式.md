这道题很典型，因为它不是让你真的去解方程组，而是利用一句：

\[
\boxed{\text{方程组有解}}
\]

直接制造一个 **四阶行列式等于 0**。fileciteturn33file0L631-L660

# 一、先看完整题目

方程组

\[
\begin{cases}
ax_1+x_3=1,\\
x_1+ax_2+x_3=0,\\
x_1+2x_2+ax_3=0,\\
ax_1+bx_2=2
\end{cases}
\]

有解。

已知

\[
D_1=
\begin{vmatrix}
a&0&1\\
1&a&1\\
1&2&a
\end{vmatrix}
=4,
\]

求

\[
D_2=
\begin{vmatrix}
1&a&1\\
1&2&a\\
a&b&0
\end{vmatrix}.
\]

fileciteturn33file0L631-L652

---

# 二、第一眼为什么不能直接用克拉默法则？

注意这个方程组是：

\[
\boxed{4\text{ 个方程，}3\text{ 个未知量}}
\]

所以系数矩阵是：

\[
4\times3.
\]

它根本不是方阵。

因此这里不能直接写：

\[
x_i=\frac{D_i}{D}.
\]

这道题真正利用的不是“克拉默公式”，而是：

\[
\boxed{\text{有解}\Rightarrow\text{常数列是系数列的线性组合}}
\]

这是关键。

---

# 三、“方程组有解”怎么翻译成列向量关系？

把方程组写成列的形式。

系数矩阵的三列分别是：

\[
C_1=
\begin{pmatrix}
a\\
1\\
1\\
a
\end{pmatrix},
\qquad
C_2=
\begin{pmatrix}
0\\
a\\
2\\
b
\end{pmatrix},
\qquad
C_3=
\begin{pmatrix}
1\\
1\\
a\\
0
\end{pmatrix}.
\]

常数列：

\[
d=
\begin{pmatrix}
1\\
0\\
0\\
2
\end{pmatrix}.
\]

如果方程组有解 \(x_1,x_2,x_3\)，那就意味着：

\[
x_1C_1+x_2C_2+x_3C_3=d.
\]

也就是说：

\[
\boxed{
d\text{ 是 }C_1,C_2,C_3\text{ 的线性组合}
}
\]

所以四个列向量

\[
C_1,C_2,C_3,d
\]

一定线性相关。

因此把它们并排放成四阶矩阵：

\[
\begin{pmatrix}
a&0&1&1\\
1&a&1&0\\
1&2&a&0\\
a&b&0&2
\end{pmatrix}
\]

它的行列式必为：

\[
\boxed{0}.
\]

所以：

\[
\boxed{
\begin{vmatrix}
a&0&1&1\\
1&a&1&0\\
1&2&a&0\\
a&b&0&2
\end{vmatrix}
=0
}
\]

这就是这道题最关键的一步。MD也是这样处理的。fileciteturn33file0L652-L660

---

# 四、为什么要沿第4列展开？

现在看第4列：

\[
\begin{pmatrix}
1\\
0\\
0\\
2
\end{pmatrix}.
\]

只有两个非零元素。

所以最自然就是：

\[
\boxed{\text{沿第4列展开}}
\]

这样展开出来的两个三阶行列式，恰好就是题目里的 \(D_1,D_2\)。

---

## 第一项：为什么是 \(-D_2\)？

第4列第1个非零元素是：

\[
1.
\]

位置：

\[
(1,4).
\]

代数余子式符号：

\[
(-1)^{1+4}=-1.
\]

删掉第1行、第4列，剩下：

\[
\begin{vmatrix}
1&a&1\\
1&2&a\\
a&b&0
\end{vmatrix}.
\]

这正好就是：

\[
D_2.
\]

所以这一项是：

\[
\boxed{-D_2}.
\]

---

## 第二项：为什么是 \(+2D_1\)？

第4列另一个非零元素是：

\[
2.
\]

位置：

\[
(4,4).
\]

符号：

\[
(-1)^{4+4}=+1.
\]

删掉第4行、第4列，剩下：

\[
\begin{vmatrix}
a&0&1\\
1&a&1\\
1&2&a
\end{vmatrix}.
\]

这就是：

\[
D_1.
\]

所以这一项是：

\[
\boxed{2D_1}.
\]

因此：

\[
0=-D_2+2D_1.
\]

已知：

\[
D_1=4.
\]

所以：

\[
0=-D_2+8.
\]

得到：

\[
\boxed{D_2=8}.
\]

与MD结论一致。fileciteturn33file0L652-L660

---

# 五、这道题真正考的不是计算，而是“有解”两个字

这道题最容易走弯路的地方，是想着：

> 要不要先解 \(x_1,x_2,x_3\)？  
> 要不要先求 \(a,b\)？

其实完全不需要。

题目只要告诉你：

\[
\boxed{\text{方程组有解}}
\]

你就应该想到：

\[
\boxed{
\text{常数列属于系数列张成的空间}
}
\]

也就是：

\[
\boxed{
d=x_1C_1+x_2C_2+x_3C_3
}
\]

从而：

\[
\boxed{
\det(C_1,C_2,C_3,d)=0
}
\]

然后再沿一个稀疏列展开。

这就是MD强调的考研重点：

\[
\boxed{
\text{题目要一个子式时，先找行列式之间的关系}
}
\]

而不是先把所有参数和未知量都求出来。fileciteturn33file0L652-L660

# 六、把这题和上一题连起来

上一道例1.13是：

\[
\boxed{
B\text{ 每列都是 }Ax=0\text{ 的解}
\Rightarrow AB=0
}
\]

这道题则是：

\[
\boxed{
Ax=b\text{ 有解}
\Rightarrow
b\text{ 是 }A\text{ 各列的线性组合}
}
\]

它们本质上都在训练：

\[
\boxed{\text{把“方程组语言”翻译成“列向量关系”}}
\]

这一点非常重要。
