## 二、使用方法与日期关联

> [!important] 打勾标准
> 一个知识项同时满足三点才打勾：①闭卷说出定义、条件与结论；②说明采用的方法及为什么能用；③遮答案完成代表题并核对。看过笔记、记住答案或猜对不算通过。每讲知识点全部覆盖，难点保留未通过标记，不能因赶日期删掉。

数学每天210分钟：**90分钟完整知识复盘＋70分钟独立刷题＋20分钟订正＋30分钟高数维护**。知识90分钟按“定义—条件—性质—方法—例题”展开，并把前日错误的闭卷检查放在开头。知识不熟可占用少量刷题时间，习题欠账登记到补漏栏；高数已完成二轮，不重排18讲学习。

教材例题逐题先判断题眼与入口，不会的遮解完整重做；章末习题按本清单的编号独立完成。数学清单覆盖线代76道章末习题、概率数学一85道章末习题。例题讲解主要在知识块完成，不把每个视频新增题都硬塞进70分钟刷题。

订正20分钟先核对、追因，再独立写正确关键步骤；未完成的订正可占当日刷题块并记录欠账。D+1重做，仍错的D+3复查，D+7混合重测。每项至少保留“题号/位置—错因—漏的条件—正确关键步骤”，不用抄整页解析。

### 第1讲 行列式

笔记：[[数学一/07-讲义/线性代数/01-行列式|本讲完整笔记]]。

#### 完整知识点

- [ ] 定义与基本对象：二、三阶行列式；n阶行列式；排列、逆序数及项的符号；余子式与代数余子式；按行/列展开；某行元素与另一行相应代数余子式乘积之和为0，列同理。
- [ ] 性质：转置；交换行/列变号；倍乘带因子；倍加不变；一行/列全零、两行/列相同或成比例时为零；乘积行列式；行列式与矩阵概念区分。
- [ ] 计算方法：三角形、副对角形、分块三角形、范德蒙德；用行列变换制造零；爪形、X形、行和相等；递推与加边法；含变量行列式的次数、求根和重根；抽象列组合写成矩阵乘积。
- [ ] 应用：余子式和/代数余子式和的反向展开；克拉默法则及方阵、行列式非零条件；齐次方阵非零解与行列式为零的充要关系；从AB=O的非零列读出非零解。
- [ ] 条件验收：一阶行列式不是绝对值；交换与倍乘是否改变值；除含参量前先排除零；克拉默判据不能越过方阵/可逆前提。

#### 代表验收动作

- [ ] 闭卷说明7条性质及展开符号；给出一个倍加不变、一次换行变号的计算例子。
- [ ] 遮答案完成一题具体型、抽象列组合、余子式和题；每步说明变换对行列式值的影响。
- [ ] 做一题含参齐次方程判非零解，说明方阵/行列式条件；例1.1—1.13逐题说入口，习题1.1—1.11独立完成。

### 第2讲 矩阵

笔记：[[数学一/07-讲义/线性代数/02-矩阵|本讲完整笔记]]。

#### 完整知识点

- [ ] 对象与运算：矩阵的形状、相等、零/单位/对角/三角矩阵；加法、数乘、乘法与维度；乘法不交换；转置；对称、反对称、正交矩阵及基本性质。
- [ ] 幂与结构：矩阵正整数次幂；外积与秩一矩阵的降幂；试算A²、A³后递推、奇偶分类；A=λI+N的二项式展开与可交换前提；幂等、幂零结构；分块运算与分块幂。
- [ ] 逆与伴随：可逆定义；可逆/非零行列式/满秩的充要联系；乘积逆的倒序；转置逆；伴随矩阵定义、AA*=|A|I及行列式、秩性质；伴随的可逆、秩n−1、秩≤n−2分支。
- [ ] 初等变换：三种初等行/列变换；初等矩阵；左乘管行、右乘管列；用[A|I]的行变换求逆；行阶梯形与行最简形；矩阵等价。
- [ ] 秩与方程：秩定义、非零子式、阶梯形求秩；同型矩阵等价当且仅当同秩；转置、可逆乘法不改变秩；和、乘积、分块、AB=O的秩关系；矩阵方程整理未知矩阵所在位置，奇异时按列转为线性方程组。
- [ ] 连接与验收：AᵀA的平方和结构与实数前提；满列/满行秩下消去的方向；满秩分解；矩阵平方差不可无条件分解，逆矩阵不能按和拆开。

#### 代表验收动作

- [ ] 给定矩阵形状，判断各乘积有无定义、能否交换/约去；闭卷写可逆与伴随秩的分支。
- [ ] 独立完成初等变换求逆、矩阵方程、含参求秩、高次幂各一题；结果代回乘积或原方程核对。
- [ ] 逐题判例2.1—2.20的方法入口；习题2.1—2.15全做，至少一次完整解释AB=O怎样限制秩。

### 第3讲 向量组

笔记：[[数学一/07-讲义/线性代数/03-向量组|本讲完整笔记]]。

#### 完整知识点

- [ ] 度量：n维向量及运算、内积、长度、夹角、正交；非零正交组线性无关；正交矩阵保持内积与长度。
- [ ] 表示与相关性：线性组合、线性表示；能表示/不能表示/唯一表示；线性相关与无关的定义及齐次方程判定；方阵行列式判定的使用边界；部分组、增加向量、删减向量、增删分量的结论与方向。
- [ ] 秩与极大无关组：极大线性无关组、向量组的秩；行变换找主元列后回原组取向量；表示系数；抽象向量设零组合或写系数矩阵；公共无关组与公共向量；向量解释秩关系、满秩分解。
- [ ] 等价：向量组相互线性表示；等价与相同张成空间；三秩相等；单向表示只给秩不等式，不能擅自变成等价。
- [ ] 数学一内容：向量空间、子空间、基、维数、坐标；换基与过渡矩阵；B=AC时旧坐标=C×新坐标；坐标唯一性的基前提。
- [ ] 正交化：施密特方法先减投影再单位化；先去冗余取基；规范正交基；用内积求坐标必须在该空间中，空间外所得是投影系数。

#### 代表验收动作

- [ ] 给定具体向量组，求秩、极大无关组和其余向量表示系数；主元列回原组取，代回核对。
- [ ] 做一题含参相关/表示、一题两组等价；分别写能表示、唯一表示、无关、等价的充要条件。
- [ ] 做过渡矩阵与坐标变换、施密特正交化各一题，核对乘积方向与内积；例3.1—3.14逐题判入口，习题3.1—3.12全做。

### 第4讲 线性方程组

笔记：[[数学一/07-讲义/线性代数/04-线性方程组|本讲完整笔记]]。

#### 完整知识点

- [ ] 表达与消元：方程/向量/矩阵三种表达；系数矩阵、增广矩阵；初等行变换保持同解；主元、自由变量和参数表示。
- [ ] 齐次方程组：总有零解；只有零解/有非零解的充要条件；解空间维数n−r；基础解系的属于解空间、无关、张成三条件；通解及基础解系求法。
- [ ] 非齐次方程组：比较r(A)、r(A|b)判定相容；有解后按r(A)=n或小于n分唯一/无穷；通解=一个特解+齐次通解；含参数的无解、唯一解、无穷解完整分支。
- [ ] 解的结构：齐次解的线性组合；非齐次解作差；线性组合系数和为0或1分别得到什么；由给定解构造通解与验证是否找到足够独立方向。
- [ ] 公共解与同解：联立、通解代入、令两组通解相等；齐次同解的解空间/行向量组/三秩关系；非齐次同解还必须有共同特解；增添方程是否为原全部解满足的约束。
- [ ] 数学一与综合：平面、直线、点的空间位置与相容、秩、自由度互译；Ax=0与AᵀAx=0；伴随、矩阵乘积与公共解的交叉题。不能只凭两矩阵同秩断言同解。

#### 代表验收动作

- [ ] 独立做含参数方程组，列全无解/唯一/无穷分支；有无穷解时写特解、基础解系、自由参数并代回。
- [ ] 由给定非齐次解构造齐次方向，用秩与独立性证明找全；做公共解与同解题，解释同秩为何不够。
- [ ] 把空间平面位置转成增广秩并说明几何；例4.1—4.15逐题判入口，习题4.1—4.10全做。

### 第5讲 特征值与特征向量

笔记：[[数学一/07-讲义/线性代数/05-特征值与特征向量|本讲完整笔记]]。

#### 完整知识点

- [ ] 定义与计算：Aξ=λξ且ξ≠0；特征多项式、根及代数重数；解(λI−A)x=0得到特征子空间；几何重数、零特征值与不可逆的关系。
- [ ] 性质与转换：特征值和/迹、积/行列式；kA、Aᵏ、f(A)、A⁻¹、A*的特征值；相同特征值对应的非零线性组合；不同特征值向量无关；混合不同特征方向的限制；f(A)=0推出f(λ)=0的单向关系。
- [ ] 相似：定义、P可逆、AP=PB；迹、行列式、秩、特征多项式等必要不变量；同谱不充分；由定义构造变换，或双方化成同一对角矩阵；转置/矩阵多项式与相似变换。
- [ ] 对角化：可对角化当且仅当有n个独立特征向量；每个重根的几何重数=代数重数；通过r(λI−A)验收；P列与Λ元素同序；含参数分类、反求A、求幂、矩阵多项式、抽象向量关系AC=CB。
- [ ] 实对称矩阵：实特征值；不同特征子空间正交；重根子空间施密特正交化和单位化；QᵀAQ=Λ；利用部分特征向量、正交基、外积表示反求矩阵。
- [ ] 验收：代回Aξ=λξ、AP=PΛ；正交矩阵额外核对QᵀQ=I；相似、等价、合同的定义及不变量分清。复杂分块幂、不可对角目标等笔记拓展在核心完整验收后回收。

#### 代表验收动作

- [ ] 独立求一个含重根矩阵的全部特征值/特征子空间，按秩判断对角化；P、Λ列顺序一致并验AP=PΛ。
- [ ] 做矩阵幂/多项式、逆或伴随的特征值、反求矩阵各一题；说出相似各必要条件与为什么不充分。
- [ ] 实对称矩阵正交对角化一题，验QᵀQ=I及AQ=QΛ；例5.1—5.19逐题判入口，习题5.1—5.15全做。

### 第1讲 随机事件与概率

#### 完整知识点

## 七、数据结构维护与跨科区分

- 数据结构已完成二轮，日常20分钟到期复盘内轮换：链表/数组算法边界，栈队列/表达式及矩阵压缩，串/KMP，树遍历/线索/Huffman，图DFS/BFS/MST/Dijkstra/拓扑/关键路径，查找BST/AVL/B树/散列/ASL，排序稳定性/空间/复杂度及过程模拟。无需重新从头刷一遍。
- DS栈/队列是抽象数据结构；组成栈帧保存函数活动记录；OS就绪/阻塞队列保存调度对象。辨认题目中的元素、操作和状态。
- DS Dijkstra求最短路径，Prim/Kruskal求最小生成树；OSPF用最短路径，不能用最小生成树替代路由路径。RIP距离向量更新是另一个过程，BGP包含策略。
- DS算法执行次数对应组成IC，但运行时间还受CPI、主频、局部性和访存停顿影响；数组连续访问、指针追踪的Cache行为不同。
- 组成Cache/主存主要解释硬件访问、映射与时间；OS页表/虚拟内存主要解释地址空间、保护、缺页与资源分配。共同题必须统一页大小、块大小、地址位宽和编址单位。
- TLB缓存PTE映射，Cache缓存指令/数据，页表保存映射和状态；TLB未命中不等于缺页，Cache未命中不等于缺页。先译址再按题设Cache组织计算，页内偏移不变。
- Cache替换的候选集合由直接/组相联/全相联映射限制；页面置换的候选集合由OS页框分配策略决定。两者可以都用LRU，不能把“组”和“页框”当同一单位。
- CPU数据通路/流水线中断描述硬件响应和指令可见结果；OS中断描述内核控制、系统调用与进程状态。缺页处理通常修复后重执行故障指令。
- 组成DMA关注接口、总线/主存争用、CPU开销；OS I/O关注软件层、设备分配、缓冲与阻塞唤醒。磁盘本身时间与磁盘调度总移动量分别计算。
