## 一、图的基本概念（视频055，★★★★ 概念公式必背）

### 1.1 图的定义

图 $G$ 由**顶点集 $V$** 和**边集 $E$** 组成：$G=(V,E)$。

- 顶点数 $|V|$ 称为图的**阶**；
- 一条边连接的两个顶点**必须都在顶点集 $V$ 中**（两头都必须连着顶点，否则不是图）；
- **图不能是空图**：顶点集 $V$ **必须非空**，但边集 $E$ **可以为空**（对比：线性表可以是空表，树可以是空树，图不行——没有顶点的"空图"无意义）。

> [!note] 视频类比
> 微信好友关系是无向图（好友是相互的），微博关注是有向图（我关注你≠你关注我），铁路/公路网也是图。图就是描述"多对多"关系的逻辑结构。

### 1.2 无向图与有向图

| | 无向图 | 有向图 |
|---|---|---|
| 边 | 无向边（边），圆括号 $(v,w)$ | 有向边（弧），尖括号 $\langle v,w\rangle$ |
| 方向 | $(v,w)$ 与 $(w,v)$ 等价 | $\langle v,w\rangle$ 与 $\langle w,v\rangle$ 是**两条相反的弧** |
| 端点 | 两个端点 | **弧尾**（无箭头端）、**弧头**（箭头端） |

### 1.3 简单图与多重图

- **简单图**：不存在重复边 + 不存在顶点到自身的边（自环）；
- **多重图**：与简单图相对（有重边或自环）。
- **数据结构这门课默认只讨论简单图**（微信好友不可能加两次，也不可能自己加自己）。

### 1.4 顶点的度（★★★ 公式必背）

- **无向图**：顶点的度 = 依附于该顶点的边数，记 $TD(v)$。
- **有向图**：**入度** = 指向该顶点的弧数；**出度** = 从该顶点发射的弧数；度 = 入度 + 出度。

**度数定理（选择题直接考）**：

$$
\boxed{\text{无向图}\ \sum d(v)=2|E|}
$$

$$
\boxed{\text{有向图}\ \sum d^+(v)=\sum d^-(v)=|E|}
$$

> [!warning] 推理方式（视频强调）
> 无向图每条边给两个端点各贡献 1 度；有向图每条弧给弧头贡献 1 入度、给弧尾贡献 1 出度。所以"所有顶点的度之和一定是偶数"，这个性质可以用来排查选择题答案。

### 1.5 路径、回路、距离

| 术语 | 含义 |
|------|------|
| **路径** | 顶点序列；无向图可双向走，**有向图路径方向必须与弧的方向一致** |
| **回路（环）** | 第一个顶点与最后一个顶点相同的路径 |
| **简单路径** | 路径中所有顶点**不重复** |
| **简单回路** | 除首尾外其余顶点不重复的回路 |
| **路径长度** | 路径上**边的条数** |
| **距离** | 两点间**最短路径的长度**；无路径则距离为 $\infty$ |

> [!warning] 方向坑
> 无向图中 a 到 d 的距离 = d 到 a 的距离；有向图中 a 能到 e，但 e 不一定能到 a（距离为 $\infty$）。

### 1.6 连通性（★★★ 边数上下界是高频选择）

| 概念 | 定义 | 关键考点 |
|---|---|---|
| **连通**（无向） | 两顶点间有路径 | 连通图 = 任意两顶点连通 |
| **强连通**（有向） | 两顶点**双向**都有路径 | 强连通图 = 任意两顶点强连通 |
| **连通图** | 任意两顶点连通的无向图 | **最少 $n-1$ 条边** |
| **非连通图** | 不是连通图 | **最多 $C_{n-1}^2$ 条边**（n-1 个顶点构成完全图，剩 1 个孤立） |
| **强连通图** | 任意两顶点强连通的有向图 | **最少 $n$ 条边**（形成一个大环，$n>1$） |

> [!important] 记忆公式（视频反复强调的两个高频考点）
> 1. **n 个顶点的连通无向图至少 $n-1$ 条边**（树就是连通图的边数下界）；
> 2. **n 个顶点的非连通无向图最多 $C_{n-1}^2$ 条边**——先让 n-1 个顶点两两相连（完全图），再留 1 个孤立顶点，此时再加任意一条边就变连通了；
> 3. **n 个顶点的强连通有向图至少 $n$ 条边**——让 n 个顶点首尾相接成一个环，从任何顶点出发都能绕一圈到达其他所有顶点。

### 1.7 子图、连通分量、生成树（★★★ 概念辨析）

- **子图**：从原图中取顶点子集 + 边子集构成的图（**边连接的两个顶点必须都在子图顶点集里**）。
- **生成子图**：**包含原图全部顶点**的子图（可以删边，不能删顶点）。
- **连通分量**（无向）：**极大**连通子图——不仅要连通，还要"尽可能多地包含顶点和边"。
- **强连通分量**（有向）：**极大**强连通子图。
- **生成树**（连通无向图）：**极小**连通子图——包含全部顶点，边数最少（$n$ 个顶点 $n-1$ 条边）；多一条边必成环，砍一条边必不连通。
- **生成森林**：非连通图各连通分量的生成树合在一起。
- 一个连通图的生成树**可以有多个**。

> [!note] 视频类比
> 生成树的现实意义：6 个村子修路，让所有村子连通且路最少 → 先求各种生成树方案，再结合每条路的造价挑最优（这就是后面最小生成树问题的雏形）。

### 1.8 带权图与带权路径长度

- **带权图（网）**：边（弧）上带**权值**的图；
- **带权路径长度**：路径上所有边权之和（如北京→天津 200 + 天津→上海 600 = 800 公里）。

### 1.9 特殊形态的图（★ 记公式）

| 形态 | 边数/特征 |
|---|---|
| **无向完全图** | 任意两顶点间都有边：$C_n^2=\dfrac{n(n-1)}{2}$ 条边 |
| **有向完全图** | 任意两顶点间有**方向相反的两条弧**：$n(n-1)$ 条边 |
| **稀疏/稠密图** | 相对概念，无绝对界限（参考：$|E|<\lvert V\rvert\log\lvert V\rvert$ 可视为稀疏） |
| **树**（无向） | 连通且无回路的图，$n$ 个顶点 $n-1$ 条边；**边数 $>n-1$ 必有回路** |
| **有向树** | 一个顶点入度为 0（根）+ 其余顶点入度为 1；**有向树不是强连通图** |

## 二、邻接矩阵法（视频056，★★★★ 存储必背）

### 2.1 基本思想

用**一维数组**存顶点信息，用**二维数组**存边（邻接）信息：

- 无向图：$a[i][j]=a[j][i]=1$ 表示顶点 $i$、$j$ 之间有边（**每条边对应两个 1**）；
- 有向图：$a[i][j]=1$ 表示存在弧 $\langle i,j\rangle$（**每条弧对应一个 1**）；
- 0 表示无边。顶点编号（数组下标）与矩阵行列一一对应。

```c
// 邻接矩阵存储结构（教材写法，图最多 MAXV 个顶点）
#define MAXV 100         // 最大顶点数
typedef struct {
    int numVertices, numEdges;   // 当前顶点数、边数
    char VerticesList[MAXV];     // 顶点表（存顶点信息）
    int Edge[MAXV][MAXV];        // 邻接矩阵（0/1 或权值）
} MGraph;
```

> [!note] 视频提醒
> 只存 0/1 时可以用 bool 或枚举类型代替 int，把矩阵缩小到 1/4 大小；写 int 也没错，考试不扣分。

### 2.2 求度（★ 必会）

- **无向图**：遍历顶点 $i$ 对应的**行或列**，数非零元素个数 = 度，$O(n)$；
- **有向图**：第 $i$ 行非零个数 = **出度**；第 $i$ 列非零个数 = **入度**；行+列 = 度。

### 2.3 带权图（网）

- 对应位置存**权值**；不存在边的地方存 $\infty$（代码里常用 `#define INF 0x7fffffff` 即 int 最大值）；
- 自己到自己可设 0（做最短路时 $D[i][i]=0$ 是标准做法）。

### 2.4 性能与性质

- **空间复杂度 $O(n^2)$**，只与顶点数有关 → **适合稠密图**；顶点多边少时浪费严重；
- 无向图矩阵**对称**，可用对称矩阵压缩存储（只存上/下三角）；
- 判断任意两顶点是否有边：**$O(1)$**（这是邻接矩阵的最大优势）。

### 2.5 矩阵的幂（★★★ 选择题爱考）

设图 $G$ 的邻接矩阵为 $A$，则：

$$
\boxed{A^n\text{ 中元素 }a^{(n)}_{ij}=\text{从顶点 }i\text{ 到顶点 }j\text{ 长度为 }n\text{ 的路径数目}}
$$

> [!tip] 理解方式（视频逐步拆解）
> $A^2 = A \times A$ 中 $a^{(2)}_{ij}=\sum_k a_{ik}a_{kj}$：$a_{ik}=1$ 表示 i→k 有边，$a_{kj}=1$ 表示 k→j 有边，两个 1 相乘 = 1 表示"i 经 k 到 j 长度为 2 的路径存在一条"。把所有中间顶点 k 加起来，就是长度为 2 的路径总数。$A^3$ 依此类推。

## 三、邻接表法（视频057，★★★★ 存储必背）

### 3.1 基本思想

**顺序存储（顶点表）+ 链式存储（边表）**，其实就是树的**孩子表示法**：

- 顶点表：一维数组，每个元素 = 顶点数据 + 指向第一条边/弧的指针；
- 边表：链表，每个边结点存"邻接顶点编号"（+ 权值），顺着指针可找到该顶点的所有邻接点。

```c
// 邻接表存储结构（教材写法）
typedef struct ArcNode {           // 边/弧结点
    int adjvex;                    // 该边指向的顶点编号
    struct ArcNode *next;          // 指向下一条边
    // InfoType info;              // 边权值（带权图才需要）
} ArcNode;

typedef struct VNode {             // 顶点结点
    char data;                     // 顶点信息
    ArcNode *first;                // 指向第一条边
} VNode;

typedef struct {
    VNode adjlist[MAXV];           // 顶点表（数组）
    int n, e;                      // 当前顶点数、边数
} ALGraph;
```

### 3.2 无向图 vs 有向图

| | 无向图 | 有向图 |
|---|---|---|
| 边结点数 | **每条边对应 2 个边结点**（双向各存一次，冗余） | 每条弧对应 1 个边结点 |
| 空间 | $O(n+2e)=O(n+e)$ | $O(n+e)$ |
| 求度 | 遍历该顶点的边表即可，方便 | 出度方便（边表）；**入度要遍历整个邻接表**，麻烦 |

> [!warning] 关键结论（选择题直接考）
> 1. 用邻接表存**无向图**时，边数 $e$ 只算一次，但边结点有 **$2e$ 个**；
> 2. **有向图找入度、找入边不方便**（必须遍历整个表）——这是邻接表存有向图的最大缺点，十字链表就是为解决这个问题而生的；
> 3. **一个图的邻接矩阵表示唯一，但邻接表表示不唯一**（各边表中邻接点的次序可任意）——这直接影响 BFS/DFS 遍历序列是否唯一。

### 3.3 适用场景

邻接矩阵空间 $O(n^2)$ 适合稠密图；邻接表空间 $O(n+e)$ **适合稀疏图**（边少时省空间），稠密图用邻接表也 OK。

## 四、十字链表、邻接多重表（视频058，★★★ 了解特性即可）

> [!note] 视频明确说明：这两种存储结构**代码逻辑复杂，考研不会要求手写实现**，只需要理解特性、会做选择题。

### 4.1 十字链表（存有向图）

同时解决"邻接矩阵空间大"和"邻接表找入边麻烦"两个问题：

- **顶点结点**：data + firstin（指向第一条入边）+ firstout（指向第一条出边）；
- **弧结点**：tailvex（弧尾）、headvex（弧头）、hlink（指向弧头相同的下一条弧）、tlink（指向弧尾相同的下一条弧）、info（权值）；
- 顺着 firstout/hlink 链可找**出边**，顺着 firstin/hlink 链可找**入边**，找入边入度 $O(1)$ 起步、非常方便；
- 空间复杂度 $O(n+e)$，与邻接表同数量级。

### 4.2 邻接多重表（存无向图）

解决邻接表存无向图的"每条边两份冗余数据、删边删顶点麻烦"问题：

- **边结点**：ivex、jvex（两个端点）+ ilink（指向下一条与 ivex 相连的边）+ jlink（指向下一条与 jvex 相连的边）+ info（权值）；
- **每条边只用一个边结点**（一份数据），同时挂在两个端点的边链上；
- 删除边：找到边结点，改两个指针即可，方便；删除顶点：删掉该顶点及其边链上所有边结点，也方便；
- 空间 $O(n+e)$，比邻接表（$2e$ 个边结点）更省。

### 4.3 总结对比（★ 记结论）

| 存储结构 | 适用 | 解决什么问题 | 表示是否唯一 |
|---|---|---|---|
| 邻接矩阵 | 稠密图 | 判边 $O(1)$ | **唯一** |
| 邻接表 | 稀疏图 | 空间 $O(n+e)$ | **不唯一** |
| 十字链表 | 有向图 | 邻接表找入边麻烦 | **不唯一** |
| 邻接多重表 | 无向图 | 邻接表删边/删顶点麻烦 | **不唯一** |

## 五、图的基本操作（视频059，★★★ 理解复杂度）

考研最常考的存储是**邻接矩阵和邻接表**，本节讨论这两个结构下基本操作的实现与复杂度。

| 操作 | 邻接矩阵 | 邻接表 |
|---|---|---|
| 判断边 $(x,y)$ 是否存在 | **$O(1)$**（查元素） | $O(1)\sim O(V)$（扫描 x 的边表） |
| 列出与 x 相连的所有边 | $O(V)$（扫一行） | $O(1)\sim O(V)$（扫边表） |
| 插入顶点 | $O(1)$（数组末尾写入） | $O(1)$ |
| 删除顶点 | $O(V)$（行、列置 0 + 标记空顶点） | 无向最坏 $O(E)$；有向删入边需遍历全表 |
| 增加一条边 | $O(1)$ | $O(1)$（**头插法**） |
| 求第一个邻接点 | $O(V)$（扫行找第一个 1） | $O(1)$（边表第一个结点） |
| 求下一个邻接点 | $O(V)$ | $O(1)$ |
| 设置/获取边权值 | 同"判断边是否存在" | 同"判断边是否存在" |

> [!important] 视频强调（遍历算法的地基）
> 考研中用得最多的就是两个操作：**FirstNeighbor（第一个邻接点）** 和 **NextNeighbor（下一个邻接点）**——它们是 BFS/DFS 遍历的核心工具。删除顶点用"置空标记"而不是移动大量元素，是邻接矩阵下的标准思路。

## 六、图的广度优先遍历 BFS（视频060，★★★★★ 必须能手写）

### 6.1 核心思想

**树的层序遍历的推广**：从某顶点出发，先访问它，再按"离起点由近到远"的层次依次访问。需要**辅助队列** + **visited 数组**（防止环路导致重复访问，图和树的最大区别）。

```c
// 广度优先遍历（伪代码骨架，教材口径）
bool visited[MAXV];                       // 访问标记数组（初始全 false）
void BFS(ALGraph G, int v) {
    visit(v);                             // 访问顶点 v
    visited[v] = true;                    // ★ 标记已访问
    EnQueue(Q, v);                        // v 入队
    while(!isEmpty(Q)) {                  // 队列非空
        DeQueue(Q, u);                    // 队头出队
        for(w = FirstNeighbor(G,u); w >= 0; w = NextNeighbor(G,u,w)) {
            if(!visited[w]) {             // 邻接点未被访问
                visit(w);
                visited[w] = true;        // ★ 入队前标记（防止重复入队）
                EnQueue(Q, w);
            }
        }
    }
}
```

### 6.2 非连通图的处理（★★★ 最容易漏）

一次 BFS 只能访问一个连通分量。要遍历整个非连通图，需在外层套一个 for 循环：

```c
void BFSTraverse(ALGraph G) {
    for(i = 0; i < G.n; i++) visited[i] = false;  // 初始化
    for(i = 0; i < G.n; i++)
        if(!visited[i]) BFS(G, i);                 // 每个未访问顶点都启动一次 BFS
}
```

**关键结论：无向图调用 BFS 的次数 = 连通分量的个数**；连通图只需调用一次。

### 6.3 复杂度（★ 背结论）

| 存储结构 | 空间 | 时间 |
|---|---|---|
| 邻接矩阵 | $O(V)$（辅助队列） | $O(V^2)$（访问顶点 $O(V)$ + 每行扫 $O(V)$，共 $V$ 行） |
| 邻接表 | $O(V)$ | $O(V+E)$（访问顶点 $O(V)$ + 遍历所有边结点 $O(2E)=O(E)$） |

> [!tip] 视频提醒（分析遍历算法复杂度的方法）
> BFS/DFS 的时间开销主要来自"**访问顶点**"+"**探索边**"两部分，拆开算再结合存储结构，不要死盯最深层循环次数（边数为 0 时最深层循环执行 0 次，但顶点仍要访问 $O(V)$）。

### 6.4 遍历序列是否唯一（★★★ 选择题高频）

- **邻接矩阵存储：遍历序列唯一**（矩阵表示唯一）；
- **邻接表存储：遍历序列不唯一**（边表次序任意）。

### 6.5 广度优先生成树/森林

- BFS 过程中，**每个顶点第一次被访问时经过的那条边**标红，去掉其他边 → **广度优先生成树**；
- 非连通图各连通分量分别生成 → **广度优先生成森林**；
- 矩阵存储生成树唯一；邻接表存储不唯一。

> [!note] 视频练习结论
> 有向图 BFS 不一定能一次访问完所有顶点（从入度大的顶点出发可能只能访问一小片）；强连通图从任何顶点出发都能一次访问完。

## 七、图的深度优先遍历 DFS（视频061，★★★★★ 必须能手写）

### 7.1 核心思想

**树的先根遍历的推广**：先访问顶点，再递归访问它的邻接点（一条路走到黑，走不动了再回头）。递归实现 + visited 数组。

```c
// 深度优先遍历（伪代码骨架，教材口径）
void DFS(ALGraph G, int v) {
    visit(v);                             // 访问顶点 v
    visited[v] = true;                    // 标记已访问
    for(w = FirstNeighbor(G,v); w >= 0; w = NextNeighbor(G,v,w)) {
        if(!visited[w]) DFS(G, w);        // ★ 递归访问未访问的邻接点
    }
}

// 非连通图处理：外层 for 循环，调用次数 = 连通分量数
void DFSTraverse(ALGraph G) {
    for(i = 0; i < G.n; i++) visited[i] = false;
    for(i = 0; i < G.n; i++)
        if(!visited[i]) DFS(G, i);
}
```

### 7.2 复杂度（★ 背结论，和 BFS 相同）

| 存储结构 | 空间 | 时间 |
|---|---|---|
| 邻接矩阵 | $O(V)$（**递归工作栈**） | $O(V^2)$ |
| 邻接表 | $O(V)$ | $O(V+E)$ |

> [!note] 区分记忆
> BFS 的辅助空间是**队列**，DFS 的辅助空间是**递归工作栈**——这是两者空间开销来源的区别，选择题爱考。

### 7.3 深度优先生成树/森林

DFS 中"第一次发现顶点"经过的边标红 → 深度优先生成树；非连通图 → 深度优先生成森林。邻接表存储时序列和生成树**不唯一**。

### 7.4 图遍历与连通性（★★★ 选择题高频结论）

- **无向图**：调用 BFS/DFS 的次数 = **连通分量数**；连通图调用 1 次；
- **有向图**：从某顶点出发能否一次遍历完取决于该顶点能否到达所有顶点；**强连通图从任何顶点出发都只需调用 1 次**。

## 八、最小生成树 MST（视频062，★★★★ 手算必会）

### 8.1 概念

- **生成树**：连通无向图包含全部顶点的极小连通子图（$n$ 个顶点 $n-1$ 条边）；
- **最小生成树（MST）**：带权连通无向图中，**边权之和最小**的生成树；
- **最小生成树可能不唯一**（比如所有边权都相等时），但所有 MST 的**边权总和一定相等且最小**；
- 若图本身是树，则 MST 就是它自身；非连通图没有生成树，只有生成森林。

> [!warning] 研究对象
> MST 问题只针对**带权的连通无向图**。不连通 → 无 MST。

### 8.2 Prim 算法（每次选一个顶点，O(V²)，适合稠密图）

**思想**：从任意一个顶点开始，每次从"已纳入集合"与"未纳入集合"之间**选权值最小的边**，把新顶点并入集合，直到所有顶点都纳入。

```
手算步骤（视频演示）：
1. 任选一个起点加入生成树；
2. 在"树内顶点 ↔ 树外顶点"的所有边中，选权值最小的一条；
3. 把这条边另一端的顶点并入树；
4. 重复 2~3 直到所有顶点入树（共 n-1 次）。
```

实现思路：用 `isJoin[]` 标记是否入树 + `lowCost[]` 记录各顶点加入当前树的最小代价；每轮选最小 lowCost 顶点入树，再更新其他顶点的 lowCost（与新入树顶点的边权比较取小）。

**时间复杂度 $O(V^2)$**（$n-1$ 轮 × 每轮扫描数组 $O(n)$），与边数无关 → **适合稠密图**。

### 8.3 Kruskal 算法（每次选一条边，O(ElogE)，适合稀疏图）

**思想**：把所有边按权值**从小到大排序**，依次检查每条边，**只要两端的顶点当前不连通就选它**（连通则跳过），直到选出 $n-1$ 条边。

```
手算步骤（视频演示）：
1. 所有边按权值递增排序；
2. 从最小权值的边开始，逐条检查；
3. 若边的两个端点当前不在同一个连通集合中 → 选它，合并两个集合；
4. 若已在同一集合（选它会成环）→ 跳过；
5. 直到选出 n-1 条边，所有顶点连通。
```

判环用**并查集**（第5章学过）：初始每个顶点独立成集，选边时判断两端是否同集，不同则 Union。

**时间复杂度 $O(E\log E)$**（排序主导），与顶点数关系不大 → **适合稀疏图**。

> [!important] 对比记忆（选择题必考）
> | | Prim | Kruskal |
> |---|---|---|
> | 策略 | 每次**选一个顶点** | 每次**选一条边** |
> | 适用 | **稠密图**（边多） | **稀疏图**（边少） |
> | 复杂度 | $O(V^2)$ | $O(E\log E)$ |

## 九、最短路径：BFS 求无权图单源最短路（视频063，★★★★）

### 9.1 适用场景

**无权图**（可看作每条边权值都是 1）的**单源最短路径**。BFS 按层扩展的特性天然保证：**第一次访问到某顶点时，经过的边数就是最短路径长度**。

### 9.2 算法改造（在 BFS 基础上加两个数组）

- `d[]`：记录源点到各顶点的最短路径长度（初始 $\infty$，源点 $d[u]=0$）；
- `path[]`：记录各顶点在最短路径上的**直接前驱**（初始 -1）。

访问邻接点 v 时：

$$
d[v]=d[u]+1,\qquad path[v]=u
$$

### 9.3 路径还原（★ 会查数组）

求源点到目标顶点的最短路径：从 `path[]` 中**从目标顶点逆向**逐个找前驱，直到回到源点，再倒序输出。

> [!note] 与广度优先生成树的联系
> 以源点为根的广度优先生成树中，每个顶点所在的层数 = 源点到它的最短距离；BFS 生成树的高度（深度）是最小的。

## 十、最短路径：Dijkstra 算法（视频064，★★★★★ 手算必会）

### 10.1 适用场景

**带权图（权值非负）的单源最短路径**。带权路径长度 = 路径上所有边权之和。BFS 只适用于无权图，带权图必须用 Dijkstra。

### 10.2 三个数组（★ 记含义）

- `final[]`（或 S）：标记顶点是否**已确定最短路径**（初始只有源点为 true）；
- `dist[]`：目前找到的从源点到各顶点的**最短路径长度**（初始为源点直接出边的权，无出边为 $\infty$，源点自身为 0）；
- `path[]`：各顶点最短路径上的**直接前驱**（初始：与源点直接相连的顶点 path=源点，其余 -1）。

### 10.3 执行过程（手算步骤）

```
1. 初始化三个数组；
2. 循环 n-1 轮：
   a. 在"未确定最短路径"的顶点中，选 dist 最小的顶点 u；
   b. 把 u 的 final 置为 true（确定 u 的最短路径）；
   c. 松弛：检查 u 的所有出边 (u,v,w)，若 dist[u]+w < dist[v]，
      则更新 dist[v] = dist[u]+w，path[v] = u；
3. 通过 path[] 从目标顶点逆向还原路径。
```

### 10.4 复杂度与限制（★★★ 必考）

- **时间复杂度 $O(V^2)$**（邻接矩阵实现；$n-1$ 轮 × 每轮扫数组找最小 $O(n)$ + 扫行松弛 $O(n)$）；
- 与 Prim 的**执行过程高度相似**（都是每轮选最小、再更新），所以复杂度相同；
- **不能处理负权值边**：一旦某顶点被"确定"最短路径，后续发现负权边可能把它改小，但算法不会回头修改已确定的顶点。

> [!warning] 负权边失效例子（视频：吃鸡跑毒/电动车下坡）
> 顶点 0→2 权 7，0→1 权 10，1→2 权 -5。直接 0→2 是 7，但 0→1→2 总长 10+(-5)=5 更短。Dijkstra 会先确定 dist[2]=7，之后再发现经过 1 的路径更短时已经来不及改了。所以 Dijkstra 只适用于**非负权图**。

> [!note] 视频彩蛋
> Dijkstra 是 1972 年图灵奖得主，考研里他的成果还有：goto 有害论（OS 虚拟存储）、信号量与 PV 原语（OS 进程同步，每年大题）、银行家算法、哲学家进餐问题——都是高频考点。

## 十一、最短路径：Floyd 算法（视频065，★★★★ 理解+手算）

### 11.1 适用场景

**所有顶点对之间的最短路径**（全源最短路）。利用**动态规划**思想，把问题分成 n 个阶段：第 k 阶段只允许编号 $\le k$ 的顶点作为中转点。

### 11.2 核心递推（★ 背公式）

$$
A^{(k)}[i][j]=\min\left\{A^{(k-1)}[i][j],\ A^{(k-1)}[i][k]+A^{(k-1)}[k][j]\right\}
$$

- $A^{(0)}$ = 邻接矩阵（不允许中转点）；
- 第 $k$ 轮：考虑允许顶点 $k$ 作为中转点，逐个检查矩阵所有元素；
- 同时用 `path` 矩阵记录"中转点"（初始全 -1，一旦更新就记 $k$）。

### 11.3 核心代码（只有 6 行，★ 能默写）

```c
// 核心代码（教材口径）：k 必须是最外层循环
for(k = 0; k < n; k++)                       // 中转点
    for(i = 0; i < n; i++)                   // 起点
        for(j = 0; j < n; j++)               // 终点
            if(A[i][k] + A[k][j] < A[i][j]) {
                A[i][j] = A[i][k] + A[k][j]; // 更新最短距离
                path[i][j] = k;              // 记录中转点
            }
```

### 11.4 复杂度与限制（★★★ 必考）

- 时间 $O(V^3)$、空间 $O(V^2)$；
- **允许负权值边**（Dijkstra 不行），但**不能有负权值回路**（否则每绕一圈路径更短，最短路径不存在；表现为最终 $A[i][i]<0$）；
- 手算题**最多三到四阶矩阵**（$5^3=125$ 次检查在考场上没有意义）。

> [!important] 三种最短路径算法总结（★ 背结论）
> | 算法 | 问题 | 适用条件 | 复杂度 |
> |---|---|---|---|
> | BFS | 单源 | 无权图 | $O(V^2)$（矩阵）/ $O(V+E)$（表） |
> | Dijkstra | 单源 | 边权**非负** | $O(V^2)$ |
> | Floyd | 全源 | 可含负边、**无负环** | $O(V^3)$ |
>
> 三种算法都不能处理**负权回路**。Dijkstra 求全源可重复 n 次，复杂度同为 $O(V^3)$。

## 十二、有向无环图描述表达式（视频066，★★★★ 会做题）

### 12.1 DAG 概念

**有向无环图（DAG）** = 不存在环路的有向图。表达式树存在大量**公共子式**，用 DAG 合并重复子树可以**节省存储空间**。

### 12.2 真题题型（2019 考过）

"用 DAG 描述表达式 $(a+b)*(b*(c+d))+(c+d)*e$，最少需要多少个顶点？"——关键是**把所有重复的公共子式合并干净**，最容易错的就是漏合并操作数本身（如两个 x 也可以合并成一个）。

### 12.3 做题方法（★ 视频自创套路，好用）

```
1. 操作数不重复地排成一排（x、y 各一个顶点）；
2. 给每个运算符标上"生效顺序"编号（防止遗漏）；
3. 按生效顺序分层构造：运算符放在它的操作数所在层的上一层
   （依赖下层运算结果的运算符放更高层）；
4. 自底向上逐层检查同一层的运算符，操作数相同的合并。
```

> [!warning] 为什么只合并同层的运算符？
> 底层运算符的操作数是具体数值，上层运算符的操作数含复合表达式，两者结构不同，不可能合并。所以**分层**是为了合并时不乱、不漏。

> [!note] 结论
> 同一个表达式对应的 DAG **形态不唯一**（运算符生效顺序不同，层数可能不同），但考研只考"最少顶点数"这类确定性问题，用上面的方法即可稳拿。

## 十三、拓扑排序（视频067，★★★★★ 手算+代码）

### 13.1 AOV 网

**AOV 网**（Activity On Vertex）：用**顶点表示活动**、**有向边表示活动之间的先后关系**的图（如做番茄炒蛋：买菜→洗番茄→切番茄）。

- AOV 网**一定是 DAG**：若存在环，"切番茄之前要洗番茄，洗番茄之前又要切番茄"，工程永远无法推进；
- **拓扑排序**：找到做这些活动的一个可行先后顺序。

### 13.2 拓扑排序步骤（手算）

```
1. 从图中选一个入度为 0 的顶点输出；
2. 删除该顶点及其所有出边（逻辑删除：邻接点入度 -1）；
3. 重复 1~2 直到图空（成功）或找不到入度为 0 的顶点（说明有环，失败）。
```

- 拓扑序列**可能不唯一**（存在多个入度为 0 的顶点时可任选其一）；
- **有环图不存在拓扑序列**——所以拓扑排序也常用来**判断图是否有环**。

### 13.3 算法实现（★ 会写骨架）

```c
// 拓扑排序（邻接表，教材口径）
bool TopologicalSort(ALGraph G) {
    InitStack(S);                                  // 栈存当前入度为 0 的顶点（队列也行）
    for(i = 0; i < G.n; i++)                       // 初始化：入度为 0 的顶点入栈
        if(indegree[i] == 0) Push(S, i);
    int count = 0;                                 // 记录已输出的顶点数
    while(!isEmpty(S)) {
        Pop(S, i);                                 // 弹出入度为 0 的顶点
        print[i] = ++count;                        // 记录拓扑序列
        for(p = G.adjlist[i].first; p; p = p->next) {
            v = p->adjvex;                         // 邻接点
            if(--indegree[v] == 0) Push(S, v);    // ★ 入度减为 0 则入栈
        }
    }
    return count == G.n;                           // count < n 说明有环，排序失败
}
```

- 时间：邻接表 $O(V+E)$（每个顶点处理一次 + 每条边遍历一次）；邻接矩阵 $O(V^2)$（扫全矩阵找边）；
- 用**栈或队列**均可，不影响结果正确性，只影响序列形态。

### 13.4 逆拓扑排序（★★ 了解）

- 每次选**出度为 0** 的顶点输出并删除其入边，重复；
- 可用 **DFS 实现**：在递归返回（顶点出栈）时输出该顶点，得到的序列就是逆拓扑序列（视频067演示过：先递归到底，退栈时依次输出）。

> [!warning] 实现坑
> 逆拓扑排序若用邻接表找"指向某顶点的边"需要遍历全表，效率低；用**邻接矩阵**扫对应列更方便，或建**逆邻接表**。

## 十四、关键路径（视频068，★★★★★ 手算必会）

### 14.1 AOE 网

**AOE 网**（Activity On Edge）：用**边表示活动**、**顶点表示事件**，边权 = 活动耗时。

- **源点**（开始顶点）：唯一入度为 0 的顶点；**汇点**（结束顶点）：唯一出度为 0 的顶点；
- 两条规则：①事件发生后，从它出发的活动才能开始；②**进入某顶点的所有活动都结束后**，该事件才会发生；
- 有的活动可并行（打鸡蛋和洗番茄），有的必须串行（洗番茄→切番茄）。

### 14.2 关键路径与关键活动

- **关键路径**：源点到汇点的**最长路径**；其长度 = **整个工程的最短完成时间**；
- **关键活动**：关键路径上的活动，**不能拖延**（一拖延整个工期就延长）。

### 14.3 四个量（★ 公式必背）

设活动 $a_i=\langle j,k\rangle$（从事件 $j$ 到事件 $k$），权为 $w(j,k)$：

| 量 | 含义 | 公式 |
|---|---|---|
| $ve[k]$ | 事件 $k$ 的**最早发生时间** | 拓扑序正向：$ve[k]=\max\{ve[j]+w(j,k)\}$（多个前驱取 max），$ve[源]=0$ |
| $vl[k]$ | 事件 $k$ 的**最迟发生时间** | 逆拓扑序反向：$vl[k]=\min\{vl[j]-w(k,j)\}$（多个后继取 min），$vl[汇]=ve[汇]$ |
| $e[i]$ | 活动 $a_i$ 的**最早开始时间** | $e[i]=ve[j]$（弧尾事件的最早发生时间） |
| $l[i]$ | 活动 $a_i$ 的**最迟开始时间** | $l[i]=vl[k]-w(j,k)$（弧头事件的最迟时间减权值） |

**时间余量** = $l[i]-e[i]$；**时间余量为 0 的活动就是关键活动**；由关键活动连成的路径就是关键路径。

### 14.4 手算步骤

```
1. 对 AOE 网做拓扑排序，按拓扑序正向求所有事件 ve（取 max）；
2. 汇点 vl = ve，按逆拓扑序反向求所有事件 vl（取 min）；
3. 对每条活动算 e = ve[弧尾]，l = vl[弧头] - 权；
4. 时间余量 = l - e，为 0 的活动是关键活动；
5. 由关键活动组成的路径即关键路径。
```

> [!note] 视频记忆口诀
> 事件最早 ve：**拓扑序正向、取大**（所有前驱活动都完成才能发生）；事件最迟 vl：**逆拓扑序反向、取小**（所有后继活动都来得及）；活动最早 e = **弧尾**的 ve；活动最迟 l = **弧头**的 vl 减权。

### 14.5 关键活动与关键路径的性质（★★★ 选择题爱考）

1. 关键活动耗时增加 → **总工期增加**；
2. 缩短关键活动时间 → 可缩短总工期；
3. **关键活动缩短到一定程度会变成非关键活动**（另一条路径成为新的关键路径），此时再压缩它不再缩短工期；
4. **可能存在多条关键路径**：只提高其中一条路径上关键活动的速度，**不一定缩短总工期**（其他关键路径仍是瓶颈）；必须同时压缩所有关键路径上的活动，或压缩**包含在所有关键路径中的公共活动**。

### 15.4 易错点清单

1. **图不能是空图**（顶点集非空），但边集可以为空；树可以空树。
2. 无向图一条边在邻接表里存 **2 个边结点**，边数只算 1 次；求边数别把 2E 当 E。
3. **连通图至少 n-1 条边**（树）；**非连通图最多 C(n-1,2) 条边**；**强连通图至少 n 条边**——三条结论别混。
4. 有向树的根入度为 0、其他入度为 1，但**有向树不是强连通图**。
5. 邻接矩阵表示**唯一**，邻接表表示**不唯一** → 遍历序列唯一性随之变化。
6. BFS **入队时标记 visited**（不是出队时），防止重复入队；DFS 首次访问时标记。
7. BFS 空间来自**队列**，DFS 空间来自**递归工作栈**。
8. **MST ≠ 任意两点最短路**：Prim/Kruskal 求的是整棵树边权和最小，不保证树上两点路径最短。
9. Dijkstra **不能有负权边**；Floyd **k 必须最外层**、不能有负环。
10. AOV 网**顶点**表示活动（拓扑排序）；AOE 网**边**表示活动（关键路径）——字母别记反。
11. 拓扑序列**不唯一** ≠ 有环；**无法输出全部顶点**才说明有环。
12. 关键路径**可能多条**；缩短一条路径上的关键活动**不一定**缩短总工期。

## 旧版补充：题型训练与复习资料

### 典型题型与解题方法

1. **存储还原图**：矩阵看对称性与非零项，邻接表注意边的重复存储及邻接点次序。
2. **遍历序列**：严格按给定邻接次序模拟，并在发现顶点时标记；非连通图补外层扫描。
3. **MST**：Prim 维护点集边界，Kruskal 维护边排序和并查集；每选边后检查是否成环。
4. **最短路**：Dijkstra 表格逐轮写 `S/dist/path`；Floyd 每轮只允许新顶点 $k$ 作中间点。
5. **关键路径**：先拓扑求 `ve`，再逆拓扑求 `vl`，最后逐边算 `e,l`，不能只凭最长路径图形猜。


### 完整例题与逐步解答

#### 例 1：Dijkstra 最短路径

有向图边权均非负：$A\to B=1$，$A\to C=4$，$B\to C=2$，$B\to D=5$，$C\to D=1$。从 A 出发求各点最短距离和路径。

> [!success]- 展开完整答案
> 初始化：`dist[A]=0`，其余为 $\infty$。
>
> 1. 选 A 固定，松弛得 $dist[B]=1$、$dist[C]=4$；
> 2. 未固定点中 B 最小，固定 B：经 B 到 C 为 $1+2=3<4$，更新 C；经 B 到 D 为 $1+5=6$；
> 3. C 的距离 3 最小，固定 C：经 C 到 D 为 $3+1=4<6$，更新 D；
> 4. 固定 D，结束。
>
> | 顶点 | 最短距离 | 路径 |
> |---|---:|---|
> | A | 0 | A |
> | B | 1 | A→B |
> | C | 3 | A→B→C |
> | D | 4 | A→B→C→D |
>
> Dijkstra 的贪心依据是非负边保证当前最小暂定距离以后不会再被降低；出现负边时这一依据失效。

#### 例 2：AOE 网的关键路径

AOE 网有活动：$0\to1$ 工期 3，$0\to2$ 工期 2，$1\to3$ 工期 4，$2\to3$ 工期 6。求事件最早/最迟时间、关键活动和总工期。

> [!success]- 展开完整答案
> 按拓扑序正向计算事件最早发生时间：
>
> $$
> ve[0]=0,quad ve[1]=3,quad ve[2]=2,quad
> ve[3]=\max(3+4,2+6)=8.
> $$
>
> 总工期为 8。再从终点逆拓扑计算最迟时间：
>
> $$
> vl[3]=8,quad vl[1]=8-4=4,quad vl[2]=8-6=2,
> $$
>
> $$
> vl[0]=\min(4-3,2-2)=0.
> $$
>
> 对活动 $u\to v$，最早开始 $e=ve[u]$，最迟开始 $l=vl[v]-w$。计算得：
>
> | 活动 | $e$ | $l$ | 余量 |
> |---|---:|---:|---:|
> | 0→1 | 0 | 1 | 1 |
> | 1→3 | 3 | 4 | 1 |
> | 0→2 | 0 | 0 | 0 |
> | 2→3 | 2 | 2 | 0 |
>
> 所以关键活动为 $0\to2$、$2\to3$，关键路径为
>
> $$
> \boxed{0\to2\to3},
> $$
>
> 总工期 $\boxed{8}$。


### 做题识别顺序

1. 先确认有向/无向、带权/无权和邻接访问顺序。
2. BFS 在入队时标记，DFS 在首次发现时标记；非连通图还需外层扫描。
3. MST 题只在无向连通带权图上做；Prim 扩点集，Kruskal 按边权并查集判环。
4. 最短路按条件选算法：无权 BFS、非负单源 Dijkstra、全源 Floyd、DAG 可按拓扑松弛。
5. 关键路径先正向算 `ve`，再逆向算 `vl`，最后逐边算活动余量。


### 一页记忆

| 算法 | 目标 | 关键条件 | 典型复杂度 |
|---|---|---|---|
| BFS | 无权最短路/遍历 | 队列 | $O(V+E)$（邻接表） |
| DFS | 遍历/判环基础 | 递归或栈 | $O(V+E)$ |
| Prim | MST | 无向连通图 | 适合稠密实现 |
| Kruskal | MST | 边排序+并查集 | $O(E\log E)$ |
| Dijkstra | 单源最短路 | 边权非负 | 堆实现 $O((V+E)\log V)$ |
| Floyd | 全源最短路 | 可含负边但无负环 | $O(V^3)$ |

- 拓扑排序只能用于 DAG；若无法输出全部顶点，则存在有向环。
- MST 最小化整棵树边权和，不保证树上任意两点路径都是原图最短路。


### 易错点

- 无向图一条边在邻接表出现两次，但边数只算一次。
- BFS/DFS 生成树依赖邻接次序；MST 与遍历树概念不同。
- Prim、Kruskal 求的是边权和最小，不保证任意两点路径最短。
- Dijkstra 不允许负边；Floyd 的 `k` 循环不能放内层。
- AOV 网顶点表示活动，AOE 网边表示活动。
- 关键活动组成的子图可能有分支，不一定只有一条链。

### 自测问题

1. 邻接矩阵与邻接表分别适合怎样的图？
2. BFS 为什么要在入队时标记访问？
3. Dijkstra 不能处理负边的根本原因是什么？
4. Floyd 中为何 `k` 必须是最外层循环？
5. 缩短某个关键活动为何不一定缩短总工期？

> [!question]- 自测问题参考答案
> 1. 邻接矩阵适合稠密图、需要 $O(1)$ 判断边是否存在的场景；邻接表适合稀疏图和按邻边遍历，空间约 $O(V+E)$。
> 2. 若到出队时才标记，同一未标记顶点可能被多个前驱重复入队，造成重复队列项和错误父结点；入队即标记保证每点只入队一次。
> 3. Dijkstra 固定当前最小距离后不再修改它；负边可能让以后才访问的顶点通过负权边把已固定距离降低，破坏贪心不变式。
> 4. 第 $k$ 轮的矩阵必须表示“只允许编号不超过 $k$ 的顶点作中间点”。只有固定 $k$ 后更新全部 $(i,j)$，才能在进入下一轮时保持这个动态规划含义。
> 5. 可能同时存在多条关键路径；缩短只属于其中一条的活动，其他关键路径仍决定总工期。即使原来只有一条，缩短后另一条近关键路径也可能成为新的瓶颈。
