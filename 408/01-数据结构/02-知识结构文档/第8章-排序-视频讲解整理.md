## 一、排序的基本概念

### 1.1 什么是排序

排序是将一组数据元素按关键字的**递增或递减**次序重新排列的过程。

- **排序码（关键字）**：作为排序依据的数据项；
- **排序结果**：若按关键字非递减排列，则为升序；若非递增，则为降序。

### 1.2 内部排序与外部排序

| | 内部排序 | 外部排序 |
|---|---|---|
| 数据位置 | 全部记录可同时驻留内存 | 数据量太大，需内外存交换 |
| 排序方式 | 直接在内存中完成 | 生成初始归并段 + 多路归并 |
| 主要代价 | 比较次数、移动次数 | 磁盘 I/O 次数 |
| 典型算法 | 插入、交换、选择、归并、基数 | 多路平衡归并、败者树、置换选择 |

### 1.3 稳定排序与不稳定排序

**稳定性**：若排序算法能保持**相等关键字记录的原相对次序**，则称为稳定排序；否则为不稳定排序。

> [!warning] 稳定性的易错点
> 1. 稳定性只对**相等关键字**有意义，关键字全不同时稳定与否无差别；
> 2. 稳定性是**算法性质**，不是"数据有序就稳定"；
> 3. 同一种思想的不同实现可能改变稳定性（如快速排序的不同划分方式）。

### 1.4 排序算法的评价指标

- **时间复杂度**：最好、平均、最坏情况的比较次数和移动次数；
- **空间复杂度**：辅助存储空间大小；
- **稳定性**：是否保持相等关键字的相对次序；
- **对初始序列的敏感性**：数据基本有序时效率是否显著提升。

## 二、插入排序（★★★ 理解+会算）

### 2.1 直接插入排序（★★★ 必会代码）

#### 基本思想

将数组分为**已排序区**和**未排序区**。第 $i$ 趟将未排序区的第一个元素 `A[i]` 插入到已排序区 `A[0..i-1]` 的合适位置。

#### 核心代码

```c
// 直接插入排序（升序，数组下标0~n-1）
void InsertSort(int A[], int n) {
    for(int i = 1; i < n; i++) {          // 从第2个元素开始
        int temp = A[i];                  // ★ 暂存待插入元素
        int j = i - 1;
        while(j >= 0 && A[j] > temp) {    // 从后往前找插入位置
            A[j + 1] = A[j];               // 元素后移
            j--;
        }
        A[j + 1] = temp;                  // ★ 插入到正确位置
    }
}
```

#### 复杂度分析

| 情况 | 时间 | 说明 |
|---|---|---|
| 最好（已有序） | $O(n)$ | 每趟只需比较1次，不移动 |
| 平均 | $O(n^2)$ | |
| 最坏（逆序） | $O(n^2)$ | 每趟比较和移动都最多 |
| 空间 | $O(1)$ | 只需一个暂存变量 |
| 稳定性 | **稳定** | 相等时不后移，保持原次序 |

> [!important] 直接插入排序的特点
> 1. 每趟结束后，**前缀 `A[0..i]` 是有序的**，但元素不一定到最终位置；
> 2. 适合**小规模或基本有序**的序列；
> 3. 移动次数与逆序对数量密切相关。

### 2.2 折半插入排序（★★ 了解）

在直接插入的基础上，用**折半查找**定位插入位置（而不是从后往前顺序查找）。

```c
void BinaryInsertSort(int A[], int n) {
    for(int i = 1; i < n; i++) {
        int temp = A[i];
        int low = 0, high = i - 1;
        while(low <= high) {              // ★ 折半查找插入位置
            int mid = (low + high) / 2;
            if(A[mid] > temp) high = mid - 1;
            else low = mid + 1;
        }
        for(int j = i - 1; j >= high + 1; j--)  // 元素后移
            A[j + 1] = A[j];
        A[high + 1] = temp;
    }
}
```

> [!note] 折半插入的特点
> - 比较次数降为 $O(n\log n)$，但**移动次数仍为 $O(n^2)$**，总时间仍为 $O(n^2)$；
> - 为保持稳定，相等时应插到已有相等元素**之后**（即 `A[mid] <= temp` 时 `low = mid + 1`）；
> - 适合**比较操作昂贵、移动操作便宜**的场景。

### 2.3 希尔排序（Shell排序，★★ 了解过程）

#### 基本思想

按**递减增量**将数组分成若干组，每组内进行直接插入排序；逐步缩小增量，最后增量为1时进行一次直接插入排序。

```c
// 希尔排序（增量序列：n/2, n/4, ..., 1）
void ShellSort(int A[], int n) {
    for(int gap = n / 2; gap >= 1; gap /= 2) {  // ★ 增量递减
        for(int i = gap; i < n; i++) {           // 对每个分组做插入排序
            int temp = A[i];
            int j = i - gap;
            while(j >= 0 && A[j] > temp) {
                A[j + gap] = A[j];
                j -= gap;
            }
            A[j + gap] = temp;
        }
    }
}
```

> [!important] 希尔排序的特点
> 1. 性能**依赖增量序列**，常见增量 `n/2, n/4, ..., 1`；
> 2. 最后一个增量**必须为1**（否则不能保证整体有序）；
> 3. 空间 $O(1)$，**不稳定**（分组插入可能改变相等元素相对次序）；
> 4. 适合**中等规模**数据，统考通常不给统一精确平均界。

## 三、交换排序（★★★★ 快速排序是全章最高频）

### 3.1 冒泡排序（★★★ 理解+会算）

#### 基本思想

从一端开始，**两两比较相邻元素**，若逆序则交换。每趟将一个极值"冒泡"到最终位置。

```c
// 冒泡排序（升序，每趟把最大值送到末尾）
void BubbleSort(int A[], int n) {
    for(int i = 0; i < n - 1; i++) {
        bool changed = false;             // ★ 提前结束标志
        for(int j = 0; j < n - 1 - i; j++) {
            if(A[j] > A[j + 1]) {
                int temp = A[j]; A[j] = A[j+1]; A[j+1] = temp;
                changed = true;
            }
        }
        if(!changed) break;               // ★ 本趟无交换，已有序，提前结束
    }
}
```

#### 复杂度

| 情况 | 时间 | 说明 |
|---|---|---|
| 最好（已有序） | $O(n)$ | 第一趟无交换，提前结束 |
| 平均/最坏 | $O(n^2)$ | |
| 空间 | $O(1)$ | |
| 稳定性 | **稳定** | 相邻比较，相等不交换 |

> [!important] 冒泡排序的特点
> 1. 每趟结束后，**至少一个元素到达最终位置**（末尾的极值）；
> 2. 必须有**提前结束标志**才能达到最好 $O(n)$，否则始终 $O(n^2)$；
> 3. 适合**基本有序**的小表。

### 3.2 快速排序（★★★★★ 全章最高频，必会代码+手算）

#### 基本思想

**分治法**：选一个**枢轴（pivot）**，通过一趟划分将数组分为两部分——左侧元素 ≤ 枢轴，右侧元素 ≥ 枢轴；然后递归排序左右两部分。

#### 划分函数（挖坑法，★ 能默写）

```c
// 一趟划分：返回枢轴的最终位置
int Partition(int A[], int low, int high) {
    int pivot = A[low];                  // ★ 选第一个元素为枢轴，挖坑
    while(low < high) {
        while(low < high && A[high] >= pivot) high--;  // 从右往左找 < pivot 的
        A[low] = A[high];                              // 填坑
        while(low < high && A[low] <= pivot) low++;    // 从左往右找 > pivot 的
        A[high] = A[low];                              // 填坑
    }
    A[low] = pivot;                     // ★ 枢轴归位
    return low;
}
```

#### 完整快速排序

```c
void QuickSort(int A[], int low, int high) {
    if(low < high) {
        int p = Partition(A, low, high);  // 划分，枢轴归位
        QuickSort(A, low, p - 1);         // 递归排序左半
        QuickSort(A, p + 1, high);        // 递归排序右半
    }
}
```

#### 复杂度分析

| 情况 | 时间 | 说明 |
|---|---|---|
| 最好/平均 | $O(n\log n)$ | 划分均衡 |
| 最坏 | $O(n^2)$ | 枢轴极不均衡（如已有序且固定取端点） |
| 递归栈空间 | 平均 $O(\log n)$，最坏 $O(n)$ | |
| 稳定性 | **不稳定** | 划分可能改变相等元素相对次序 |

> [!warning] 快速排序的易错点
> 1. **每趟划分后，枢轴到达最终位置**（这是快排的标志性特征）；
> 2. 最坏情况发生在**初始有序且固定取端点为枢轴**时，退化为 $O(n^2)$；
> 3. 改善方法：**随机枢轴**、**三数取中**、**三向划分**；
> 4. 为限制递归栈深度，可**优先递归较短区间**，循环处理较长区间。

> [!tip] 手算划分过程
> 给序列 `[49, 38, 65, 97, 76, 13, 27, 49]`，选49为枢轴：
> 1. 从右找<49：27，放到左端 → `[27, 38, 65, 97, 76, 13, _, 49]`
> 2. 从左找>49：65，放到右端 → `[27, 38, _, 97, 76, 13, 65, 49]`
> 3. 从右找<49：13，放到左端 → `[27, 38, 13, 97, 76, _, 65, 49]`
> 4. 从左找>49：97，放到右端 → `[27, 38, 13, _, 76, 97, 65, 49]`
> 5. 从右找<49：无（low=high=3），枢轴归位 → `[27, 38, 13, 49, 76, 97, 65, 49]`
> 枢轴49最终在位置3，左侧都≤49，右侧都≥49。

## 四、选择排序（★★★★ 堆排序是重点）

### 4.1 简单选择排序（★★ 理解）

每趟从未排序区选**最小值**，与未排序区第一个元素交换。

```c
void SelectSort(int A[], int n) {
    for(int i = 0; i < n - 1; i++) {
        int minPos = i;
        for(int j = i + 1; j < n; j++)
            if(A[j] < A[minPos]) minPos = j;
        if(minPos != i) {
            int temp = A[i]; A[i] = A[minPos]; A[minPos] = temp;
        }
    }
}
```

> [!note] 简单选择排序的特点
> - 比较次数**恒为** $n(n-1)/2$（与初始序列无关）；
> - 时间 $O(n^2)$，空间 $O(1)$，**不稳定**（交换可能改变相等元素次序）；
> - 每趟结束后，**前缀的最小值到达最终位置**。

### 4.2 堆排序（★★★★ 手算建堆+调整必会）

#### 什么是堆

堆是一棵**完全二叉树**的数组表示：
- **大根堆**：每个节点的值 ≥ 其孩子的值（根最大），用于升序排序；
- **小根堆**：每个节点的值 ≤ 其孩子的值（根最小），用于降序排序。

数组下标关系（从0开始）：
- 节点 $i$ 的左孩子：$2i+1$；
- 节点 $i$ 的右孩子：$2i+2$；
- 节点 $i$ 的父节点：$(i-1)/2$；
- 最后一个非叶节点：$n/2 - 1$。

#### 向下调整（SiftDown，★ 能默写）

```c
// 大根堆向下调整：将以root为根的子树调整为大根堆
void SiftDown(int A[], int root, int end) {
    int temp = A[root];
    int child = 2 * root + 1;             // 左孩子
    while(child <= end) {
        if(child + 1 <= end && A[child] < A[child + 1])
            child++;                       // ★ 选较大的孩子
        if(temp >= A[child]) break;        // 根已最大，停止
        A[root] = A[child];                // 孩子上移
        root = child;
        child = 2 * root + 1;
    }
    A[root] = temp;                        // 原根放到最终位置
}
```

#### 建堆（★ 手算必会）

从**最后一个非叶节点**开始，向前逐个做向下调整。

```c
void BuildMaxHeap(int A[], int n) {
    for(int i = n / 2 - 1; i >= 0; i--)   // ★ 从最后一个非叶节点向前
        SiftDown(A, i, n - 1);
}
```

> [!important] 建堆的复杂度
> 建堆时间为 $O(n)$（不是 $O(n\log n)$！），因为各层调整的节点数和深度加权求和收敛到 $O(n)$。这是选择题高频考点。

#### 完整堆排序

```c
void HeapSort(int A[], int n) {
    BuildMaxHeap(A, n);                    // 1. 建大根堆
    for(int i = n - 1; i > 0; i--) {
        int temp = A[0]; A[0] = A[i]; A[i] = temp;  // 2. 堆顶与末尾交换
        SiftDown(A, 0, i - 1);             // 3. 缩小堆，调整堆顶
    }
}
```

#### 复杂度

| 指标 | 值 |
|---|---|
| 建堆 | $O(n)$ |
| 排序总时间 | $O(n\log n)$（最好/平均/最坏均如此） |
| 空间 | $O(1)$ |
| 稳定性 | **不稳定** |

> [!warning] 堆排序的易错点
> 1. 升序排序建**大根堆**，降序建**小根堆**（别搞反）；
> 2. 每趟将**堆顶与末尾交换**，然后缩小堆范围调整；
> 3. 建堆是 $O(n)$，排序是 $O(n\log n)$，总时间 $O(n\log n)$；
> 4. 适合**数据量大、要求最坏界、内存紧张**的场景；小规模缓存表现不如快排。

## 五、归并排序（★★★★ 理解+会手算合并）

### 5.1 基本思想

**分治法**：将数组递归二分，直到每个子序列长度为1；然后将两个有序子序列**合并**为一个有序序列。

### 5.2 合并函数（★ 能默写）

```c
// 合并 A[left..mid] 和 A[mid+1..right]（两段都已有序）
void Merge(int A[], int left, int mid, int right, int temp[]) {
    int i = left, j = mid + 1, k = left;
    while(i <= mid && j <= right) {
        if(A[i] <= A[j]) temp[k++] = A[i++];  // ★ 相等时取左边，保持稳定
        else temp[k++] = A[j++];
    }
    while(i <= mid) temp[k++] = A[i++];       // 复制左段剩余
    while(j <= right) temp[k++] = A[j++];      // 复制右段剩余
    for(int t = left; t <= right; t++)         // 写回原数组
        A[t] = temp[t];
}
```

### 5.3 完整归并排序

```c
void MergeSort(int A[], int left, int right, int temp[]) {
    if(left < right) {
        int mid = left + (right - left) / 2;
        MergeSort(A, left, mid, temp);         // 递归排序左半
        MergeSort(A, mid + 1, right, temp);    // 递归排序右半
        Merge(A, left, mid, right, temp);      // 合并
    }
}
```

### 5.4 复杂度

| 指标 | 值 |
|---|---|
| 时间 | $O(n\log n)$（最好/平均/最坏均如此） |
| 空间 | $O(n)$（辅助数组）+ $O(\log n)$（递归栈） |
| 稳定性 | **稳定**（相等时取左段元素） |

> [!important] 归并排序的特点
> 1. 是**稳定排序**中效率最高的之一；
> 2. 每趟合并后形成更长的有序段，但元素不一定到最终位置；
> 3. 是**外部排序的基础**（多路归并）；
> 4. 链表实现可减少节点移动，空间开销降低。

## 六、基数排序（★★★ 理解过程）

### 6.1 基本思想

不基于比较，而是按关键字的**各位数字**进行分配和收集。最低位优先（LSD）：从最低位开始，逐趟按位分配到桶中，再按桶顺序收集。

### 6.2 LSD 基数排序过程

```
以十进制、3位数为例：
第1趟（个位）：按个位分配到0~9号桶，再按桶顺序收集
第2趟（十位）：按十位分配到0~9号桶，再按桶顺序收集
第3趟（百位）：按百位分配到0~9号桶，再按桶顺序收集
完成，序列有序
```

### 6.3 复杂度

| 指标 | 值 |
|---|---|
| 时间 | $O(d(n+r))$，$d$=位数，$r$=基数 |
| 空间 | $O(n+r)$（辅助桶） |
| 稳定性 | **稳定**（每趟分配收集必须稳定） |

> [!note] 基数排序的特点
> 1. **不是基于比较**的排序，时间复杂度与 $n\log n$ 下界无关；
> 2. 适合**位数有限的整数或定长字符串**；
> 3. 每一趟的分配和收集必须是**稳定**的（LSD要求）；
> 4. 链式桶实现的空间口径可能写为 $O(r)$（桶指针），但整体需 $O(n+r)$。

## 七、内部排序算法总比较（★★★★★ 选择题必背）

### 7.1 综合对比表

| 算法 | 最好 | 平均 | 最坏 | 辅助空间 | 稳定 | 每趟确定最终位置 |
|---|---|---|---|---|---|---|
| 直接插入 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **是** | 否（前缀有序） |
| 折半插入 | $O(n\log n)$比较 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **是** | 否 |
| 希尔 | 依增量 | 依增量 | 常记$O(n^2)$ | $O(1)$ | 否 | 否 |
| 冒泡 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **是** | **是**（极值归位） |
| 快速 | $O(n\log n)$ | $O(n\log n)$ | $O(n^2)$ | 平均$O(\log n)$ | 否 | **是**（枢轴归位） |
| 简单选择 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 否 | **是**（最小值归位） |
| 堆排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | 否 | **是**（堆顶归位） |
| 归并 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | **是** | 否（形成更长有序段） |
| 基数 | $O(d(n+r))$ | $O(d(n+r))$ | $O(d(n+r))$ | $O(n+r)$ | **是** | 否 |

### 7.2 关键结论（★ 记）

1. **时间复杂度始终为 $O(n\log n)$**：堆排序、归并排序（与初始序列无关）；
2. **最坏为 $O(n^2)$**：快速排序（枢轴不均衡时）；
3. **最好为 $O(n)$**：直接插入、冒泡（需提前结束标志）；
4. **稳定排序**：直接插入、折半插入、冒泡、归并、基数（5个）；
5. **不稳定排序**：希尔、快速、简单选择、堆（4个）；
6. **空间 $O(n)$**：归并排序；其余内部排序均为 $O(1)$（快排递归栈平均 $O(\log n)$）；
7. **每趟至少一个元素到最终位置**：冒泡、简单选择、堆排序、快速排序（枢轴）；
8. **建堆时间 $O(n)$**，不是 $O(n\log n)$。

> [!tip] 识别排序算法的技巧
> 给一个中间序列判断是哪种排序：
> - **前缀有序且长度递增** → 插入排序；
> - **后缀有序且是极值** → 冒泡/选择/堆排序；
> - **有一个枢轴元素左右分明** → 快速排序；
> - **多个有序段** → 归并排序；
> - **元素按位分组** → 基数排序。

## 八、外部排序（★★★ 选择题常考）

### 8.1 基本过程

1. 按内存大小将外存文件分段，每段读入内存进行**内部排序**，写回外存，生成**初始归并段**；
2. 对初始归并段进行**多路归并**，直到得到一个完整有序文件。

### 8.2 多路平衡归并的趟数

若初始归并段数为 $r$，采用 $k$ 路平衡归并，则归并趟数：

$$
s = \lceil \log_k r \rceil
$$

> [!important] 增大归并路数 $k$ 的影响
> - **好处**：减少归并趟数，从而减少磁盘 I/O 次数；
> - **坏处**：增加输入缓冲区数量，且每趟选最小记录的比较成本从 $O(k)$ 增加；
> - **解决方案**：用**败者树**将 $k$ 路选择的比较次数从 $O(k)$ 降为 $O(\log k)$。

### 8.3 败者树（★ 理解）

败者树是一棵完全二叉树，用于在 $k$ 个归并段中快速选出最小记录。
- 每个内部节点记录**比较中的败者**（较大者），胜者继续向上比较；
- 根节点记录**全局败者**，根的父节点（额外节点）记录**全局胜者**；
- 调整时只需从叶到根更新，比较次数 $O(\log k)$。

### 8.4 置换-选择排序（★ 了解）

用于生成**平均长度大于内存容量**的初始归并段：
- 工作区中存当前段的候选记录；
- 输出当前工作区中**可接续**的最小记录（≥本段最后输出值）；
- 小于本段最后输出值的记录被**冻结**到下一段；
- 输入分布影响段长，平均段长约为内存容量的2倍。

### 8.5 最佳归并树（★★ 会算）

用**哈夫曼树**思想安排不同长度归并段的归并顺序，使读写总量（带权路径长度）最小。

$k$ 路归并时，若初始段数 $r$ 不满足严格 $k$ 叉树条件，需补**长度为0的虚段**：

$$
(r - 1) \bmod (k - 1) = 0
$$

若不成立，补足使其成立的最少虚段数，再每次合并 $k$ 个最小权段。虚段应参与最早合并，不产生实际 I/O。

> [!warning] 外部排序的核心考点
> 1. 归并趟数公式 $\lceil \log_k r \rceil$；
> 2. 败者树的作用（降低多路选择比较代价）；
> 3. 最佳归并树的虚段计算和哈夫曼构造；
> 4. 置换-选择生成的初始归并段平均长度约为内存的2倍。

### 易错点清单

1. **快速排序最坏 $O(n^2)$**：不是始终 $O(n\log n)$，初始有序且固定取端点时退化。
2. **堆排序建堆是 $O(n)$**：不是 $O(n\log n)$，这是高频陷阱。
3. **升序建大根堆，降序建小根堆**：别搞反。
4. **稳定性只对相等关键字有意义**：关键字全不同时稳定与否无差别。
5. **冒泡最好 $O(n)$ 必须有提前结束标志**：没有标志则始终 $O(n^2)$。
6. **归并排序空间 $O(n)$**：是内部排序中空间最大的（基数排序 $O(n+r)$ 也不小）。
7. **每趟确定最终位置的算法**：冒泡、选择、堆、快排（枢轴）；插入、希尔、归并不确定。
8. **基数排序不是比较排序**：不受 $n\log n$ 下界限制，但要求关键字可按位分解。
9. **外部排序趟数公式**：$\lceil \log_k r \rceil$，增大 $k$ 减少趟数但增加比较代价。
10. **最佳归并树虚段**：$(r-1)\bmod(k-1)\neq0$ 时需补虚段，虚段权为0参与最早合并。
11. **折半插入只减少比较次数**：移动次数仍为 $O(n^2)$，总时间不变。
12. **快速排序不稳定**：划分过程中相等元素可能被交换位置。

## 旧版补充：题型训练与复习资料

### 典型题型与解题方法

1. **给一趟结果识别算法**：看是否形成前缀有序、极值归位、枢轴分区、堆结构或相邻有序段。
2. **比较选型**：先看数据规模与初始有序度，再看稳定性、最坏界、空间和键域。
3. **快速划分**：严格按题给 partition 代码模拟；不同实现中相等元素处理和一趟结果不同。
4. **堆调整**：数组下标先定 0 基/1 基，每次选择更大孩子，下沉到满足堆序。
5. **外排**：先算初始段数，再算归并趟数；非等长段求 I/O 最优时画最佳归并树并补虚段。


### 完整例题与逐步解答

#### 例 1：Lomuto 快速划分

对数组 `[4,2,7,3,6]` 使用 Lomuto 划分，取末元素 6 为枢轴，条件为“元素小于等于枢轴就交换到左区”。写出一趟结果。

> [!success]- 展开完整答案
> 用 `i` 指向“小于等于枢轴区”的末尾。依次扫描 4、2、7、3：
>
> - 4、2 均不大于 6，留在左区；
> - 7 大于 6，暂留右区；
> - 3 不大于 6，与 7 交换，数组变为 `[4,2,3,7,6]`；
> - 最后把枢轴 6 与右区首元素 7 交换。
>
> 一趟结果为
>
> ```text
> [4, 2, 3, 6, 7]
> ```
>
> 枢轴最终下标为 3（0 基），左侧均 $\le6$，右侧均 $>6$。不同 partition 代码对等值元素、指针移动和一趟排列可能不同，考试必须按题给代码模拟。

#### 例 2：排序算法选型

待排序序列有 $n$ 个元素，已经基本有序，只含少量逆序对；要求稳定且额外空间 $O(1)$。优先考虑什么算法，为什么？

> [!success]- 展开完整答案
> 直接插入排序的比较/移动次数与逆序对数量密切相关。基本有序时，每个元素只需向前移动很短距离，时间可接近 $O(n)$；它稳定且额外空间 $O(1)$。
>
> 带“本趟是否发生交换”标志的冒泡排序也可能在基本有序时接近 $O(n)$，同样稳定、原地。但通常直接插入的常数和局部性更好。
>
> 因而优先答案是
>
> $$
> \boxed{\text{直接插入排序}}.
> $$
>
> 快速排序平均快但不稳定，堆排序最坏 $O(n\log n)$ 但不稳定，归并稳定却需要 $O(n)$ 辅助数组，都不完全满足题设组合。

#### 例 3：多路外部归并趟数

外部排序已经生成 50 个初始归并段，内存允许做 5 路归并。忽略不均匀段和缓冲细节，至少需要多少趟归并？

> [!success]- 展开完整答案
> 每一趟最多把归并段数缩小为原来的 $1/5$。需要最小整数 $p$ 满足
>
> $$
> 5^p\ge50.
> $$
>
> 因为 $5^2=25<50$，$5^3=125\ge50$，所以
>
> $$
> \boxed{p=\lceil\log_5 50\rceil=3\text{ 趟}}.
> $$
>
> 若问 I/O 次数，每一趟通常读写全部数据各一次；若初始段长度不同且要求最小总读写量，应构造最佳归并树，并补权值为 0 的虚段使其成为满足 $k$ 叉合并约束的树。


### 做题识别顺序

1. 一趟结果识别先看：前缀有序、相邻交换、枢轴分区、极值归位、堆序还是有序段倍增。
2. 选型依次检查稳定性、最坏时间、额外空间、初始有序度、数据规模和键域。
3. 快排/堆排必须按题给 0 基/1 基和具体代码模拟。
4. 复杂度同时写最好、平均、最坏与辅助空间，快速排序递归栈不能漏。
5. 外排先算初始段数和归并路数，再算趟数；最优 I/O 需要考虑段长和最佳归并树。


### 一页记忆

| 排序 | 最好 | 平均/最坏 | 空间 | 稳定 |
|---|---:|---:|---:|:---:|
| 直接插入 | $O(n)$ | $O(n^2)$ | $O(1)$ | 是 |
| 冒泡 | $O(n)$ | $O(n^2)$ | $O(1)$ | 是 |
| 快速 | $O(n\log n)$ | 平均 $O(n\log n)$，最坏 $O(n^2)$ | 平均 $O(\log n)$ | 否 |
| 简单选择 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 否 |
| 堆排序 | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | 否 |
| 归并 | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | 是 |

$$
\boxed{\text{归并趟数}=\lceil\log_k r\rceil}
$$


### 易错点

- 折半插入没有减少元素移动数量，因此总时间仍为 $O(n^2)$。
- 快速排序不是原地 $O(1)$ 空间：递归栈必须计入。
- 建堆是 $O(n)$，不是把每个结点的 $O(\log n)$ 简单相乘得出的紧确界。
- “每趟有序”不等于“每趟有元素最终归位”。
- 基数排序各位的分配收集必须稳定。
- 增加外排归并路数会减少趟数，但缓冲区和选择结构也需相应资源。

> [!question]- 自测问题参考答案
> 1. 直接插入排序在逆序对很少时接近 $O(n)$；带提前终止标志的冒泡排序在已有序时也是 $O(n)$。
> 2. 随机化或三数取中降低连续极端划分概率；优先递归较小分区并循环处理较大分区可控制栈深；工程实现还可在递归过深时切换堆排序。408 题仍按给定快排模型分析。
> 3. 简单选择每趟线性扫描剩余区，累计 $O(n^2)$；堆用完全二叉树维护极值，建堆 $O(n)$，每次删除堆顶并调整 $O(\log n)$，总计 $O(n\log n)$。
> 4. LSD 先按低位排好；处理更高位时，稳定排序保证高位相同元素仍保持原有低位次序，否则低位信息被破坏。
> 5. 严格 $k$ 叉树叶子数需满足 $(r-1)\bmod(k-1)=0$。补 0 权虚段使树形满足约束，又不增加实际归并数据量，从而可按 Huffman 思想得到最小加权路径长度。
