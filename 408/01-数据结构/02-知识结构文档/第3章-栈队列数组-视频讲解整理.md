## 一、栈的基本概念（视频019）

### 1.1 什么是栈

栈（Stack）是**只允许在一端进行插入或删除操作的线性表**。

- **栈顶（Top）**：允许插入和删除的那一端
- **栈底（Bottom）**：不允许插入和删除的那一端，固定不变
- **空栈**：不含任何元素的栈

### 1.2 栈的特点：后进先出（LIFO）

栈的核心特性是**Last In First Out（后进先出）**，最后进入栈的元素最先被弹出。

> 视频老师举例：就像往一个桶里放盘子，最后放进去的盘子在最上面，要拿盘子必须先拿最上面的。

### 1.3 栈的基本操作

| 操作名 | 功能 | 时间复杂度 |
|--------|------|-----------|
| `InitStack(&S)` | 初始化栈，构造一个空栈 | O(1) |
| `StackEmpty(S)` | 判断栈是否为空 | O(1) |
| `Push(&S, x)` | 入栈，将元素x压入栈顶 | O(1) |
| `Pop(&S, &x)` | 出栈，弹出栈顶元素并用x返回 | O(1) |
| `GetTop(S, &x)` | 读栈顶元素，用x返回栈顶元素 | O(1) |
| `DestroyStack(&S)` | 销毁栈，释放栈占用的存储空间 | O(n) |

> [!important] 考研考点
> 入栈和出栈操作都只能在栈顶进行，时间复杂度均为O(1)。

### 1.4 出栈序列与卡特兰数

n个不同元素按固定次序依次入栈，所有合法出栈序列的数量是**卡特兰数（Catalan number）**：

$$
C_n = \frac{1}{n+1}\binom{2n}{n}
$$

例如：
- n=3时，C₃=5（合法出栈序列有5种，不是3!=6种）
- n=4时，C₄=14

> [!warning] 注意
> 卡特兰数只适用于"固定入栈次序"的情况。如果题目允许改变入栈次序、限制栈容量，不能直接套用。

**验证具体出栈序列是否合法的方法**：按入栈次序压栈，栈顶等于目标序列当前元素时持续弹出，最终全部匹配才合法。

## 二、栈的顺序存储实现（视频020）

### 2.1 顺序栈的定义

顺序栈使用一组地址连续的存储单元存放自栈底到栈顶的数据元素，同时附设指针`top`指示栈顶元素在顺序栈中的位置。

```c
#define MaxSize 50  // 定义栈中元素的最大个数
typedef struct {
    ElemType data[MaxSize];  // 存放栈中元素
    int top;  // 栈顶指针
} SqStack;
```

### 2.2 两种top约定（考研重点）

这是考研最容易混淆的地方，**必须先确认题目用的是哪种约定**：

#### 约定一：top = -1 表示空栈（王道教材默认）

- 空栈时 `top = -1`
- 栈顶元素是 `data[top]`
- 入栈：先 `++top`，再 `data[top] = x`
- 出栈：先 `x = data[top]`，再 `--top`
- 栈满条件：`top == MaxSize - 1`
- 栈中元素个数：`top + 1`

#### 约定二：top = 0 表示空栈（top指向下一个可插入位置）

- 空栈时 `top = 0`
- 栈顶元素是 `data[top - 1]`
- 入栈：先 `data[top] = x`，再 `++top`
- 出栈：先 `--top`，再 `x = data[top]`
- 栈满条件：`top == MaxSize`
- 栈中元素个数：`top`

> [!warning] 考研必坑
> 两种约定的代码完全不同，考试时必须先看题目说明。如果题目没说明，默认用王道教材的`top=-1`约定。

### 2.3 顺序栈基本操作（top=-1约定）

```c
// ======1. 初始化栈======
void InitStack(SqStack &S) {
    S.top = -1;  // 栈顶指针初始化为-1，表示空栈
}

// ======2. 判断栈是否为空======
bool StackEmpty(SqStack S) {
    return S.top == -1;  // 栈顶指针为-1表示空栈
}

// ======3. 入栈======
bool Push(SqStack &S, ElemType x) {
    if(S.top == MaxSize - 1)  // 栈满，不能入栈
        return false;
    S.data[++S.top] = x;  // 栈顶指针先加1，再将元素压入栈顶
    return true;
}

// ======4. 出栈======
bool Pop(SqStack &S, ElemType &x) {
    if(S.top == -1)  // 栈空，不能出栈
        return false;
    x = S.data[S.top--];  // 先取出栈顶元素，再将栈顶指针减1
    return true;
}

// ======5. 读栈顶元素======
bool GetTop(SqStack S, ElemType &x) {
    if(S.top == -1)  // 栈空，没有栈顶元素
        return false;
    x = S.data[S.top];  // 将栈顶元素赋值给x
    return true;
}
```

### 2.4 共享栈（两个栈共享一维数组）

利用栈底位置相对不变的特性，可以让两个顺序栈共享一个一维数组空间。

- 栈0的栈底在数组下端（下标0），栈顶向中间增长
- 栈1的栈底在数组上端（下标MaxSize-1），栈顶向中间增长
- 两个栈的栈顶在数组中间相遇时为栈满

```c
typedef struct {
    ElemType data[MaxSize];  // 共享数组空间
    int top0;  // 栈0的栈顶指针
    int top1;  // 栈1的栈顶指针
} ShStack;
```

**初始化**：`top0 = -1`，`top1 = MaxSize`

**栈满条件**：`top0 + 1 == top1`（两个栈顶相邻）

> [!important] 考研考点
> 共享栈的栈满条件是`top0 + 1 == top1`，不是`top0 == top1`。共享栈提高了空间利用率，但两个栈各自的后进先出性质不变。

## 三、栈的链式存储实现（视频021）

### 3.1 链栈的定义

链栈是采用链式存储结构实现的栈。通常用单链表实现，**规定所有操作都在表头进行**（表头作为栈顶）。

链栈一般**不需要头结点**，因为栈的操作只在栈顶（表头）进行，带头结点反而多一步。

```c
typedef struct Linknode {
    ElemType data;  // 数据域：存储栈中元素
    struct Linknode *next;  // 指针域：指向下一个节点
} Linknode, *LiStack;  // 链栈的结构体类型
```

> 视频老师强调：链栈的栈顶就是链表的头指针指向的节点，入栈和出栈都在表头操作，时间复杂度O(1)。

### 3.2 链栈的基本操作

```c
// ======1. 初始化链栈======
void InitStack(LiStack &S) {
    S = NULL;  // 栈顶指针初始化为NULL，表示空栈
}

// ======2. 判断链栈是否为空======
bool StackEmpty(LiStack S) {
    return S == NULL;  // 栈顶指针为NULL表示空栈
}

// ======3. 入栈（头插法）======
bool Push(LiStack &S, ElemType x) {
    Linknode *s = (Linknode *)malloc(sizeof(Linknode));  // 为新节点分配内存
    if(s == NULL)  // 内存分配失败
        return false;
    s->data = x;  // 新节点的数据域赋值为x
    s->next = S;  // 新节点的指针域指向原来的栈顶节点
    S = s;  // 栈顶指针指向新节点，新节点成为新的栈顶
    return true;
}

// ======4. 出栈======
bool Pop(LiStack &S, ElemType &x) {
    if(S == NULL)  // 栈空，不能出栈
        return false;
    Linknode *p = S;  // p指向栈顶节点
    x = p->data;  // 将栈顶元素的数据域赋值给x
    S = p->next;  // 栈顶指针指向下一个节点
    free(p);  // 释放原栈顶节点的内存空间
    return true;
}

// ======5. 读栈顶元素======
bool GetTop(LiStack S, ElemType &x) {
    if(S == NULL)  // 栈空，没有栈顶元素
        return false;
    x = S->data;  // 将栈顶元素的数据域赋值给x
    return true;
}
```

> [!note] 顺序栈 vs 链栈
> - 顺序栈：操作简单，随机访问，但容量固定，可能溢出
> - 链栈：容量动态，不会溢出，但每个节点需要额外指针空间，操作稍复杂
> - 考研中顺序栈考得更多，链栈了解即可

## 四、队列的基本概念（视频022）

### 4.1 什么是队列

队列（Queue）是**只允许在表的一端进行插入，而在表的另一端进行删除**的线性表。

- **队头（Front）**：允许删除的一端，又称队首
- **队尾（Rear）**：允许插入的一端
- **空队列**：不含任何元素的队列

### 4.2 队列的特点：先进先出（FIFO）

队列的核心特性是**First In First Out（先进先出）**，最先进入队列的元素最先被删除。

> 视频老师举例：就像排队买饭，先来的人先买，后来的人排在后面。

### 4.3 队列的基本操作

| 操作名 | 功能 | 时间复杂度 |
|--------|------|-----------|
| `InitQueue(&Q)` | 初始化队列，构造一个空队列 | O(1) |
| `QueueEmpty(Q)` | 判断队列是否为空 | O(1) |
| `EnQueue(&Q, x)` | 入队，将元素x加入队尾 | O(1) |
| `DeQueue(&Q, &x)` | 出队，删除队头元素并用x返回 | O(1) |
| `GetHead(Q, &x)` | 读队头元素，用x返回队头元素 | O(1) |

## 五、队列的顺序实现（视频023）

### 5.1 顺序队列的定义与假溢出

顺序队列使用一组地址连续的存储单元存放队列中的元素，并附设两个指针：

- `front`：队头指针，指向队头元素
- `rear`：队尾指针，指向队尾元素的下一个位置（下一个可插入位置）

```c
#define MaxSize 50  // 定义队列中元素的最大个数
typedef struct {
    ElemType data[MaxSize];  // 存放队列中的元素
    int front, rear;  // 队头指针和队尾指针
} SqQueue;
```

**假溢出问题**：普通顺序队列中，随着入队和出队操作，`front`和`rear`都不断向后移动。当`rear`到达数组末尾时，即使数组前面还有空闲空间，也无法再入队，这就是**假溢出**。

### 5.2 循环队列（考研核心）

为了解决假溢出问题，将顺序队列臆造为一个环形的空间，即把存储队列元素的表从逻辑上看成一个环，称为**循环队列**。

循环队列通过**取模运算（%）**实现指针的循环移动。

#### 三种判空判满方案

**方案一：牺牲一个存储单元（王道教材默认，考研最常考）**

- 空队列：`front == rear`
- 满队列：`(rear + 1) % MaxSize == front`
- 队列长度：`(rear - front + MaxSize) % MaxSize`
- 最多存储 `MaxSize - 1` 个元素

> [!important] 为什么要牺牲一个单元？
> 如果不牺牲单元，那么`front == rear`既可能表示空队列，也可能表示满队列，无法区分。牺牲一个单元后，用`(rear+1)%MaxSize == front`表示满，二者就可以区分了。

**方案二：增加size计数器**

- 增加一个`size`成员记录队列中元素的个数
- 空队列：`size == 0`
- 满队列：`size == MaxSize`
- 可以使用全部MaxSize个单元

**方案三：增加tag标志位**

- 增加一个`tag`成员，记录最近一次操作是入队还是出队
- `tag = 0`表示最近一次是出队，`tag = 1`表示最近一次是入队
- 当`front == rear`时，若`tag == 0`则为空，若`tag == 1`则为满

#### 循环队列基本操作（牺牲一个单元方案）

```c
// ======1. 初始化循环队列======
void InitQueue(SqQueue &Q) {
    Q.front = Q.rear = 0;  // 队头指针和队尾指针都初始化为0
}

// ======2. 判断循环队列是否为空======
bool QueueEmpty(SqQueue Q) {
    return Q.front == Q.rear;  // 队头指针等于队尾指针表示空队列
}

// ======3. 入队======
bool EnQueue(SqQueue &Q, ElemType x) {
    if((Q.rear + 1) % MaxSize == Q.front)  // 队列已满，不能入队
        return false;
    Q.data[Q.rear] = x;  // 将元素x放入队尾
    Q.rear = (Q.rear + 1) % MaxSize;  // 队尾指针循环后移一位
    return true;
}

// ======4. 出队======
bool DeQueue(SqQueue &Q, ElemType &x) {
    if(Q.front == Q.rear)  // 队列已空，不能出队
        return false;
    x = Q.data[Q.front];  // 将队头元素赋值给x
    Q.front = (Q.front + 1) % MaxSize;  // 队头指针循环后移一位
    return true;
}

// ======5. 求队列长度======
int QueueLength(SqQueue Q) {
    return (Q.rear - Q.front + MaxSize) % MaxSize;  // 队列长度公式
}
```

> [!warning] 考研必坑
> 1. 循环队列所有指针更新都要取模`% MaxSize`
> 2. 牺牲一个单元时，最多只能存`MaxSize - 1`个元素
> 3. 长度公式`(rear - front + MaxSize) % MaxSize`中，加MaxSize是为了防止负数

## 六、队列的链式实现（视频024）

### 6.1 链队列的定义

链队列是采用链式存储结构实现的队列。同时需要队头指针和队尾指针，通常**带头结点**。

```c
typedef struct LinkNode {  // 链队列的节点类型
    ElemType data;  // 数据域：存储队列中的元素
    struct LinkNode *next;  // 指针域：指向下一个节点
} LinkNode;

typedef struct {  // 链队列的结构体类型
    LinkNode *front, *rear;  // 队头指针和队尾指针
} LinkQueue;
```

### 6.2 链队列的基本操作

```c
// ======1. 初始化链队列（带头结点）======
void InitQueue(LinkQueue &Q) {
    Q.front = Q.rear = (LinkNode *)malloc(sizeof(LinkNode));  // 建立头结点，队头队尾都指向头结点
    Q.front->next = NULL;  // 头结点的指针域初始化为NULL
}

// ======2. 判断链队列是否为空======
bool QueueEmpty(LinkQueue Q) {
    return Q.front == Q.rear;  // 队头指针等于队尾指针表示空队列（都指向头结点）
}

// ======3. 入队（在队尾插入）======
void EnQueue(LinkQueue &Q, ElemType x) {
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));  // 为新节点分配内存
    s->data = x;  // 新节点的数据域赋值为x
    s->next = NULL;  // 新节点的指针域初始化为NULL（作为新的尾节点）
    Q.rear->next = s;  // 原队尾节点的指针域指向新节点
    Q.rear = s;  // 队尾指针指向新节点，新节点成为新的队尾
}

// ======4. 出队（删除队头元素）======
bool DeQueue(LinkQueue &Q, ElemType &x) {
    if(Q.front == Q.rear)  // 队列已空，不能出队
        return false;
    LinkNode *p = Q.front->next;  // p指向队头元素（头结点的下一个节点）
    x = p->data;  // 将队头元素的数据域赋值给x
    Q.front->next = p->next;  // 头结点的指针域指向队头元素的下一个节点
    if(Q.rear == p)  // 如果删除的是最后一个元素
        Q.rear = Q.front;  // 队尾指针指向头结点，避免尾指针悬空
    free(p);  // 释放原队头元素的内存空间
    return true;
}
```

> [!important] 考研考点
> 链队列删除最后一个数据结点后，**必须将队尾指针指向头结点**（`Q.rear = Q.front`），否则尾指针会成为悬空指针，后续入队操作会出错。

## 七、双端队列（视频025）

### 7.1 什么是双端队列

双端队列（Deque，Double-Ended Queue）是指**允许两端都可以进行入队和出队操作**的队列。

- 两端分别称为**前端（front）**和**后端（rear）**
- 每一端都可以进行入队和出队操作

### 7.2 双端队列的分类

| 类型 | 说明 |
|------|------|
| 一般双端队列 | 两端都可以入队和出队 |
| 输入受限的双端队列 | 只允许一端进行入队操作，另一端可以入队和出队 |
| 输出受限的双端队列 | 只允许一端进行出队操作，另一端可以入队和出队 |

> [!note] 视频老师说明
> 双端队列这部分内容在考研中主要考选择题，考察给定一个输入序列，判断哪些输出序列是合法的。解题方法就是按照双端队列的操作规则，模拟入队出队过程，看能否得到目标序列。

### 7.3 输出序列合法性判断

判断方法：按照双端队列允许的操作，从左到右依次将输入元素入队，在入队过程中可以从允许的一端出队，看能否得到目标输出序列。

> [!important] 考研考点
> 栈可以看作是"输入和输出都受限在同一端"的双端队列；普通队列可以看作是"一端只能入、另一端只能出"的双端队列。

## 八、栈在括号匹配中的应用（视频026）

### 8.1 括号匹配问题

括号匹配是编译器中语法检查的基本功能。给定一个包含各种括号的表达式，检查括号是否正确匹配。

常见的括号类型：
- 圆括号：`(` 和 `)`
- 方括号：`[` 和 `]`
- 花括号：`{` 和 `}`

### 8.2 括号匹配的算法思想

利用栈的**后进先出**特性：

1. 从左到右扫描表达式
2. 遇到**左括号**（`(`、`[`、`{`），将其压入栈中
3. 遇到**右括号**（`)`、`]`、`}`）：
   - 若栈为空，说明右括号没有对应的左括号，匹配失败
   - 弹出栈顶元素，检查是否与当前右括号匹配
   - 若不匹配，匹配失败
4. 扫描结束后，若栈不为空，说明有左括号没有对应的右括号，匹配失败

> 视频老师举例：`([{}])` 是合法的；`([)]` 是不合法的，因为扫描到`)`时栈顶是`[`，不匹配。

### 8.3 括号匹配的代码实现

```c
// ======括号匹配算法======
bool BracketMatch(char *str, int n) {
    SqStack S;  // 定义一个顺序栈S
    InitStack(S);  // 初始化栈S
    for(int i = 0; i < n; i++) {  // 从左到右扫描表达式
        if(str[i] == '(' || str[i] == '[' || str[i] == '{') {
            // 遇到左括号，压入栈中
            Push(S, str[i]);
        } else {
            // 遇到右括号
            if(StackEmpty(S))  // 栈为空，说明右括号没有对应的左括号
                return false;
            char topElem;  // 定义变量topElem，用于存储栈顶元素
            Pop(S, topElem);  // 弹出栈顶元素
            // 检查栈顶左括号是否与当前右括号匹配
            if(str[i] == ')' && topElem != '(')
                return false;
            if(str[i] == ']' && topElem != '[')
                return false;
            if(str[i] == '}' && topElem != '{')
                return false;
        }
    }
    // 扫描结束后，栈必须为空才匹配成功
    return StackEmpty(S);
}
```

### 8.4 复杂度分析

- **时间复杂度**：O(n)，每个字符最多入栈和出栈各一次
- **空间复杂度**：O(n)，最坏情况下所有字符都是左括号，栈中需要存储n个元素

> [!important] 考研考点
> 括号匹配是栈的经典应用，选择题常考给定一个括号序列，判断是否合法，或者问扫描到某个位置时栈中的内容。

## 九、栈在表达式求值中的应用（视频027、028）

### 9.1 三种算术表达式

表达式由**操作数**、**运算符**和**界限符（括号）**组成。根据运算符的位置，分为三种表达式：

| 表达式类型 | 运算符位置 | 示例 | 说明 |
|-----------|-----------|------|------|
| 中缀表达式 | 运算符在两个操作数之间 | `a + b * c` | 人类最熟悉的写法，需要括号和优先级 |
| 后缀表达式（逆波兰式） | 运算符在两个操作数之后 | `a b c * +` | 不需要括号，运算符出现顺序就是运算顺序 |
| 前缀表达式（波兰式） | 运算符在两个操作数之前 | `+ a * b c` | 不需要括号 |

> 视频老师强调：中缀表达式中操作数的相对顺序在后缀和前缀表达式中**保持不变**，改变的只是运算符的相对顺序。

### 9.2 中缀表达式转后缀表达式（手算方法）

**左优先原则**：从左到右扫描中缀表达式，只要左边的运算符可以先计算，就先计算。

具体步骤：
1. 从左到右扫描中缀表达式
2. 遇到操作数，直接加入后缀表达式
3. 遇到运算符，比较它与栈顶运算符的优先级：
   - 若当前运算符优先级**高于**栈顶运算符，将其压入栈
   - 若当前运算符优先级**低于或等于**栈顶运算符（左结合），弹出栈顶运算符加入后缀表达式，继续比较
4. 遇到左括号`(`，压入栈
5. 遇到右括号`)`，依次弹出栈中运算符加入后缀表达式，直到弹出左括号为止（左括号不加入后缀表达式）
6. 扫描结束后，将栈中剩余的运算符依次弹出加入后缀表达式

**运算符优先级**：
- 括号：`(` `)` 最高
- 乘除：`*` `/` 次之
- 加减：`+` `-` 最低
- 同优先级从左到右结合（左结合）

> 视频老师举例：中缀表达式 `a + b - c * d / e + f`
> - 操作数顺序：a b c d e f（保持不变）
> - 运算符顺序：+ - * / + → 后缀中变为：+ * / - +
> - 最终后缀表达式：`a b + c d * e / - f +`

### 9.3 中缀转后缀的算法实现（计算机方法）

```c
// ======中缀表达式转后缀表达式======
// 假设输入已经词法切分，运算符只有+、-、*、/，操作数为单个字母
void InfixToPostfix(char *infix, char *postfix) {
    SqStack S;  // 定义运算符栈S
    InitStack(S);  // 初始化栈S
    int j = 0;  // 后缀表达式的下标计数器
    for(int i = 0; infix[i] != '\0'; i++) {  // 从左到右扫描中缀表达式
        if(infix[i] >= 'a' && infix[i] <= 'z') {
            // 遇到操作数，直接加入后缀表达式
            postfix[j++] = infix[i];
        } else if(infix[i] == '(') {
            // 遇到左括号，压入栈
            Push(S, infix[i]);
        } else if(infix[i] == ')') {
            // 遇到右括号，弹出栈中运算符直到左括号
            char op;  // 定义变量op，用于存储弹出的运算符
            Pop(S, op);  // 弹出栈顶元素
            while(op != '(') {  // 直到弹出左括号为止
                postfix[j++] = op;  // 将弹出的运算符加入后缀表达式
                Pop(S, op);  // 继续弹出栈顶元素
            }
            // 左括号不加入后缀表达式
        } else {
            // 遇到运算符+、-、*、/
            while(!StackEmpty(S)) {
                char topOp;  // 定义变量topOp，用于存储栈顶运算符
                GetTop(S, topOp);  // 读取栈顶运算符
                // 比较优先级：若栈顶运算符优先级 >= 当前运算符优先级（左结合）
                if(Priority(topOp) >= Priority(infix[i])) {
                    Pop(S, topOp);  // 弹出栈顶运算符
                    postfix[j++] = topOp;  // 加入后缀表达式
                } else {
                    break;  // 栈顶运算符优先级更低，停止弹出
                }
            }
            Push(S, infix[i]);  // 将当前运算符压入栈
        }
    }
    // 扫描结束后，将栈中剩余的运算符依次弹出
    while(!StackEmpty(S)) {
        char op;  // 定义变量op，用于存储弹出的运算符
        Pop(S, op);  // 弹出栈顶运算符
        postfix[j++] = op;  // 加入后缀表达式
    }
    postfix[j] = '\0';  // 后缀表达式结束符
}

// ======运算符优先级函数======
int Priority(char op) {
    if(op == '*' || op == '/')
        return 2;  // 乘除优先级为2
    if(op == '+' || op == '-')
        return 1;  // 加减优先级为1
    return 0;  // 左括号优先级为0（不会被弹出）
}
```

### 9.4 后缀表达式求值

后缀表达式的优点是**不需要括号**，运算符出现的顺序就是运算的先后顺序。

**算法思想**：
1. 从左到右扫描后缀表达式
2. 遇到**操作数**，将其压入栈中
3. 遇到**运算符**，弹出栈顶两个操作数：
   - 第一次弹出的是**右操作数**（b）
   - 第二次弹出的是**左操作数**（a）
   - 计算 `a 运算符 b`，将结果压回栈中
4. 扫描结束后，栈中仅剩一个元素，就是表达式的值

> [!warning] 考研必坑
> 后缀表达式求值时，**先弹出的是右操作数，后弹出的是左操作数**！对于减法和除法，顺序不能反：`a - b` 不是 `b - a`。

```c
// ======后缀表达式求值======
// 假设操作数为单个数字字符，运算符为+、-、*、/
int EvalPostfix(char *postfix) {
    SqStack S;  // 定义操作数栈S
    InitStack(S);  // 初始化栈S
    for(int i = 0; postfix[i] != '\0'; i++) {  // 从左到右扫描后缀表达式
        if(postfix[i] >= '0' && postfix[i] <= '9') {
            // 遇到操作数，压入栈中
            Push(S, postfix[i] - '0');  // 将字符转换为整数后压栈
        } else {
            // 遇到运算符，弹出两个操作数
            int b, a;  // 定义变量b和a，分别存储右操作数和左操作数
            Pop(S, b);  // 先弹出右操作数b
            Pop(S, a);  // 再弹出左操作数a
            int result;  // 定义变量result，用于存储运算结果
            switch(postfix[i]) {
                case '+': result = a + b; break;
                case '-': result = a - b; break;
                case '*': result = a * b; break;
                case '/': result = a / b; break;
            }
            Push(S, result);  // 将运算结果压回栈中
        }
    }
    int finalResult;  // 定义变量finalResult，用于存储最终结果
    Pop(S, finalResult);  // 弹出栈中唯一的元素，即最终结果
    return finalResult;
}
```

### 9.5 中缀表达式直接求值（两个栈）

中缀表达式可以直接求值，不需要先转后缀。需要**两个栈**：
- **操作数栈**：存放暂时还不能确定运算顺序的操作数
- **运算符栈**：存放暂时还不能确定运算顺序的运算符

**算法思想**：
1. 从左到右扫描中缀表达式
2. 遇到操作数，压入操作数栈
3. 遇到运算符，按照中缀转后缀的规则判断：
   - 若需要弹出运算符栈中的运算符，则弹出该运算符
   - 同时从操作数栈弹出两个操作数（先弹右操作数，再弹左操作数）
   - 计算结果压回操作数栈
   - 最后将当前运算符压入运算符栈
4. 遇到括号，按照中缀转后缀的规则处理
5. 扫描结束后，依次弹出运算符栈中剩余的运算符，每次弹出都从操作数栈弹出两个操作数计算
6. 最终操作数栈中仅剩一个元素，就是表达式的值

> 视频老师强调：中缀表达式直接求值，本质上就是把"中缀转后缀"和"后缀求值"两个算法结合起来，一边生成后缀表达式一边求值。

> [!important] 考研考点
> 1. 中缀转后缀是选择题高频考点，常考转换到某一步时栈中的内容
> 2. 后缀求值要记住先弹右操作数
> 3. 中缀表达式直接求值需要两个栈，了解即可

## 十、栈在递归中的应用（视频029）

### 10.1 递归的基本概念

**递归**：在函数的定义中调用函数自身的方法。

递归的两个基本要素：
1. **递归边界（终止条件）**：递归的出口，当满足这个条件时递归不再继续
2. **递归体（递归表达式）**：将大问题分解为更小的同类型问题

> 视频老师举例：阶乘函数 n! = n × (n-1)!，其中 0! = 1 是递归边界，n! = n × (n-1)! 是递归体。

### 10.2 递归工作栈

递归函数的执行过程中，系统会维护一个**递归工作栈**，用于存储：
- 函数的**参数**
- 函数的**局部变量**
- 函数调用的**返回地址**

每次递归调用时，将这些信息压入栈中；每次递归返回时，从栈中弹出这些信息，恢复上一层的执行状态。

> 视频老师强调：递归的本质就是利用栈来保存函数调用的现场信息。递归次数过多时，递归工作栈可能溢出（栈溢出）。

### 10.3 递归与非递归的转换

递归算法的优点是代码简洁、思路清晰，但缺点是：
- 递归调用需要额外的栈空间开销
- 递归次数过多可能导致栈溢出
- 递归的执行效率相对较低

**将递归转换为非递归（迭代）的方法**：
1. 分析递归过程中需要保存的信息
2. 自己维护一个栈来模拟系统的递归工作栈
3. 用循环代替递归调用

> [!note] 考研说明
> 递归在数据结构中应用广泛，如二叉树的遍历、图的DFS等。408考试中递归代码是可以接受的，不需要强行转换为非递归。但要理解递归背后的栈机制。

### 11.1 队列在计算机系统中的应用

队列的**先进先出**特性使其在计算机系统中有广泛应用：

## 十二、数组与特殊矩阵的压缩存储（视频031）

### 12.1 数组的基本概念

数组是由**相同类型**的数据元素组成的**有限序列**。

- **一维数组**：可以看作是一个线性表
- **二维数组**：可以看作是"数据元素是一维数组"的一维数组
- **多维数组**：以此类推

### 12.2 数组的存储结构

数组在内存中占用**连续的存储空间**。对于多维数组，有两种存储方式：

#### 行优先存储（C语言默认）

按行依次存储，先存第0行，再存第1行，...

二维数组 `A[m][n]`（m行n列），每个元素占L字节，以0为下界：

$$
LOC(A[i][j]) = LOC(A[0][0]) + (i \times n + j) \times L
$$

#### 列优先存储（Fortran语言默认）

按列依次存储，先存第0列，再存第1列，...

$$
LOC(A[i][j]) = LOC(A[0][0]) + (j \times m + i) \times L
$$

> [!warning] 考研必坑
> 1. 先确认是行优先还是列优先
> 2. 先确认下标从0开始还是从1开始
> 3. 公式中的n是**列数**（行优先时），m是**行数**（列优先时）
> 4. 若下标从1开始，需要先将下标减1转换为0基

### 12.3 特殊矩阵的压缩存储

特殊矩阵是指具有很多相同元素或零元素，且这些元素分布有一定规律的矩阵。压缩存储的目的是**节省存储空间**。

#### 12.3.1 对称矩阵

**定义**：n阶方阵中，元素满足 `a[i][j] = a[j][i]` 的矩阵。

**压缩策略**：只存储下三角（包括主对角线）的元素，上三角元素通过对称性访问。

下三角（含主对角线）共有 `n(n+1)/2` 个元素。

按行优先存储下三角，一维数组下标k（0基）与矩阵下标(i, j)的映射关系：

- 若 `i >= j`（下三角或主对角线）：

$$
k = \frac{i(i+1)}{2} + j
$$

- 若 `i < j`（上三角）：利用对称性，访问 `a[j][i]`，即

$$
k = \frac{j(j+1)}{2} + i
$$

> 推导：第i行之前有 0+1+2+...+i = i(i+1)/2 个元素，第i行中第j列是第j个（0基），所以 k = i(i+1)/2 + j。

#### 12.3.2 三角矩阵

**定义**：
- **下三角矩阵**：上三角（不含主对角线）的元素全部为同一个常数c
- **上三角矩阵**：下三角（不含主对角线）的元素全部为同一个常数c

**压缩策略**：
- 下三角矩阵：存储下三角（含主对角线）的元素，再额外存储一个常数c
- 上三角矩阵：存储上三角（含主对角线）的元素，再额外存储一个常数c

总共需要 `n(n+1)/2 + 1` 个存储单元。

下三角矩阵按行优先存储下三角，映射关系与对称矩阵相同。

#### 12.3.3 三对角矩阵（带状矩阵）

**定义**：n阶方阵中，只有主对角线以及主对角线上下两条对角线上的元素非零，其余元素全为0。

即满足 `|i - j| <= 1` 的元素非零。

**压缩策略**：只存储三条对角线上的元素，按行优先存储。

第0行有2个元素，第1到n-2行各有3个元素，第n-1行有2个元素，总共 `3n - 2` 个元素。

按行优先存储，矩阵下标(i, j)（1基）映射到一维数组下标k（0基）：

$$
k = 2i + j - 3
$$

> 推导：第i行之前有 2 + 3(i-1) = 3i - 1 个元素（i>=1），第i行中第j列相对于行首的偏移是 j - (i-1) = j - i + 1，所以 k = (3i-1) + (j-i+1) - 1 = 2i + j - 3。

> [!warning] 考研必坑
> 三对角矩阵的公式推导要注意矩阵下标是0基还是1基，一维数组下标是0基还是1基。考试时建议现场推导，不要死记硬背。

#### 12.3.4 稀疏矩阵

**定义**：矩阵中非零元素的个数远远小于矩阵元素的总数，且非零元素的分布没有规律。

通常用**稀疏因子**描述：`δ = 非零元素个数 / 矩阵元素总数`，当 `δ <= 0.05` 时称为稀疏矩阵。

**压缩存储方法**：

**方法一：三元组顺序表**

每个非零元素用一个三元组 `(行号, 列号, 值)` 表示，所有三元组按行优先顺序存储。

```c
#define MaxSize 100  // 非零元素的最大个数
typedef struct {
    int i, j;  // 非零元素的行号和列号
    ElemType e;  // 非零元素的值
} Triple;

typedef struct {
    Triple data[MaxSize];  // 三元组数组
    int mu, nu, tu;  // 矩阵的行数、列数、非零元素个数
} TSMatrix;
```

优点：节省存储空间
缺点：随机访问需要遍历查找，矩阵的插入删除操作需要移动大量元素

**方法二：十字链表（链式存储）**

每个非零元素用一个节点表示，节点包含：行号、列号、值、向右指针（指向同一行的下一个非零元素）、向下指针（指向同一列的下一个非零元素）。

每行的非零元素链接成一个行链表，每列的非零元素链接成一个列链表，整体形成一个十字交叉的链表结构。

优点：适合矩阵的动态变化（插入、删除非零元素）
缺点：结构复杂，需要额外的指针空间

> [!important] 考研考点
> 1. 对称矩阵、三角矩阵、三对角矩阵的下标映射是选择题高频考点
> 2. 稀疏矩阵的两种存储方式（三元组、十字链表）了解即可
> 3. 矩阵压缩存储的题目，关键是先确认存储方式（行优先/列优先）、下标基准（0基/1基），然后现场推导

### 13.4 易错点总结

1. **顺序栈top约定**：`top=-1`和`top=0`两种约定的入栈出栈代码完全不同，考试先看题目说明
2. **循环队列牺牲单元**：最多存`MaxSize-1`个元素，判满条件`(rear+1)%MaxSize==front`
3. **循环队列长度公式**：`(rear-front+MaxSize)%MaxSize`，加MaxSize防负数
4. **后缀求值操作数顺序**：先弹右操作数，后弹左操作数，减法除法不能反
5. **链队列删最后元素**：必须将rear指向头结点，否则悬空
6. **矩阵压缩下标基准**：0基还是1基，行优先还是列优先，先确认再推导
7. **共享栈判满**：`top0+1==top1`，不是`top0==top1`
8. **卡特兰数适用条件**：只适用于固定入栈次序，改变入栈次序不能直接套用

## 旧版补充：题型训练与复习资料

### 典型题型与解题方法

1. **循环队列**：先写清 `front`、`rear` 指向有效元素还是空位，再套判空、判满、长度公式。
2. **出栈序列**：模拟入栈并尽可能匹配弹出；只看局部逆序容易误判。
3. **表达式**：转换时维护运算符栈，求值时维护操作数栈；写清结合性和操作数弹出次序。
4. **矩阵压缩**：先确定存上三角还是下三角、行优先还是列优先、二维与一维下标基准，再数前面完整行的元素。


### 完整例题与逐步解答

#### 例 1：循环队列状态

容量为 $M=8$ 的数组实现循环队列，约定 `front` 指向队头元素，`rear` 指向下一可插入位置，并牺牲一个单元。当前 `front=6`、`rear=2`，求队列长度、有效下标和再入队一个元素后的状态。

> [!success]- 展开完整答案
> 长度公式为
>
> $$
> len=(rear-front+M)\bmod M.
> $$
>
> 代入得
>
> $$
> len=(2-6+8)\bmod8=\boxed{4}.
> $$
>
> 从 `front` 开始按模 8 前进 4 步，有效元素位于下标
>
> ```text
> 6, 7, 0, 1
> ```
>
> 新元素写入 `data[2]`，然后
>
> $$
> rear=(2+1)\bmod8=3.
> $$
>
> 判空为 `front==rear`，判满为 `(rear+1)%M==front`。牺牲一个单元使空与满状态不再使用同一对指针值。

#### 例 2：后缀表达式求值

求后缀表达式

```text
5 2 3 * -
```

的值，并说明弹栈顺序。

> [!success]- 展开完整答案
> 从左到右扫描：5、2、3 依次入栈。遇到 `*`：第一次弹出 3 作为右操作数，第二次弹出 2 作为左操作数，计算 $2\times3=6$ 并压栈。
>
> 此时栈为 `[5,6]`。遇到 `-`：先弹 6 作为右操作数，再弹 5 作为左操作数：
>
> $$
> 5-6=\boxed{-1}.
> $$
>
> 对减法、除法尤其不能颠倒：代码通常写作 `right=pop(); left=pop(); push(left op right)`。

#### 例 3：对称矩阵压缩下标

一个 $n$ 阶对称矩阵按行优先只存下三角（含主对角线），一维数组从 1 编号。元素 $a_{ij}$ 映射到哪个位置？

> [!success]- 展开完整答案
> 若 $i\ge j$，在第 $i$ 行之前共存
>
> $$
> 1+2+\cdots+(i-1)=\frac{i(i-1)}2
> $$
>
> 个元素，本行中 $a_{ij}$ 是第 $j$ 个，所以
>
> $$
> \boxed{k=\frac{i(i-1)}2+j}.
> $$
>
> 若 $i<j$，利用对称性 $a_{ij}=a_{ji}$，交换下标后映射：
>
> $$
> \boxed{k=\frac{j(j-1)}2+i}.
> $$
>
> 若数组从 0 编号，最终位置还要减 1；矩阵和数组下标基准必须分别确认。


### 做题识别顺序

1. 栈/队列先写指针语义，再写判空、判满、长度，不能只背公式。
2. 表达式题明确结合性和优先级；后缀求值记住先弹右操作数。
3. 循环队列所有指针更新都取模，牺牲单元时最大元素数为 $M-1$。
4. 数组地址题先数前面完整的行/列，再加本行/列内偏移，最后乘元素大小。
5. 特殊矩阵先把任意 $a_{ij}$ 映射到实际存储的三角区域，再统一 0 基/1 基。


### 一页记忆

$$
\boxed{
len=(rear-front+M)\bmod M
}
$$

$$
\boxed{
empty:front=rear,\qquad
full:(rear+1)\bmod M=front
}
$$

- 栈后进先出，适合递归、括号、表达式和 DFS；队列先进先出，适合层序、缓冲和 BFS。
- 共享栈从数组两端向中间增长，通常 `top1+1==top2` 时满。
- 行优先地址：基址 +（前面完整行元素数 + 行内偏移）× 元素字节数。


### 易错点

- 牺牲单元的循环队列最多存 $M-1$ 个元素。
- 链队列删除最后一个数据结点后必须同步修正尾指针。
- 栈混洗不是任意排列；固定入栈次序存在禁形。
- 后缀求值第一次弹出的是右操作数。
- 矩阵题最常错在 0 基与 1 基混用，以及把矩阵阶数当作每元素字节数。

### 自测问题

1. 长度为 $M$ 的循环队列为何常只能存 $M-1$ 个元素？
2. 共享栈在什么条件下判满？
3. 后缀表达式 `5 2 3 * -` 的结果是什么？
4. 对称矩阵存下三角时，访问上三角元素如何映射？
5. 链队列删除最后一个结点时为何要修改 `rear`？

> [!question]- 自测问题参考答案
> 1. 若所有 $M$ 个单元都可用，则 `front==rear` 既可能表示空也可能表示满。牺牲一个单元后用 `(rear+1)%M==front` 表示满，二者可区分。
> 2. 两栈从两端向中间增长时，`top1+1==top2` 判满。
> 3. 先算 $2\times3=6$，再算 $5-6=-1$。
> 4. 对称矩阵有 $a_{ij}=a_{ji}$。若只存下三角，访问 $i<j$ 的上三角元素时交换下标，按 $a_{ji}$ 的下三角位置映射。
> 5. 删除后队列若变空，头指针指向头结点而原尾结点已释放；若不把 `rear` 也改回头结点，它会成为悬空指针，后续入队会破坏链。
