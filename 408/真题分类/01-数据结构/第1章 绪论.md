## 2011年

### 第1题（选择题）

设n 是描述问题规模的非负整数，下面程序片段的时间复杂度是 。

```c
x=2;
while(x<n/2) x=2*x;
```

A. `O(log2n)`
B. `O(n)`
C. `O(nlog2n)`
D. `O(n 2)`

---

## 2012年

### 第1题（选择题）

求整数n（n≥0）阶乘的算法如下，其时间复杂度是 。

```c
int fact (int n) {
    if(n<=1) return 1 return n*fact(n-10)
}
```

A. `O(log2n)`
B. `O(n)`
C. `O(nlog2n)`
D. `O(n 2)`

## 2014年

### 第1题（选择题）

下列程序段的时间复杂度是 。

```c
count=0;
for (k=1; k<=n;k*=2) for (j=1; j<=n; j++) count++;
```

A. `O(log2n)`
B. `O(n)`
C. `O(nlog2n)`
D. `O(n 2)`

## 2017年

### 第1题（选择题）

下列函数的时间复杂度是 。

```c
int func(int n) {
    int i=0, sum=0;
    while(sum<n)sum += ++i;
    return i;
}
```

A. `O(log n)`
B. `O(n 1/2)`
C. `O(n)`
D. `O(n log n)`
