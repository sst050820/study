## 协议栈速查

| 层次 | 数据单元 | 关键标识 | 典型设备/协议 |
|---|---|---|---|
| 应用层 | 报文 | 名称、URL | DNS、HTTP、SMTP、FTP |
| 传输层 | TCP 报文段/UDP 用户数据报 | 端口 | TCP、UDP |
| 网络层 | IP 数据报 | IP 地址 | 路由器、IPv4/IPv6、ICMP |
| 数据链路层 | 帧 | MAC 地址 | 网桥、交换机、Ethernet |
| 物理层 | 比特 | 信号参数 | 中继器、集线器 |

## 高频计算链

- 时延：发送时延、传播时延、排队时延、处理时延。
- 链路：Nyquist、Shannon、CRC、窗口上限、信道利用率、最小帧长。
- 网络：子网/CIDR、最长前缀匹配、分片偏移、路由收敛。
- 传输与应用：TCP 序号/ACK/窗口、拥塞窗口、DNS+TCP+HTTP 交互时间。

## 知识图谱与综合复习路线

- 六张章级图已分别嵌入六份原章节笔记，避免在目录页一次加载全部高清长图。

两套资料合并后应沿两条方向相反、彼此校验的主线复习：

1. **发送/封装主线**：应用生成报文 → TCP/UDP 加端口和可靠性信息 → IP 选择下一跳 → ARP 获得下一跳 MAC → 交换机按 MAC 表转发 → 物理层发送信号。
2. **接收/排错主线**：先确认链路与帧，再看 IP 地址、路由和 ICMP，随后检查端口、TCP 状态与拥塞窗口，最后才定位 DNS、HTTP 等应用协议。

**背诵重点**集中在体系分层、物理层公式、停止等待/GBN/SR 三套可靠机制、随机接入、IPv4 地址与路由、TCP 可靠传输和拥塞控制，以及各层首部关键字段。**大题重点**是“主机进入某域名后的端到端过程”：联合填写交换表、ARP 表和路由表，解释 DHCP 配置、ICMP 差错、特殊地址、TCP 建连/传输/释放及 HTTP 交互。

综合题每走一跳都问三件事：IP 源/目的是否改变，MAC 源/目的是否改变，使用哪张表决定下一步。这样可以避免把端到端标识和逐跳标识混在一起。
