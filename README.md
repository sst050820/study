## 笔记规范

每篇章节笔记遵循统一结构：

1. **本章必背 N 条（30 秒版）** —— 打开先扫一眼骨架
2. **考点地图 / 知识结构** —— 整章的树形导览
3. **完整知识点** —— 分节讲解，含公式与代码
4. **典型题型 + 例题** —— 逐步解答
5. **易错点** —— 单独高亮
6. **闭卷自测** —— 答不上来再回头精读

链接写法统一为**库根全路径**（如 `[[408/01-数据结构/02-知识结构文档/第2章-线性表]]`），禁用 `../` 相对路径——目录层级手写易错，且失效是静默的。

详见 [`00-链接规范.md`](00-链接规范.md)。

## 使用说明

### 本地使用（Obsidian）

1. `git clone` 本仓库，或用 Obsidian「打开文件夹」直接指向本地 `study/`
2. 推荐从 [`00-学习总览.md`](00-学习总览.md) 进入
3. 修改笔记前建议先阅读 [`00-链接规范.md`](00-链接规范.md)

### 同步

```bash
git add -A
git commit -m "更新笔记"
git push origin main
```

> ⚠️ 在 Obsidian 中重命名/移动文件前，请先关闭「设置 → 文件与链接 → 自动更新内部链接」，否则库根路径会被静默改写成裸名。
