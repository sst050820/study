# 2027考研政治每日1小时计划

**实际从2026年10月9日开始，复习至12月18日，共71天，每天60分钟。** 之前的日期不算已完成进度。政治考试安排为12月19日上午，具体以准考证为准。[教育部《2027年全国硕士研究生招生工作管理规定》](https://www.moe.gov.cn/srcsite/A15/moe_778/s3261/202609/t20260923_1451734.html)

这次根据你新找到的五份资料重新安排。**旧版手册退出当前计划；第一轮改到11月19日结束。** 入门前几天放慢，之后按小主题推进。目标是在每天1小时内建立框架、做代表题、反复回忆，不把逐字背完整本或刷完全部1000题设为硬指标。

### 使用时需要知道的两点

1. **“完整版”这个文件名实际指上册。** 下册节选缺少印刷12—46页和52页以后内容，所以不能据目录把时政、认识论、习概、史纲、思法的完整分析题模板视为已经提供。独立自测本其余Day暂不列为必背任务。
2. 上册专题1—5自测和独立下册自测本都没有印在文件内的完整答案部分。先回查正文核对；扫码速查不是本地PDF里的答案。无法确认的题标为“?”，不要把猜测当成正确表述。

《考点清单》用于解释手册中没理解的概念；肖1000用于练习和订正；“500句”暂作可选补充。这些阅读都计入当天60分钟。

## 二、每天怎样分配60分钟

### 10月9日—11月19日：理解、练题、短句背诵

| 用时 | 做什么 |
|---|---|
| 5分钟 | 合书回想昨天2—3个考点。第一天用于打开资料和认识学习顺序 |
| 20分钟 | 读2027上册当天小主题；看不懂的地方在这20分钟内查《考点清单》 |
| 15分钟 | 做对应肖1000。第一周约5—8题，今天是导论单选1—7题；时间到就停 |
| 10分钟 | 读解析、订正错误和蒙对题，每个错因记一句话 |
| 10分钟 | 遮住上册复述3—5个已学考点，或选做已学专题对应的上册自测 |

**5＋20＋15＋10＋10＝60分钟。** 自测用于回忆已学内容，不要求每学一个专题就额外做完整组题。专题组学完的自测日，把20分钟新内容阅读改为自测和回查；当天肖1000以重做相关错题为主。

11月8—14日的下册会议阅读与自测，**替代最后10分钟的上册自测**。优先复述与当天史纲或前面毛中特、习概对应的2—3个会议；整组做不完留待复习，不增加时长。

第一天的具体顺序是先理解导论、再用新手册背精选关系、最后做题订正，详见[[04-每日学习/2026-10-09-第1天-马原导论|今天的学习单]]。

### 11月20日—11月26日：补漏、错题、下册原理自测

| 用时 | 做什么 |
|---|---|
| 5分钟 | 回想前一天错题或薄弱概念 |
| 20分钟 | 重做肖1000“× / ?”题，或选做已学主题对应的近年真题选择题 |
| 15分钟 | 订正并回查上册；理解不清时查《考点清单》 |
| 10分钟 | 上册薄弱专题自测或闭卷对比易混概念 |
| 10分钟 | 下册原理复述或会议自测；只做现有节选能核对的内容 |

**5＋20＋15＋10＋10＝60分钟。** 优先补高频空缺，真题按主题选做，不要求这一周刷完五年所有选择题。

### 11月27日—12月17日：模拟选择题、时政与分析题

- **选择题重点日：**5分钟旧考点回忆＋25分钟模拟选择题＋15分钟订正＋15分钟时政/分析题复述＝60分钟。
- **背诵重点日：**5分钟旧框架回忆＋15分钟错题重做＋10分钟订正＋30分钟时政/分析题复述＝60分钟。12月逐渐增加这种安排。
- 模拟卷分次完成；当天做不完的题留到下次。给背诵保留固定时段。
- 下册节选用于练“识别材料考什么原理→说原理关键词→联系材料”，每次先练一个原理；不把原理模板当成适用所有设问的完整答案。
- 时政与其他科目分析题使用当年、对应主题的冲刺资料。现有下册节选没有提供这些完整内容，**获得相应资料后放进15/30分钟背诵时段替换使用**。
- 旧真题分析题主要看设问和答题结构；“500句”用于选择题考点巩固，不替代分析题专题答案。

### 12月18日：轻复习

回看已标记的错题、时政关键词、已经背过的分析题框架，保持状态，准备次日上午考试。

## 五、周复盘和落后时怎样调整

每周最后一天，把当天15分钟新题时段改为复盘：检查最易错的两个主题、上周错题是否能解释、哪些考点仍无法闭卷说出。仍然总计60分钟。

若落后，先减少新题和重复阅读，保留订正、回忆；第二天继续当前主题，不补双倍时长。补漏顺序为：反复错的核心概念→常见题型→细枝末节。尚未完成的内容写在补漏清单，不勾成完成。
